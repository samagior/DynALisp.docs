LeeMac Sample Module

The LeeMac module is a sample module: it showcases what DynALisp does with a collection of existing AutoLISP programs, here programs by Lee Mac (www.lee-mac.com). It holds 115 programs and 196 commands: 115 main commands and 81 child commands. Use it as a model for a module of your own (a folder of Contents\Modules, with the same Apps, Remote and Docs folders):

  • Startup Suite – every program is indexed in Dyl-Suite (Dyl-SuiteUpdate reads the Lisp files): turned on or off, loaded at startup, its aliases edited and its docs page opened, without touching its code.
  • Main and child commands – one LM-* main command per program, its presets and variants as Pst-* child commands, and the original command names kept as aliases.
  • Shared subfunctions – the Lee Mac subfunctions are loaded once, when the first program runs (Remote\LM-Sub.lsp, Remote>> prefix) and offered in VS Code as snippets (LM-LocalSub, LM-RemoteSub).
  • Docs – one page per program, with its commands and aliases, opened from Dyl-Suite; this index opens with LM-Docs.

Each program has one main command named LM-*. Its presets and variants are child commands (Pst-*), run by their aliases (the short names, e.g. AT) or picked from the main command. In Dyl-Suite, a main command with children shows [+] / [-]: double-click it (or Fold/Unfold) to show or hide its children; double-click any other command (or Docs) to open its page, the commands without a page of their own opening this index. The list is sorted by command, aliases, name, module or group with Sort by, each main command keeping its children under it. Aliases are added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).

The help pages are delivered for consistency purposes only, as the docs of this sample module: they are copies of Lee Mac's pages, and the programs and their descriptions are the work of Lee Mac, who keeps all the credit for them. Each page links to its original on his website, www.lee-mac.com, for the latest version. They name the commands by their original names, kept as aliases. The programs without a help page of their own open this index. The programs keep their author and their licence (Licences\LEE-MAC-LICENCE.md).
