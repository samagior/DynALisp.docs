Program Description

This program is the precursor of my more generalised and extensively developed Steal from Drawing program. This program allows a user to import a block from a selected drawing file into the active drawing, without opening the external file.

Upon issuing the command syntax IB at the AutoCAD command line, the user is prompted to select a drawing file (dwg/dwt/dws) from which to source the block to be imported.

Following a valid response, a dialog is displayed prompting the user to select a block from the list of blocks defined in the selected drawing file and not already present in the current drawing.

Following selection, the definition of the chosen block is imported into the active drawing and the user is prompted to specify an insertion point at which a reference of the imported block will be inserted.

The program will perform successfully in all UCS/Views and is also compatible with Dynamic Blocks.

See also: Steal from Drawing & Copy or Rename Block Reference.
