Ribbon

The developer docs of Ribbon: its files and how its code works. What it does and how to use it are in its User Guide page.

Building The Ribbon

For whoever changes DynALisp: the tab is generated, never edited in the CUI editor.

  • Installer\Ribbon\BuildRibbon.py writes DynALisp.cuix from Installer\Ribbon\Ribbon.csv (the panels and buttons), RibbonIcons.py (the icons) and Resources\StartupSuite.csv (the names, descriptions and children). It warns about a main command missing from the ribbon or without an icon. --sheet <file.png> draws every icon on the light and the dark ribbon.
  • The texts of the tab in another language are in Installer\Ribbon\Ribbon.fr.csv (a panel, a command or an item of the Quick Draw gallery, its name and its tooltip); the script writes them by the id of each item in Resources\DynALisp.Ribbon.fr.csv, which the plugin reads, and warns about a text missing.
  • The drop-downs are built with dotnet build Installer\Ribbon\Plugin -c Release, AutoCAD closed.
  • The same run draws the pictures of this page from the same panels and icons (Installer\Ribbon\RibbonPanels.py, into Docs\Plugins\Ribbon) and writes its Panels section: they follow the ribbon, with no screenshot to take. --pictures draws them only.
  • Restart AutoCAD to see the new ribbon.

The Plugin

  • Plugin.cs – the IExtensionApplication of the DLL, its [assembly: CommandClass(...)] listing every class that holds a LispFunction (a static class cannot be listed, and a function of a class not listed is never defined, so every (if Dyl:X ...) of the Lisp side does nothing). Host holds what every part shares: Host.OnIdle (the ribbon is changed only when AutoCAD is idle with no command running), Host.Picks (only an item the user picks runs a setter), Host.Standard (the AEC lists of Res\AEC\Standard), Host.Labels, Host.Run. Part is the base of a drop-down part, Part.Later asks for a change at the next idle.
  • PhaseCombos.cs – the Auto-phase and Phase drop-downs: Dyl:RibbonPhase records the state the Lisp side pushes (Remote>>Dyl:PhaseStatus), each drawing keeps its own, and a pick runs Remote>>Dyl:PhaseSet or PhaseAutoSet (see Layer Phase).
  • TransferCombos.cs – the Level, From and To drop-downs of Layer Transfer, their lists read from the drawing after each command; Dyl:RibbonTransfer gives the choice to Pst-TransferField. NcsName reads a layer name with the rule of Dyl-LayTransfer-Ncs: change both together.
  • Translations.cs – the tab in the language of the AutoCAD installed: the texts of DynALisp.Ribbon.<code>.csv put on the items by their UID, again when AutoCAD makes the ribbon again; Dyl:RibbonLang and Dyl:RibbonLangInfo.

The DLL is built with dotnet build Installer\Ribbon\Plugin -c Release, AutoCAD closed (it keeps the DLL open), for .NET 8: AutoCAD 2025 and later. In an older AutoCAD, the tab is the CUIx alone, in English, without the drop-downs.
