Clean Startup

The developer docs of Clean Startup: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesInstaller\Startup\Startup.cs (DynALisp.Startup.csproj), built twice and committed: Contents\Resources\DynALisp.Startup.dll (.NET 8, AutoCAD 2025 and later) and Contents\Resources\Net48\DynALisp.Startup.dll (.NET Framework 4.8, AutoCAD 2015 to 2024), a component of PackageContents.xml each
DataThe user setting DynalispCleanStartup, read by the plugin itself from FixedProfile\General of the product key
FollowsThe Versions And Updates convention on plugins every version needs

How It Works

  1. The plugin reads DynalispCleanStartup itself when it loads: it never relies on a Lisp call made while DynALisp loads.
  2. It waits until AutoCAD has started: DynALisp loaded, no command running, and the command line quiet for 2 seconds.
  3. AutoCAD has no API for its command line: the plugin finds, by reflection, the list the command line shows (CommandLineViewModel.HistoryCollection of AcWindows.dll, the same in AutoCAD 2015, 2026 and 2027). In a version where it is not found, or is not a list, it does nothing.
  4. The lines of the startup are blanked, but the Drawing created using... line, the lines of DynALisp (DynALisp loaded..., -->) and every line reporting an error or a warning, which are moved to the end. The F2 text window keeps the whole log.
  5. Dyl:CleanStartup is its Lisp function: the Settings window checks it before showing the toggle, greyed out when the plugin is not loaded.
