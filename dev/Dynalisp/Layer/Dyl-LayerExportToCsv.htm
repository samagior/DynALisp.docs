Export Layers To CSV

The developer docs of Export Layers To CSV: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerExportToCsv.lsp
Writes%USERPROFILE%\Downloads\layers_YYYYMMDD.csv, the format read by Import Layers From CSV

How It Works

  1. The output file is %USERPROFILE%\Downloads\layers_YYYYMMDD.csv; if USERPROFILE is not set, HOMEDRIVE + HOMEPATH is used, and as a last resort the drawing folder.
  2. Every layer of the layer table is read (xref-dependent layers included) and its values are turned into readable text (see table below).
  3. Rows are sorted by layer name, case-insensitive.
  4. The file is written in UTF-8 with a BOM (for Excel) and a header row; values containing commas, quotes or line breaks are quoted.
  5. The command reports the number of layers and the full path of the file.

The Code

One command, c:Dyl-LayerExportToCsv, with its helpers as local functions: lw->string and color->string turn the ActiveX values into the texts of the table, csv-escape quotes a field holding a comma, a quote or a line break. The layers are read through vla-get-Layers, sorted with vl-sort on their upper-case name, and written with an error handler that closes the file.

Known Limitations

  • The header comment of the file still names the command EXPORTLAYERS, its name before the conventions.
  • The file is divided by commas, not by ; as the data files of DynALisp.
