Layer Keys

The developer docs of Layer Keys: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Layer\Dyl-LayerKeys.lsp (command) and Modules\Dynalisp\Remote\Dyl-LayerKey.lsp (layer keys, loaded at startup)

How It Works

  1. When an App uses a key, the key is looked up in LayerKeys.csv. Default keys missing from the file use their default values.
  2. If the layer of the key exists in the drawing, it is used; when its properties differ from those of the key, you are asked whether to update it (see Layers That Differ From Their Key). It is never changed without your answer.
  3. If it does not exist, it is created with the color, linetype, lineweight, plot setting and description of the key. A linetype that is not loaded yet is loaded from acad.lin (imperial) or acadiso.lin (metric); if it cannot be loaded, the layer stays Continuous.
  4. While auto-phase is on, every key adds the active phase to its layer name (an AEC layer override too, to the layer of the layer key style); that layer is created with the phase color (2# for existing to demolish, 20# for existing to remain, the key color otherwise, and always when the key keeps its color in every phase). With auto-phase on, objects created on the layer of a key also go to the active phase.
  5. The layer a key gives an App to draw on is thawed and turned on when it is frozen or off, with a message on the command line (Layer A-Detl-Patt-E thawed to draw on it.): a frozen layer cannot be made current, and the objects on it cannot be selected, so the outlines drawn there could not be hatched. Locked layers are left locked.
  6. A key that is not defined uses a layer of the same name, created as color 7, Continuous, default lineweight; a message names the key on the command line.
  7. An AEC layer override uses the layer the layer key style of the drawing gives it (see AEC Layer Overrides).

The new dimensions, leaders, text and other common objects can go to a layer key of their own too, whatever the current layer: see Object Layer Keys (Auto layer keys, Dyl-Settings).

Using Layer Keys In An App

  • (Remote>>Dyl:LayerKeyLayer "THIN") – returns the layer of the key, created if missing.
  • (Remote>>Dyl:LayerKeyApply (entlast) "THIN") – puts an object on the layer of the key.
  • (Remote>>Dyl:LayerKeyRead) – returns every key: (key layer color linetype lineweight plot description aec).
  • (Remote>>Dyl:LayerKeyDialog key) – opens the Layer Keys dialog on a key; returns T when the keys were saved.
  • (Remote>>Dyl:LayerKeyPick key) – the same dialog to pick a key: returns the key double-clicked (the keys saved), nil on OK or Cancel.
