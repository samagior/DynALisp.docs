Layer Color Weight

The developer docs of Layer Color Weight: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerColorWeight.lsp
DataThe layer table of the drawing; the standard itself is Res\Layer\Dyl Standard.pdf and the plot style Res\Printers\Plot Styles\Dyl Standard.ctb (the code holds its rule, it reads neither file)

The Rule In The Code

  • LCW:weights – the lineweights (1/100 mm) of the last digits 0 to 9.
  • (LCW:WeightOf aci) – the lineweight of a color: 10 to 249 by their last digit, the pens 1 to 7 by their number, the greys 8, 9 and 250 to 255 at 13.
  • (LCW:Digit lw) – the last digit of a lineweight, the nearest one of the standard for a lineweight it does not have; nil for Default.
  • (LCW:ColorOf aci lw) – the color for a lineweight: the color itself when it already gives it; a color 10 to 249 keeps its tens and takes the digit; a pen 1 to 6 goes to its hue through (0 10 50 90 130 170 210) plus the digit; black and the greys go to the pen of the digit (1 to 7), nil otherwise.

How It Works

  1. With DYL-LAYERCOLORWEIGHT, choose Lineweight (default, the lineweight follows the color) or Color (the color follows the lineweight). The two child commands skip this question.
  2. Choose All (default, every layer of the drawing) or Select (the layers of the objects you select).
  3. Lineweight from color: each layer takes the lineweight of its color in the table above.
  4. Color from lineweight: a color from 10 to 249 keeps its tens (its hue) and takes the last digit of its lineweight: color 11 with 0.35 mm becomes 13. A pen color 1 to 6 goes to its hue: red 1 with 0.35 mm becomes 13. Black (7) and the greys go to the pen color of the lineweight: 7 with 0.35 mm becomes 3. A lineweight that is not in the standard (0.30 mm) takes the nearest one (0.35 mm). A layer that already matches is left as is, so a dark grey ##9 layer at 0.13 mm stays dark grey.
  5. The changes are one undo step. The command reports how many layers changed, how many already matched, and lists the layers not changed.

The Code

  • c:Dyl-LayerColorWeight asks Lineweight/Color and runs (LCW:Run tocolor); c:Pst-LayerWeightByColor and c:Pst-LayerColorByWeight run it directly.
  • LCW:Run asks All/Select (LCW:SelLayers: the layers of the objects selected, upper case, each once), then walks the layer table with tblnext inside one undo mark (its error handler ends the mark). A layer of an xref (bit 16 of code 70) is passed over; one in true color or a color book (codes 420, 430), or with no value for the rule, is listed as not changed; the others get code 62 (its sign kept, so a layer off stays off) or code 370 with entmod when their value differs.
  • It prints the count changed and already matching, and the layers not changed, sorted.
