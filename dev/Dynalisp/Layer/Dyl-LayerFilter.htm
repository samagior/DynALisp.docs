Layer Filters

The developer docs of Layer Filters: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Layer\Dyl-LayerFilter.lsp

How It Works

Each command is a preset made of five pattern lists (show, hide, secondary show, secondary hide, screen), a lock flag and a start state. When the command runs:

  1. Xrefs – xrefs inserted on a layer that has the same name as the xref (sheet set convention) have that layer added to the show list, along with layers 0 and Defpoints.
  2. Tokens – group names in the lists are expanded into wildcard patterns (see table below).
  3. Phases – for Existing views, -E and -X variants of the show patterns are added; New views also add -N -R -M; Demolition views add -D -S -T.
  4. Model space – an UNDO mark is set, every layer is reset to 0% transparency and unlocked; presets with a Reset start state then set layer 0 current and turn off and freeze every layer. -LAYER then turns on/thaws the show lists and turns off/freezes the hide lists (primary first, secondary last, so the secondary lists win), applies 50% transparency to the screen list, optionally locks it, and regenerates.
  5. Paper space – select the viewports (other objects are ignored). The same lists are applied with VPLAYER (freeze/thaw and 50% transparency) to the selected viewports only; the layers themselves are not changed.
  6. If the command fails, the drawing is rolled back to the UNDO mark.
