Layer Filters

The developer docs of Layer Filters: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerFilter.lsp
ReadsThe layer table, the xrefs of the drawing and the Model views folder beside it

A Preset

Each child command sets the lists of its view, then calls the engine:

(defun c:Pst-ArchitecturalFloorPlanFilter (/ *shw *hid *sh2 *hi2 *scn *lck *msg)
  (setq *str "Empty"            ; the start state: "Empty" (Reset) or "Curent" (Keep)
        *shw '("A-Flor")        ; shown, primary
        *hid '()                ; hidden, primary
        *sh2 '() *hi2 '()       ; shown and hidden, secondary (applied last, so they win)
        *scn '()                ; screened at 50 % transparency
        *lck "No"               ; "Yes": the screened layers are locked
        *msg "Architectural floor plan")
  (Dyl-LayerFilter *shw *hid *sh2 *hi2 *scn *lck *msg)
)

A new view is one more child of that form, with its comment lines for Dyl-SuiteUpdate and its alias. c:Dyl-LayerFilter is Dyl:ChildPicker of dynalisp.mnl.

How It Works

Each command is a preset made of five pattern lists (show, hide, secondary show, secondary hide, screen), a lock flag and a start state. When the command runs:

  1. Xrefs – xrefs inserted on a layer that has the same name as the xref (sheet set convention) have that layer added to the show list, along with layers 0 and Defpoints.
  2. Tokens – group names in the lists are expanded into wildcard patterns (see table below).
  3. Phases – for Existing views, -E and -X variants of the show patterns are added; New views also add -N -R -M; Demolition views add -D -S -T.
  4. Model space – an UNDO mark is set, every layer is reset to 0% transparency and unlocked; presets with a Reset start state then set layer 0 current and turn off and freeze every layer. -LAYER then turns on/thaws the show lists and turns off/freezes the hide lists (primary first, secondary last, so the secondary lists win), applies 50% transparency to the screen list, optionally locks it, and regenerates.
  5. Paper space – select the viewports (other objects are ignored). The same lists are applied with VPLAYER (freeze/thaw and 50% transparency) to the selected viewports only; the layers themselves are not changed.
  6. If the command fails, the drawing is rolled back to the UNDO mark.

The Engine

Dyl-LayerFilter (a function, not a command) does the steps above: its comment block names each of its locals. It sets an UNDO mark (*dyl-marked) and an error handler that goes back to it (_.undo _back) and restores CMDECHO; expands the group tokens of *shw, *hid, *sh2, *hi2 into patterns; then runs _.-LAYER in model space, or _.VPLAYER on the viewports of (ssget "P" '((0 . "VIEWPORT"))) in paper space. Local>>LM:lst->str is a local copy of the Lee Mac function.

Known Limitations

  • *str is a global variable, not a local of the presets, and its Keep value is spelled "Curent".
  • An xref whose drawing is in the Model views folder beside the drawing should get its layers screened, but the test compares the xref name with the file names of that folder, which end in .dwg: it likely never matches. *rst, the xrefs not found there, is built but not used.
