Layer Drawing List

The developer docs of Layer Drawing List: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerList.lsp

How It Works

  1. Pick the insertion point of the first row.
  2. Choose All (default, every layer of the drawing in layer table order) or Select (the layers of the objects you select, each once).
  3. For each layer the routine creates, on that layer: a 200-unit horizontal line, the layer name as text (height 2.25) 1 unit above the line and, if the layer has one, its description 75 units to the right.
  4. The next row starts 7.5 units below.

The Code

  • c:Dyl-LayerList asks the point and Select/All. All walks the layer table with tblnext; Select takes the layer (code 8) of each object of (ssnamex (ssget)), each once.
  • (lnd-list pt layer) makes the row with entmake: a LINE from pt to 200 units right, a TEXT of height 2.25 one unit above, and a second TEXT 75 units right for the description (read with getpropertyvalue), all on the layer. It returns the point 7.5 units below, for the next row.

Known Limitations

  • The sizes are drawing units, not scaled to the annotation scale.
  • With Select, the list is built with acad_strlsort but the sorted list is dropped (progn returns lst), so the layers come in selection order.
  • The command uses getpropertyvalue (AutoCAD 2012 and later) and the current text style.
