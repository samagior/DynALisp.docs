Layer Drawing List

The developer docs of Layer Drawing List: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Layer\Dyl-LayerList.lsp

How It Works

  1. Pick the insertion point of the first row.
  2. Choose All (default, every layer of the drawing in layer table order) or Select (the layers of the objects you select, each once).
  3. For each layer the routine creates, on that layer: a 200-unit horizontal line, the layer name as text (height 2.25) 1 unit above the line and, if the layer has one, its description 75 units to the right.
  4. The next row starts 7.5 units below.
