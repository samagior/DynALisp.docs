Layer Pen Colors

The developer docs of Layer Pen Colors: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Layer\Dyl-LayerPenColors.lsp

How It Works

  1. With DYL-LAYERPENCOLORS, choose Pens (default) or Restore. The two child commands skip this question.
  2. Choose All (default, every layer of the drawing) or Select (the layers of the objects you select).
  3. Pens: each layer matching a rule gets the color of the rule (or keeps its own). Any other layer gets the pen color of its current lineweight, its color is not read. A lineweight that is not in the table takes the nearest one (0.30 mm gives 3).
  4. The first time a layer changes, its color is saved in the layer itself (true colors and color books too). Running Pens again later, for example on layers added since, never replaces a color already saved.
  5. Restore: each layer with a saved color gets it back, and the saved color is removed.
  6. The changes are one undo step. The command reports the layers changed, already matching, kept by a rule, and lists the layers not changed.
