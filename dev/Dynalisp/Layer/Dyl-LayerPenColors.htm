Layer Pen Colors

The developer docs of Layer Pen Colors: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerPenColors.lsp
DataModules\Dynalisp\Res\Layer\PenColors.csv (the rules, Name;Layers;Colors;Color;Description, your copy under User); the dyl-pens ldata of each layer (its saved color)

How It Works

  1. With DYL-LAYERPENCOLORS, choose Pens (default) or Restore. The two child commands skip this question.
  2. Choose All (default, every layer of the drawing) or Select (the layers of the objects you select).
  3. Pens: each layer matching a rule gets the color of the rule (or keeps its own). Any other layer gets the pen color of its current lineweight, its color is not read. A lineweight that is not in the table takes the nearest one (0.30 mm gives 3).
  4. The first time a layer changes, its color is saved in the layer itself (true colors and color books too). Running Pens again later, for example on layers added since, never replaces a color already saved.
  5. Restore: each layer with a saved color gets it back, and the saved color is removed.
  6. The changes are one undo step. The command reports the layers changed, already matching, kept by a rule, and lists the layers not changed.

The Code

  • LPC:pens – the pen color of each standard lineweight; (LPC:PenOf lw) the one nearest to a lineweight, nil for Default, ByLayer, ByBlock and 2.00.
  • LPC:Rules – reads PenColors.csv through Dyl:UserFile and Remote>>Dyl:CsvRead, LPC:defaults when it is missing; (LPC:Rule name aci rules) returns the first rule whose layer pattern and color pattern match (a true color never matches a rule on colors).
  • LPC:ColorGet / LPC:ColorPut – the color of a layer as (method index red green blue book name), through its TrueColor, and back: an RGB color and its color book are restored as they were.
  • (LPC:Run restore) – asks All/Select, then in one undo mark: for Pens, a layer gets the color of its rule or of LPC:PenOf, its color first saved with (vlax-ldata-put lay "dyl-pens" ...) when it has none saved; for Restore, a layer with saved data gets it back and the data is deleted. Xref layers are left out.
  • c:Dyl-LayerPenColors asks Pens/Restore; c:Pst-LayerColorsToPens and c:Pst-LayerColorsRestore run LPC:Run directly.
