Layer Groups

The developer docs of Layer Groups: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Layer\Dyl-LayerGroup.lsp

How It Works

  1. The routine opens the layer filter dictionary of the drawing (ACLYDICTIONARY in the extension dictionary of the layer table).
  2. For each discipline, an existing group filter with the same display name is found and removed, so running the command again rebuilds the groups instead of duplicating them.
  3. Every layer whose name matches the discipline pattern, plus layers 0 and Defpoints, is added to the new group filter (AcLyLayerGroup record listing the layers).
