Layer Groups

The developer docs of Layer Groups: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerGroup.lsp
WritesThe ACLYDICTIONARY dictionary of the extension dictionary of the layer table: the layer filters of the drawing

How It Works

  1. The routine opens the layer filter dictionary of the drawing (ACLYDICTIONARY in the extension dictionary of the layer table).
  2. For each discipline, an existing group filter with the same display name is found and removed, so running the command again rebuilds the groups instead of duplicating them.
  3. Every layer whose name matches the discipline pattern, plus layers 0 and Defpoints, is added to the new group filter (AcLyLayerGroup record listing the layers).

The Code

  • c:Dyl-LayerGroup runs Dyl:LayGroup, a function of about 850 lines, one region per discipline.
  • It gets (or makes) ACLYDICTIONARY with vla-addobject, then for each group: removes the group filter of the same name, collects the layers matching the pattern (and 0, Defpoints), and makes an AcLyLayerGroup record listing them.
  • Dyl-A and its siblings set the names of a group (*dic, *obj, *obj2) as global variables.

Known Limitations

  • The Mechanical group copies the Landscape pattern (L-*) in place of M-*.
  • Each discipline repeats the same code: one table of (name pattern sub-groups) and a loop would make a new discipline one row.
  • A group filter lists its layers: the layers made later are not in it until the command runs again.
