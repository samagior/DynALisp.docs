Make Layers

The developer docs of Make Layers: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerMake.lsp
DataThe CSV layer lists of *dyl:layerlist (Res\Layer\...), one folder per discipline, read through Dyl:UserFile

A Layer Set

Each child command names its lists, then calls the engine:

(defun c:Pst-MakeBasicDrawingLayers ()
  (setq *typ "Csv"                ; "Csv": layer lists, "Lyr": single layer names
        *dir "Dyl//Drawing"       ; the folder under *dyl:layerlist
        *lst '("Basic.csv"))      ; its CSV files
  (Dyl-LayerMake *typ *dir *lst *cop)
)

c:Dyl-LayerMake is Dyl:ChildPicker of dynalisp.mnl.

How It Works

  1. The rows of every CSV of the preset are read (header skipped).
  2. If a row contains the stack placeholder 0000, you are asked for the stack (None, 1-First … 9-Ninth) which replaces it with 0001 … 0009.
  3. If a row contains the discipline placeholder $$, you are asked for the discipline (General, Architectural, Interior, Structural, Landscape) which replaces it with its letter.
  4. The name fields are joined with hyphens to make the layer name; the Description column becomes the layer description.
  5. Properties are derived from the name:
    • colour: 151 by default, then fixed colours by keyword (e.g. Eqpm 1, Plnt 81, Note/Mark 122, Dims/Grid 221, Text 41, Scrn 8, Exst 9, Redl true colour 255,0,0; elevation layers have their own colours);
    • lineweight: from the last digit of the colour number – 0 → 0.13, 1 → 0.18, 2 → 0.25, 3 → 0.35, 4 → 0.50, 5 → 0.70, 6 → 1.00, 7 → 1.40, 8 → 2.00, 9 → 0.13 mm (grey colours always 0.13);
    • linetype: Continuous, or Center/Hidden/Phantom (and their 2 variants) for Cntr, Hdln, Phnt, Grid, Labl, Tags … layers;
    • plot: off for Nplt and Rdme layers.
  6. Each layer is made or updated with -LAYER and the command line shows ...<layer> - created or - updated.

The Engine

Dyl-LayerMake (a function of about 440 lines, its variables global) reads the rows of every CSV with Local>>LM:readcsv, looks for the placeholders with Local>>getMatching, asks for the stack and the discipline, builds the names, gets the properties from the keywords of the name, and makes each layer with _.-LAYER. Local>>LM:* are local copies of Lee Mac functions that Remote\LM-Sub.lsp also has.

Known Limitations

  • The discipline check passes the whole CSV data to wcmatch, which takes text only: every set stops there with bad argument type.
  • A row without the 0000 placeholder makes no name: the name is built only inside the stack substitution.
  • Several file names of the presets differ from the files shipped (A-Elev.csv and A-Elevation.csv, folder NCS and NCSv5); a file missing is skipped without a message.
  • *cop, the color group option, is fixed to "MinorColor", which adds no override.
  • The Layer Keys make standard layers the current way; this engine predates them.
