Make Layers

The developer docs of Make Layers: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerMake.lsp
DataThe CSV layer lists of *dyl:layerlist (Res\Layer\List), columns Designator,Major,Minor1,Minor2,Minor3,Description, read through Dyl:UserFile; Res\AEC\Standard\Major.csv for the description of a major group

A Layer Set

Each child command names its lists, relative to *dyl:layerlist, then calls the engine:

(defun c:Pst-MakeArchitecturalFloorPlanLayers ()
  (setq *typ "Csv"                ; "Csv": layer lists, "Lyr": a list of (name . description)
        *dir nil                  ; a folder for every file, or nil: the paths say it
        *lst '("Dyl\\Model\\Floor.csv" "Architecture\\A-Anno.csv"))
  (Dyl-LayerMake *typ *dir *lst *cop)
)

c:Dyl-LayerMake is Dyl:ChildPicker of dynalisp.mnl.

How It Works

  1. The rows of every list are read (header skipped, the separator the one the header uses); a list missing is reported.
  2. The questions, each only when a list needs it: the stack when a field is 0000 (0001 ... 0009, or dropped for None and Enter), the discipline when a designator is $$ or ??, the major group when a major is Maj$ or Majr (its description, from Major.csv, replaces MajrDesc$ and GroupTyp in the descriptions).
  3. The name is the first five fields joined with hyphens: a field ---- is dropped, and so are a ? (the optional second letter of an NCS designator: A? gives A) and a ~ padding a short field (Air~). A name already listed is kept once. The Description column is the layer description.
  4. Properties are derived from the name:
    • colour: 151 by default, then fixed colours by keyword (e.g. Eqpm 1, Plnt 81, Note/Mark 122, Dims/Grid 221, Text 41, Scrn 8, Exst 9, Redl true color 255,0,0), and by stack (Bgrd, Mcut of the elevations);
    • lineweight: from the last digit of the colour number – 0 → 0.13, 1 → 0.18, 2 → 0.25, 3 → 0.35, 4 → 0.50, 5 → 0.70, 6 → 1.00, 7 → 1.40, 8 → 2.00, 9 → 0.13 mm (grey colours always 0.13);
    • linetype: Continuous, or Center/Hidden/Phantom (and their 2 variants) for Cntr, Hdln, Phnt, Grid, Labl, Tags … layers, the ISO and JIS joint lines for the joints of the elevations;
    • plot: off for Nplt and Rdme layers.
  5. Each layer is made or updated through ActiveX (Local>>LayerPut), never made current, in one undo group; the command line shows ...<layer> - created or - updated, then the count.

The Engine

  • Dyl-LayerMake – reads the lists (Local>>LM:readcsv, Lee Mac's reader, the separator found in the header), looks for the placeholders (Local>>getMatching), asks the questions, builds the names (Local>>FirstN), gets the properties from the keywords of the name, and makes each layer. Its variables are local, and so is its *error*, which ends the undo group.
  • Local>>LayerPut – adds the layer or takes the one there (vla-Add, vla-Item), then sets its color (ACI, or a true color through AcCmColor), lineweight, linetype, plot and description; returns the error caught, reported for that layer alone.
  • Local>>Linetype – the linetype of the drawing, loaded from acad.lin or acadiso.lin (MEASUREMENT) when missing, else Continuous.
  • Local>>MajorDesc – the English description of a major group in Major.csv.

Known Limitations

  • *cop, the color group option (MinorColor, DesignatorColor...), is fixed to "MinorColor", which adds no override: the other groups are kept in the code but never used.
  • The Layer Keys make standard layers the current way; this engine predates them, and its colors are not those of the layer keys.
