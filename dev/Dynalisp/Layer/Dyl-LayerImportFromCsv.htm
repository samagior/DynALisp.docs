Import Layers From CSV

The developer docs of Import Layers From CSV: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Layer\Dyl-LayerImportFromCsv.lsp
DataThe preset CSV files (Modules\Dynalisp\Res\preset_arch_floor.csv only, so far), in the format of Export Layers To CSV; the layer states of the drawing

How It Works

Preset commands

  1. The preset CSV is looked up in the program folder. If it is missing, a file dialog opens instead.
  2. If the layer state of the preset already exists in the drawing, you choose U (restore the existing state, CSV ignored), I (apply the CSV and overwrite the state) or C (cancel).
  3. Otherwise the CSV is applied and the layer state is created.
  4. All viewports are regenerated.

Applying a CSV

  1. The header row and any UTF-8 BOM are skipped; quoted fields are supported.
  2. Each row is matched to an existing layer by name (case-insensitive). Layers that are not in the drawing are not created: they are counted and listed as MISSING.
  3. Colour, lineweight, linetype, plot, transparency, on/off, freeze, new viewport freeze and description are applied. A missing linetype is loaded from acad.lin / acadiso.lin; if it cannot be found, the layer keeps its linetype and a note is printed.
  4. A summary gives the number of layers updated and missing.

The Code

  • Presets – each child, c:Pst-ArchitecturalFloorPlanLayers…, is (il:run-preset csv state label). It looks for the CSV in *il-lsp-folder* and opens getfiled when it is not there; il:state-exists-p checks the layer state (through the LayerStateManager of ActiveX), il:ask-conflict asks U/I/C, il:state-restore or il:apply-csv then il:state-save runs, and every viewport is regenerated.
  • Reading the file – il:apply-csv reads it line by line: il:strip-bom, il:csv-split (quoted fields), then per layer of the drawing: il:parse-color (Red (1), ACI 151, 151), il:parse-lw, il:parse-trans; a missing linetype is loaded from acad.lin or acadiso.lin (il:find-lt, il:load-lt).
  • c:Dyl-LayerImportFromCsv (IMPORTLAYERS) opens getfiled in Downloads and runs il:apply-csv, without a layer state.

Known Limitations

  • *il-lsp-folder* is found by looking for import_layers_from_csv.lsp, the former name of the file, which the bundle no longer has: the presets are looked up in the drawing folder, and the file window opens in most cases. The folder should be *dyl:dylres.
  • The file is divided by commas, not ;; it is read with the raw path, not through Dyl:UserFile.
  • Colors are read as index colors.
