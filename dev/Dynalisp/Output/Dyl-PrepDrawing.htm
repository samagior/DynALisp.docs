Prep Drawing

The developer docs of Prep Drawing: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Output\Dyl-PrepDrawing.lsp (the steps and the command), the PrepBeforeOutput region of Resources\dynalisp.mnl (MAJ:steps, MAJ:cmd-silent, MAJ:PrepLoad)
UsesTBL:ShrinkAllTables (dynalisp.mnl), Remote>>Dyl:DrawOrderApply and Remote>>Dyl:DrawOrderRebuild (Draw Order)

Running The Steps

(MAJ:PrepDrawing steps) runs the names of steps, in the order of the file, with CMDECHO 0; c:Dyl-PrepDrawing passes every step of MAJ:steps, Command Optimizer the ones of the column of its command. Each command step goes through MAJ:cmd-silent: the command in a vl-catch-all-apply, then Enter up to four times while CMDACTIVE says it waits, so a step can never hang on a prompt (a keyword another language reads otherwise).

StepRuns
LAYERS_.-LAYER _ON * _THAW * ""
UNHIDE_.UNISOLATEOBJECTS
XREFS_.-XREF _RELOAD *, when MAJ:has-xrefs finds a block that is an xref
DATALINKS_.DATALINKUPDATE _U with a selection of every table, when MAJ:datalink-count finds links: the all data links keyword proved unreliable across versions and languages, so the command never asks for a selection
TABLESTBL:ShrinkAllTables, when it is defined
DRAWORDER, DRAWORDERCLEANWhile auto draw order is on, Remote>>Dyl:DrawOrderApply (or Remote>>Dyl:DrawOrderRebuild, which deletes the draw order tables first) inside one undo mark; *do:busy* is cleared afterwards, since an error leaving it on would stop auto draw order
REGEN_.REGENALL

Loading

The file is autoloaded with its command, like any App. The commands of Command Optimizer need its functions even while Dyl-PrepDrawing is turned off: MAJ:PrepLoad loads it from *dyl:apps\Output the first time MAJ:PrepDrawing is not defined.

Known Limitations

  • c:Dyl-PrepDrawing passes both DRAWORDER and DRAWORDERCLEAN: the rebuild wins.
  • MAJ:PrepDrawingForSave, MAJ:ZoomExtentsAllTabs and the view-state and extents-cache functions (a zoom extents of every layout before a save) are no longer called by anything.
  • A step that fails is silent: MAJ:cmd-silent keeps no error.
