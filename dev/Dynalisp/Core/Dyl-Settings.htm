Settings

The developer docs of Settings: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Resources\dynalisp.mnl (Settings region) and Modules\Dynalisp\Res\Dyl-Settings.dcl

Where The Settings Are

The settings are Windows user settings of AutoCAD (getenv / setenv): DynalispReactors, DynalispSettingsSync, DynalispSetupOn, DynalispSysVarOn, DynalispDisplayOn, DynalispAutoUpdate, DynalispCleanStartup, DynalispRevisionSync, DynalispLanguage, DynalispShrinkGapImperial / Metric... A setting is on only when it is "1", so a setting never saved is off; DynalispLanguage holds English or French. If the reactors keep AutoCAD from starting, turn them off from the command line: (setenv "DynalispReactors" "0"), then open the drawings again.
