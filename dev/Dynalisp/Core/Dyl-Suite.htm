The developer docs of Startup Suite: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Resources\dynalisp.mnl and Resources\Dyl-Suite.dcl

Visual Studio Code

DYL-VSCODE (or Open in VS Code) opens the DynALisp folder in Visual Studio Code, to read or edit the programs. When Visual Studio Code is not found, a window guides the install: Install (winget) installs it with the Windows package manager, Download page opens its download page, Open DynALisp checks again and opens the folder once it is installed.
