Preview Picture

The developer docs of the Preview Picture window of the Start page: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesRes\Dyl-StartPagePreview.xaml (the window, shown by DynALisp.Windows.dll), Installer\Windows\Engine\Frame.cs (dyl:PictureFrame, StartUi.Picture), Installer\Windows\StartPage.cs (Preview), Installer\Windows\Previews.cs (Choose)

The Window

No Lisp runs it: the Start page shows it itself (Session.Show, over AutoCAD with ShowModalWindow, fitted and revealed as every window) when the picture picked for Choose preview picture... differs by more than 1 % from StartUi.PreviewAspect (1.6, the shape of every picture of a drawing on the page). Its value frm is the file of the picture; its Open Docs opens this page on the docs website, in the language of DynALisp.

dyl:PictureFrame (filled by View.Fill) reads the picture with StartUi.Picture (decoded whole, the file left free, turned by its System.Photo.Orientation), shows it Uniform in its box, and draws over it a frame of its Aspect (the rest darkened by an even-odd path), a grip at its corner. Dragging inside moves it, the grip sizes it about its top-left corner, the wheel about its middle (1.1 a notch), a click outside centres it there; it never leaves the picture and never gets smaller than 32 pixels. Each change gives frm/crop, x y width height in the pixels of the picture, to the values; on OK, Previews.Choose cuts it out (CroppedBitmap) before making the picture at most 960 pixels and a PNG.
