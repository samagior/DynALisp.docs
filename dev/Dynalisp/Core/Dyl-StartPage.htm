Start Page

The developer docs of the Start page: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesInstaller\Windows\StartPage.cs (the Start tab, the values, the buttons, Dyl:StartPage and Dyl:StartPageInfo), Installer\Windows\Engine\Start.cs (dyl:RecentDrawings, Page.Of), Modules\Dynalisp\Res\Dyl-StartPage.xaml (the page), in DynALisp.Windows.dll (.NET 8 and .NET 10, both committed)
DataThe user setting DynalispStartPage (Overrides of Dyl-Settings, Dyl:StartPageSet of dynalisp.mnl), read by the plugin itself from FixedProfile\General every second; the Recent File List key of the product key of AutoCAD (then of the profile); %TEMP%\DynALisp Diagnostics\Last startup.txt (the last startup, for the next session); %TEMP%\DynALisp Start\*.png (the pictures of the drawings, by path, date and size); the last %TEMP%\DynALisp Report <date>\Report.txt of Dyl-Diagnostics
FollowsThe Windows convention (a window file without code, its picture drawn by Shots) and the experiments of the Ribbon convention (what is not found is left as it is, and said)

How It Works

  1. Plugin.Initialize of Bridge.cs starts StartPage.Init: a timer on the thread of AutoCAD (every 200 ms, never in a command) that reads DynalispStartPage every second. Dyl:StartPageSet calls (Dyl:StartPage "Apply") so a change saved in Dyl-Settings is read at once, and sets STARTMODE to 1 when it is 0.
  2. The Start tab has no API. StartPage.Find looks in the MDIClient of the main window for the child that holds a browser window (Chrome_WidgetWin_*, CefSharp or WebView2: a drawing holds none), and the child of it the browser is in. Nothing found: the Start tab is left as it is, said by (Dyl:StartPage).
  3. Build opens Res\Dyl-StartPage.xaml with Session.Open (the theme of AutoCAD, DynALisp Neutral included), takes its content with Page.Of (its resources and font, the size its file gives for its picture dropped) and shows it in an HwndSource made a child of the window of the tab (WS_CHILD), at its whole client area. The browser window under it is hidden; the page is hidden with the tab and destroyed with it. Each tick keeps it the size of the tab and first of its children, and the browser hidden.
  4. Each time the tab is shown, Refresh gives the page its values (ver, the cards dyi, sti, sei, dgi as lines label<TAB>value<TAB>state, the buttons greyed out) and calls View.Fill; the recent drawings are read on another thread (File1, File2... of Recent File List, 48 at most, their date and the picture of their header: the PNG, or the BMP made a PNG, from the address at 0x0D of the DWG), then given as rec/rows. A theme changed makes the page again.
  5. The engine shows the cards and the drawings: a plain ItemsControl takes the items of its list (key/list), dyl:RecentDrawings its table key/rows (path, name, folder, when, picture, missing), filtered by its Search box, counted in its Count text.
  6. The buttons are run by the plugin: New (DocumentCollection.Add of the template of QNEW, else acad.dwt or acadiso.dwt by MEASUREINIT), Open... and a drawing clicked (DocumentCollection.Open, a drawing open made current), Settings and Run Diagnostics (Dyl-Settings, Dyl-Diagnostics sent to the current drawing or the first open, greyed out when none is), Open report, and Open Docs through the engine.
  7. The Lisp does not run in the Start tab: Dyl:StartupSummary gives the plugin the startup of each drawing ((Dyl:StartPageInfo ms commands aliases warnings errors steps drawing)), kept in memory and in Last startup.txt for the next session.
  8. Off, the page is destroyed and the browser shown again.

Diagnostics

The Interface section of Dyl-Diagnostics gives DynalispStartPage and STARTMODE, the lines of (Dyl:StartPage) (the setting, what was found, the page, the recent drawings and their key, the last error), a problem when it is on and not shown (the plugin not loaded, STARTMODE 0, the Start tab not found), and while it is on the windows of the MDIClient and the chain of each browser window ((Dyl:StartPage "Tree"), written to %TEMP%\DynALisp Diagnostics\Start page.txt), to adapt Find to another version of AutoCAD.

Limits

  • An experiment past what Autodesk supports: a version of AutoCAD that holds its Start tab another way leaves its own page shown.
  • A drawing saved before AutoCAD 2013 may have only a BMP picture, made a PNG; a DXF has none (a sheet is drawn in its place).
  • The page is in English, as every window of DynALisp.
