Info And User Files

The developer docs of Info And User Files: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesThe Info and UserFiles regions of Resources\dynalisp.mnl, Resources\Dyl-Info.dcl
DataThe AppVersion of PackageContents.xml, CHANGELOG.md, the latest release of *dyl:relrepo*; the User folder
FollowsThe Versions And Updates and User Files conventions

Versions And Updates

  • Dyl:InfoVersion reads AppVersion, the one place the version is kept; Dyl:InfoNewer-p compares two versions.
  • Dyl:InfoCheck reads the latest release of the public releases repository (Dyl:InfoLatest through Dyl:InfoHttp, short timeouts), and keeps *dyl:latest*: (VERSION PAGE-URL SETUP-URL NOTES-URL), or NONE when it could not be read. Once per drawing, when the window opens.
  • What's new (Dyl:InfoWhatsNew, Dyl:InfoNotes) shows the sections of CHANGELOG.md (Dyl:InfoMd reads its Markdown); after an update, Dyl:UpdWhatsNew shows the new ones once.
  • Update to... (Dyl:InfoUpdate) downloads the setup (Dyl:InfoDownload) and starts it (Dyl:InfoRun); the setup waits for AutoCAD to close. Dyl:InfoGit-p tells a git clone, which is never updated this way.
  • Dyl:UpdAuto, a startup step, does it by itself while DynalispAutoUpdate is on, at most once a day (DynalispUpdateChecked).

User Files

  • (Dyl:UserFile path) returns the user copy of a data file when there is one (Dyl:UserPath: the same path under DynALisp.bundle\User), else the default; (Dyl:UserFileW path) the copy to write, made from the default the first time. Dyl:UserDir and Dyl:UserDirW do it for a folder whose files are added and deleted, copied whole and marked by _UserFolder.txt.
  • c:Dyl-UserFiles lists the copies (Dyl:UserItems), resets one (deletes the copy) or makes it the default (copies it under Contents: how an edit is published).
  • Export settings and Import settings (Dyl:SetsExport, Dyl:SetsImport) write and read a DynALisp Settings <date> folder: DynALisp-Settings.txt (every Dynalisp* setting as Name=Value, the local ones of *dyl:setslocal* left out), User\ and Modules\MyTools\; the setup and the uninstall use the same format (Installer\DynALisp.iss).

The Window

c:Dyl-Info loads Dyl-Info.dcl; its list of modules is every module with a docs index, on the website or on this computer (Dyl:DocsFind), and its list of commands is *dyl:core*, the core commands defined.
