Data Links

The developer docs of Data Links: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Cleaning\Dyl-DataLinks.lsp

How It Works

  1. The links are read from the ACAD_DATALINK dictionary of the drawing.
  2. A link is used when a table of the drawing points to it, or when the link lists a table that still exists as one of its users. Both checks are made so that a link is never reported unused by mistake.
  3. The source file is read from the connection string of the link. A relative path is looked up from the drawing folder.
  4. Each delete runs in one undo group: U restores the deleted links.
