Color ByLayer

The developer docs of Color ByLayer: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Cleaning\Dyl-ColorByLayer.lsp
DataNone: the commands keep no setting and write no file.

The Commands

One Apps file, autoloaded: c:Dyl-ColorByLayer (alias CHCOLOR) and its child c:Pst-ChangeColor (alias CC). Both hand the work to AutoCAD's CHPROP, called by its international name as the conventions ask.

CHCOLOR, step by step

  1. (ssget) takes the selection, the objects selected first included.
  2. With a selection: (command "_.chprop" ss "" "_c" "_bylayer"), then the message Objects' color changed to Bylayer.; without: Nothing selected.

CC, step by step

  1. (acad_colordlg 256) opens the color window with ByLayer (256) selected, in a while loop: a cancel returns nil and opens it again.
  2. (ssget) takes the objects, then (command "_.ChProp" ss "" "_C" usercol "") gives them the color number.

Known Limitations

  • The loop on acad_colordlg gives no way out of the window but a color: Esc at the selection prompt ends the command.
  • acad_colordlg returns an index color only; acad_truecolordlg would give true colors and color books.
  • CHPROP skips the objects on locked layers; no undo group is set (each command is one step of UNDO anyway).
