Quick Shape

The developer docs of Quick Shape: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Draw\Dyl-QuickShape.lsp, Remote\Dyl-QuickShapePresets.lsp (its spec), Remote\Dyl-Presets.lsp (the preset engine), Remote\Dyl-Materials.lsp (the hatch, the border box)
DataRes\QuickShape.csv (the presets), the library drawings of Res\Shapes (*qs:folder*, the whole folder copied to User once a shape is added, Dyl:UserDirW), Res\Materials.csv

The Libraries

  • Every .dwg of the shapes folder is a library and every block in it a shape (layouts, xrefs and anonymous blocks excepted), named <Library>|<Block> (Shapes|Stud-2x4). The base point of the block is the insertion point; its Block Units scale it to the drawing.
  • Dyl:QuickShapeDb opens a library: the document when it is open in AutoCAD, else an ObjectDBX document (Dyl:QuickShapeRelease releases it). Dyl:QuickShapeLibs, Dyl:QuickShapeBlocks and Dyl:QuickShapeList list them.
  • Dyl:QuickShapeStarter makes Shapes.dwg when the folder has no library, from the outlines of *qs:starter* (closed polylines in inches; an outline inside another is an island).
  • Dyl:QuickShapeAdd (Add shape from selection...) makes a block of the objects selected in a library (Dyl:QuickShapeDefine, its name asked by Dyl:QuickShapeAskName); Dyl:QuickShapeOpen opens a library to edit it (Open library).

Placing A Shape

(Dyl:QuickShapeRun id) reads the preset (Dyl:QuickShapeGet), gives its border to its material (Dyl:QuickShapeMat), and Dyl:QuickShape brings the block into the drawing when it does not have it, inserts it where the user drags it (point, then rotation), explodes it, fills its closed outlines with Remote>>Dyl:MaterialHatch (islands included) and puts the outlines on the border key, in a loop until Enter or Esc.

The Window

Dyl:QuickShapeDialog is the preset window of the engine, as the one of Quick Draw, with the Shape list and the Border settings box, and no Behaviors: a shape always has its border.
