Hatch Presets

The developer docs of Hatch Presets: its files and how its code works. What it does and how to use it are in its User Guide page.

DataRes\HatchPresets.csv (your copy under User)
FollowsThe Presets And Materials convention: hatch preset in the windows, the messages, the docs, the code and the files

Hatch Presets File

The hatch presets are saved in Res\HatchPresets.csv (semicolons, one hatch preset per row, with a header; the spec HatchPreset). Your changes go to its copy under User; the shipped file under Contents gives the default values (status, Reset Selected, Reset All). The columns, in order: Id, Group, Name, Pattern, Scale, ScaleMetric (no longer used: one scale; kept for the order of the columns), Angle, OutlineKey, HatchKey, Annotative, ScaleDrawing, ScaleRef; the optional settings, each one an ...On column (1: checked) and its value: BorderColor, BorderLinetype, BorderLtScale, BorderLineweight (hundredths of mm, 25 = 0.25 mm), BorderTransparency, HatchColor, Background, HatchLineweight, HatchTransparency; then Associative, NoBorder, BehindBorder (no longer used, kept for the order of the columns), Method, Width, Justify, Sides, ScaleWidth, WidthFactor, OriginOnLine, OriginOffset, ExistingBackgroundOn, ExistingBackground, ShrinkGap (in drawing units), ShrinkGapOn, ShrinkGapMetric (no longer used: an older gap moved to ShrinkGap), OriginAlong, HatchLinetypeOn, HatchLinetype, HatchLtScaleOn, HatchLtScale; then the slots of the bands of Quick Draw Linear and Offset, set in each preset (see Ends and Corners): Ends, EndExtension, EndAngle, Corners, MiterLimit, LapThrough, Joints, HatchFollows; the assembly of Linear (Assemblies): AssemblyOn, Assembly; EndsOn, CornersOn (the ends and corners of its own); Type: Drafting (a size on paper) or Model (a real size: Remote>>Dyl:MaterialFix turns Annotative and ScaleDrawing off, so the hatch is drawn at its scale whatever the drawing scale), Drafting in an older file. An id starting with hp- is a default hatch preset, cu- a custom one. Missing columns get their default value. The spec has (head . 4): a user copy whose header does not begin with Id, Group, Name, Pattern is not read (Remote>>Dyl:PresetFile), so the HatchPresets.csv of DynALisp 1.0 (Type, Key, Pattname..., which nothing read) left in the User folder is ignored, and replaced the first time the hatch presets are saved. The border and behavior columns are no longer edited: they give their border and behaviors to the presets of older files and to the default presets (through the material joined to its hatch preset, see Materials).

The Code

  • Reading – Remote>>Dyl:HatchPresetRead reads the file (after the split of a materials file of DynALisp 1.1 and older, Remote>>Dyl:MaterialMigrate), each row cleaned by Remote>>Dyl:MaterialFix (a G-DS-ANNO-STD-* layer key becomes HATCH); Remote>>Dyl:HatchPresetDefs gives the shipped values, for Reset (read again when the shipped file changes, *hp:defcache*; *hp:defaults* when it cannot be read). The tools never read a hatch preset alone: they read a material joined to it (Remote>>Dyl:MaterialGet).
  • The scale – one scale per hatch preset, in the units of its pattern: Remote>>Dyl:MaterialPatUnits finds them (acad.pat imperial, acadiso.pat metric, ;%UNITS= or ISO / METRIC in the name of a file of its own, Remote>>Dyl:MaterialPatFileUnits), and Remote>>Dyl:MaterialScale converts it (× or ÷ 25.4 by MEASUREMENT) and multiplies it by the drawing scale when it follows it (Remote>>Dyl:MaterialDrawScale).
  • The hatch – Remote>>Dyl:MaterialHatch makes it on its outlines (islands included), on the layer of its key (Remote>>Dyl:LayerKeyLayer), with its overrides (Remote>>Dyl:MaterialProps), its background (Remote>>Dyl:MaterialBackgroundPut, the existing phase background while auto-phase is on in phase E), annotative (Remote>>Dyl:MaterialAnnoPut) and behind its border.
  • The window – Remote>>Dyl:HatchPresetDialog shows Res\Dyl-HatchPresets.xaml, a WPF window of the preset engine ((window . "Dyl-HatchPresets.xaml"), spec HatchPreset; it splits an older materials file first): its list, filter, sort, Show group and several items selected are those of Installer\Windows\Engine\Presets.cs (Windows convention). Its values are the tiles of *mt:tiles*, checked by Remote>>Dyl:MaterialDlgCheck; what they grey out are the rules of the window file (dyl:Win.EnabledBy: pat!= no pattern, pat!=SOLID, typ!=Model), as the DCL dialog did. Before it is shown, Remote>>Dyl:HatchPresetWinPrep reads the patterns of the support path once (Remote>>Dyl:HatchPresetPats: mt:pats, mt:found) and the layer keys (mt:keys); Remote>>Dyl:HatchPresetWinVals gives its lists (pat, typ, hat, hwt), the units of each pattern under the scale and whether a .pat file has it (sunt/by, pfl/by: the text and the open button follow the pattern picked, dyl:Win.ItemsBy="pat"), and what the previews are drawn from. Remote>>Dyl:HatchPresetWinGet turns Annotative and Adaptive scaling off for a Model hatch preset. The Pattern list starts with None, the pattern "": a hatch preset without hatch (hp-Void), kept by the preset engine although its column 3 is empty (blank3 of its spec), never hatched (Remote>>Dyl:MaterialHatchAt) and previewed as a space.
  • Its buttons – each one closes the window with its code, run by Remote>>Dyl:MaterialDlgStatus, then the window opens again on the hatch presets being edited: 5 the Layer Keys window (Remote>>Dyl:LayerKeyPick), 7 Draw legend... (Remote>>Dyl:MaterialLegend), 8 the Preset Groups window (the preset engine), 10 Pick hatch... (Remote>>Dyl:MaterialPickHatch), 11, 12 and 13 the color window of AutoCAD for the hatch color, the background color and the existing phase background (*hp:colorcodes*, Remote>>Dyl:MaterialColorPick: the color picked checks its checkbox), 14 the .pat file of the pattern in Notepad (*hp:patcode*, Remote>>Dyl:MaterialPatOpen). Pick hatch... reads a hatch of the drawing and, when its pattern is on no .pat file of the support path, offers rpat:rebuild-hatch of Rebuild Pattern (turned on and loaded first when it is off, Dyl:SuiteFileOn-p).
  • The previews – a hatch preset is previewed by the Windows plugin, from its .pat file, at its size on paper (the Quick Draw Gallery). In this window the plugin draws it itself from the columns of the hatch preset as they are edited (pst/hatch: pattern, scale, angle, annotative, adaptive scaling, type), with the .pat file and the units of each pattern (pst/pats) and the drawing scale (pst/ds), as Remote>>Dyl:MaterialBand does for the other windows: a Model hatch preset is divided by the drawing scale, a Drafting one keeps its size on paper when it is annotative or adaptive.
