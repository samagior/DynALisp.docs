Hatch Presets

The developer docs of Hatch Presets: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Draw\Dyl-Materials.lsp (command) and Modules\Dynalisp\Remote\Dyl-Materials.lsp (hatch presets, loaded at startup)

Hatch Presets File

The hatch presets are saved in Res\Materials.csv (semicolons, one hatch preset per row, with a header). Your changes go to its copy under User; the shipped file under Contents gives the default values (status, Reset Selected, Reset All). The columns, in order: Id, Group, Name, Pattern, Scale, ScaleMetric (no longer used: one scale; kept for the order of the columns), Angle, OutlineKey, HatchKey, Annotative, ScaleDrawing, ScaleRef; the optional settings, each one an ...On column (1: checked) and its value: BorderColor, BorderLinetype, BorderLtScale, BorderLineweight (hundredths of mm, 25 = 0.25 mm), BorderTransparency, HatchColor, Background, HatchLineweight, HatchTransparency; then Associative, NoBorder, BehindBorder (no longer used, kept for the order of the columns), Method, Width, Justify, Sides, ScaleWidth, WidthFactor, OriginOnLine, OriginOffset, ExistingBackgroundOn, ExistingBackground, ShrinkGap (in drawing units), ShrinkGapOn, ShrinkGapMetric (no longer used: an older gap moved to ShrinkGap), OriginAlong, HatchLinetypeOn, HatchLinetype, HatchLtScaleOn, HatchLtScale; then the slots of the bands of Quick Draw Linear and Offset, set in each preset (see Ends and Corners): Ends, EndExtension, EndAngle, Corners, MiterLimit, LapThrough, Joints, HatchFollows; the assembly of Linear (Assemblies): AssemblyOn, Assembly. An id starting with mt- is a default hatch preset, cu- a custom one. Missing columns get their default value, so a file of an older version still reads.
