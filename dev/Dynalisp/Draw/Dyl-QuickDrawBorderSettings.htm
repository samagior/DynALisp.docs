Border Settings

The developer docs of Border Settings: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Draw\Dyl-QuickDraw.lsp (Dyl:QuickDrawBorderDialog, Dyl:QuickDrawPropsDialog, Dyl:QuickDrawPropsVals, Dyl:QuickDrawBorderText; shared with Hatch Settings), Res\Dyl-QuickDrawBorderSettings.xaml (the window, shown by DynALisp.Windows.dll), Remote\Dyl-Materials.lsp (*mt:bordertiles*, the checks, the layers of an assembly)
DataThe border columns of the preset in QuickDraw.csv (17 to 27, from *qd:border*, in the order of *mt:bordertiles*; No border in 28); for a layer of an assembly, the border field of its layer in QuickDrawAssemblies.csv

The Window

The keys of the window are the border tiles of *mt:bordertiles*: out the layer key (a list, out/vals the keys), then each override, a checkbox and its value: bco bcv the color, blo blt the linetype, bso bsc the linetype scale, bwo bwt the lineweight (bwt/vals, *mt:weights*, in hundredths of a millimeter), bto btr the transparency. Each value is greyed out by its checkbox and checked as it is typed (dyl:Win.Check). sub 1 greys out the open buttons okp (Layer Keys, code 6) and bcp (the color window of AutoCAD, code 11).

In the Quick Draw window, the open button hbe of Has a border (hbr, the inverse of No border) closes it with *mt:borderpick* (12). Dyl:QuickDrawDlgStatus calls (Dyl:QuickDrawBorderDialog r) on the preset shown, which calls Dyl:QuickDrawPropsDialog with the window file and the border tiles of the preset (Remote>>Dyl:MaterialBorderTiles from *qd:border*): Dyl:QuickDrawPropsVals gives the border columns as the values of the keys (the layer keys of mt:keys, a key of the preset not defined added and marked), with sub 0. Codes 6 and 11 keep the values of the window, run Remote>>Dyl:LayerKeyPick or Remote>>Dyl:MaterialColorPick (which checks the color override), and open the window again. On OK each override on is checked with Remote>>Dyl:MaterialDlgCheck and an empty layer key is refused; the columns are then given to every preset selected (Remote>>Dyl:PresetDlgPut). The border tiles stay in *qd:tiles*, without a control in the Quick Draw window: the engine keeps their columns as they are. The summary under Has a border is column 59 of the window (hbi, Dyl:QuickDrawBorderText).

The Assembly Presets window opens the same file itself, on the rows of the layers selected (dyl:Win.Open with dyl:Win.Columns="out:15,bco:17,...,btr:26", see Lists Of Rows), with sub 1 and the lists of Dyl:QuickDrawAsmWinVals; see Assembly Presets for how a layer keeps its border.

When Drawn

Dyl:QuickDrawBorderMake puts the border of a preset on its layer key with Remote>>Dyl:MaterialProps 'border (the border columns of its material, given by Remote>>Dyl:MaterialBorderPut); the border of a layer of an assembly is a list of the same columns (Dyl:QuickDrawLayerBorder), drawn by Dyl:QuickDrawBorderKey. An assembly has no border of its preset (No border, column 31 of its material, set by Dyl:QuickDrawMat).
