Quick Draw

The developer docs of Quick Draw: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Draw\Dyl-QuickDraw.lsp

How It Works

  1. The hatch scale is the scale of the hatch preset, in the units of its pattern: multiplied by 25.4 for an imperial pattern (acad.pat, most pattern files of their own) in a metric drawing (MEASUREMENT = 1), divided by 25.4 for a metric pattern in an imperial drawing (see Hatch Presets).
  2. The layer of the outline layer key is made current (created first with the key properties when the drawing does not have it), then the outlines are made with the Draw with method of the preset (asked first when the preset has none). The current layer is restored afterwards, also when the command is cancelled.
  3. Only closed polylines, circles, ellipses and splines are kept: an open outline that was drawn is erased (a selected one is skipped) and an alert is shown.
  4. The outlines are put on the layer of the outline layer key.
  5. One hatch is created on all the outlines with -HATCH (Select objects), associative or not and annotative or not as set in the hatch preset, using the pattern, scale and angle of the hatch preset (the scale multiplied by the drawing scale divided by the one it was set for, when the hatch preset follows it) (SOLID uses neither scale nor angle). Since the outlines are hatched together, an outline inside another one stays open (island). The hatch is then put on the layer of the hatch layer key (created if missing).
  6. Outlines and hatch are one undo step. If nothing was made, nothing is hatched.
