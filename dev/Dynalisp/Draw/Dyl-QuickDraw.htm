Quick Draw

The developer docs of Quick Draw: its files and how its code works. What it does and how to use it are in its User Guide page.

The Preset Engine

Quick Draw is a preset tool of Remote\Dyl-Presets.lsp: a preset is a list of strings (id group name ...), the first three columns the same for every tool, then the values of the tool (the columns of *qd:tiles*). Remote\Dyl-QuickDrawPresets.lsp adds its spec to *dyl:presetspecs* at startup (file, header, default . "QD-*", base . "Pst-QuickDraw", cmd . "Pst-QuickDrawCustom", get . Dyl:QuickDrawGet, run . Dyl:QuickDrawRun...), so the command of each custom preset, Pst-QuickDrawCustom<Name>, exists before the App loads (a dynamic child, Dyl:DynList). A default preset has its id (qd-Brick) and a command of the App (Pst-QuickDrawBrick); a custom one gets cu-<Name> the first time it is saved, kept when it is renamed.

How It Works

  1. The hatch scale is the scale of the hatch preset, in the units of its pattern: multiplied by 25.4 for an imperial pattern (acad.pat, most pattern files of their own) in a metric drawing (MEASUREMENT = 1), divided by 25.4 for a metric pattern in an imperial drawing (see Hatch Presets).
  2. The layer of the outline layer key is made current (created first with the key properties when the drawing does not have it), then the outlines are made with the Default method of the preset (asked first when the preset has none). The current layer is restored afterwards, also when the command is cancelled.
  3. Only closed polylines, circles, ellipses and splines are kept: an open outline that was drawn is erased (a selected one is skipped) and an alert is shown.
  4. The outlines are put on the layer of the outline layer key.
  5. One hatch is created on all the outlines with -HATCH (Select objects), associative or not and annotative or not as set in the hatch preset, using the pattern, scale and angle of the hatch preset (the scale multiplied by the drawing scale divided by the one it was set for, when the hatch preset follows it) (SOLID uses neither scale nor angle). Since the outlines are hatched together, an outline inside another one stays open (island). The hatch is then put on the layer of the hatch layer key (created if missing).
  6. Outlines and hatch are one undo step. If nothing was made, nothing is hatched.

Drawing A Preset, In The Code

  1. (Dyl:QuickDrawRun id) – reads the preset (Dyl:QuickDrawGet: Dyl:QuickDrawRead, each row fixed by Dyl:QuickDrawFix, a default filled by Dyl:QuickDrawDefault), puts its behaviors and border in its material (Dyl:QuickDrawMat, Remote>>Dyl:MaterialBorderPut), and asks its method when it has none (Dyl:QuickDrawAsk, the last one given kept with setenv).
  2. Dyl:QuickDraw – draws the outline: a standard AutoCAD command run by Dyl:QuickDrawDraw (the user finishes it, the entities after a mark collected by Dyl:QuickDrawAfter), or the DynALisp methods: Linear (Dyl:QuickDrawLinear, the band built from its segments with Dyl:QdBand, Dyl:QdMiter, Dyl:QdCorner, Dyl:QdEnd, a live preview with grdraw: Dyl:QdGrBand), Offset (Dyl:QuickDrawOffsetBands, along a picked curve: Dyl:QuickDrawCurveBand), shrinkwrap (Shrinkwrap).
  3. The hatch – Remote>>Dyl:MaterialHatch fills each closed outline with the pattern, the scale of the drawing (Remote>>Dyl:MaterialScale: the units of the pattern, the drawing scale), the origin and the layer key of the material; Dyl:QuickDrawBorderMake puts the border on its key with its overrides.
  4. An assembly – the layers of the preset (Remote>>Dyl:MaterialLayers, the Assembly column) are placed across the band (Dyl:QuickDrawLayersBand, Dyl:QuickDrawCurveLayers), each Hatch layer hatched as its own preset (Dyl:QuickDrawLayerHatch), each Line layer drawn on its key.

The vector helpers Dyl:QdAdd, QdSub, QdMul, QdCross, QdDot, QdInters, QdBulge... do the 2D geometry of the bands.

The Windows

  • Dyl:QuickDrawDialog – the Quick Draw window, Res\Dyl-QuickDraw.xaml, a preset window of the windows plugin, shown by Remote>>Dyl:PresetWin. Its spec gives:
    • wtiles – the controls that are not in *qd:tiles*: Has a border (hbr, the inverse of the No border column 28), what the hatch is aligned to (mht, hidden: set in the Band Settings window, read by the rules of the hatch origin) and the texts beside the open buttons, read from the columns Dyl:QuickDrawWinExtra adds to each row for the window only: Custom band settings (mbs, column 41, *qd:bandon*), then 42 the layers of an assembly (3 layers), 43 the own justification, ends and corners of the bands (under Custom band settings, shown while it is on, Remote>>Dyl:MaterialBandText), 44 the width of the layers, 45 the preview of an assembly (used while "mas,mth=Linear|Offset|" holds; else the preview is the hatch of the material, Dyl:QuickDrawWinMatSpec).
    • wprep / wvals – Dyl:QuickDrawWinPrep reads the layer keys and the hatch presets of every group before each showing, Dyl:QuickDrawWinVals gives the lists of the window (methods, border layer keys, lineweights) with their stored values (key/vals), so the rules of the file test the values, not the indexes.
    • wprefix – "4|Polyline=PL-|*=QD-": the text of a new alias, PL- for a preset drawn with a polyline (column 4, the method).
    • What is greyed out is in the window file (dyl:Win.EnabledBy on each row: mth=Linear|Offset| for the band settings, the empty value standing for Ask when drawn), and the checks of the text boxes are its dyl:Win.Check, with the messages of Remote>>Dyl:MaterialDlgCheck; Dyl:QuickDrawDlgCheck checks them again before saving.
    • The open buttons close the window with their code, Dyl:QuickDrawDlgStatus opens their window (3 Band Settings, 4 the origin Pick..., 5 Assembly Layers, 6 Layer Keys, 11 the color of the border: Remote>>Dyl:MaterialColorPick) and gives what was picked to every preset selected; 8 Preset Groups and 9 Hatch Presets are run by the engine (Remote>>Dyl:PresetDlgCode). Then the window opens again on the presets being edited.
  • Dyl:QuickDrawBandDialog – the Band Settings window (Res\Dyl-QuickDrawBandSettings.xaml: the justification, the hatch, the ends and the corners, with their sketches; Band Settings).
  • Dyl:QuickDrawLayersDialog – the Assembly Layers window (Res\Dyl-AssemblyLayers.xaml; Assembly Layers).
  • Dyl:QuickDrawGallery – the gallery (Quick Draw Gallery).
