Hatch Presets

The developer docs of Hatch Presets: its files and how its code works. What it does and how to use it are in its User Guide page.

Hatch Presets File

The hatch presets are saved in Res\Materials.csv (semicolons, one hatch preset per row, with a header). Your changes go to its copy under User; the shipped file under Contents gives the default values (status, Reset Selected, Reset All). The columns, in order: Id, Group, Name, Pattern, Scale, ScaleMetric (no longer used: one scale; kept for the order of the columns), Angle, OutlineKey, HatchKey, Annotative, ScaleDrawing, ScaleRef; the optional settings, each one an ...On column (1: checked) and its value: BorderColor, BorderLinetype, BorderLtScale, BorderLineweight (hundredths of mm, 25 = 0.25 mm), BorderTransparency, HatchColor, Background, HatchLineweight, HatchTransparency; then Associative, NoBorder, BehindBorder (no longer used, kept for the order of the columns), Method, Width, Justify, Sides, ScaleWidth, WidthFactor, OriginOnLine, OriginOffset, ExistingBackgroundOn, ExistingBackground, ShrinkGap (in drawing units), ShrinkGapOn, ShrinkGapMetric (no longer used: an older gap moved to ShrinkGap), OriginAlong, HatchLinetypeOn, HatchLinetype, HatchLtScaleOn, HatchLtScale; then the slots of the bands of Quick Draw Linear and Offset, set in each preset (see Ends and Corners): Ends, EndExtension, EndAngle, Corners, MiterLimit, LapThrough, Joints, HatchFollows; the assembly of Linear (Assemblies): AssemblyOn, Assembly; EndsOn, CornersOn (the ends and corners of its own); Type: Drafting (a size on paper) or Model (a real size: Remote>>Dyl:MaterialFix turns Annotative and ScaleDrawing off, so the hatch is drawn at its scale whatever the drawing scale), Drafting in an older file. An id starting with mt- is a default hatch preset, cu- a custom one. Missing columns get their default value, so a file of an older version still reads.

The Code

  • Reading – Remote>>Dyl:MaterialRead reads the file, each row cleaned by Remote>>Dyl:MaterialFix (a G-DS-ANNO-STD-* layer key becomes HATCH); Remote>>Dyl:MaterialGet returns one by id; Remote>>Dyl:MaterialDefs the shipped values, for Reset.
  • The scale – one scale per material, in the units of its pattern: Remote>>Dyl:MaterialPatUnits finds them (acad.pat imperial, acadiso.pat metric, ;%UNITS= or ISO / METRIC in the name of a file of its own, Remote>>Dyl:MaterialPatFileUnits), and Remote>>Dyl:MaterialScale converts it (× or ÷ 25.4 by MEASUREMENT) and multiplies it by the drawing scale when it follows it (Remote>>Dyl:MaterialDrawScale).
  • The hatch – Remote>>Dyl:MaterialHatch makes it on its outlines (islands included), on the layer of its key (Remote>>Dyl:LayerKeyLayer), with its overrides (Remote>>Dyl:MaterialProps), its background (Remote>>Dyl:MaterialBackgroundPut, the existing phase background while auto-phase is on in phase E), annotative (Remote>>Dyl:MaterialAnnoPut) and behind its border.
  • The window – Remote>>Dyl:MaterialDialog, with its list, filter, sort and several items selected (Windows convention): Remote>>Dyl:MaterialDlgInit and MaterialDlgCheck. Pick hatch... reads a hatch of the drawing and, when its pattern is on no .pat file of the support path, offers rpat:rebuild-hatch of Rebuild Pattern (turned on and loaded first when it is off, Dyl:SuiteFileOn-p).
  • The previews – a hatch preset is previewed by the Windows plugin, from its .pat file, at its size on paper (the Quick Draw Gallery): the Lisp gives it the pattern, its file and its scale on paper, by its Type (a Model material is divided by the drawing scale).
