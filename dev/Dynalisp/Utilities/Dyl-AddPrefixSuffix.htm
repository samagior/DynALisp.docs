Add Prefix / Suffix

The developer docs of Add Prefix / Suffix: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-AddPrefixSuffix.lsp

How It Works

  1. Select the objects; only Text and Mtext are kept.
  2. Choose Prefix or Suffix (Enter = Suffix).
  3. Type the string to add; spaces are accepted. An empty string cancels the command.
  4. The string is added to the text contents of each object and the command reports how many were updated. One U undoes the whole change.

The Code

One command, c:Dyl-AddPrefixSuffix: ssget filtered to TEXT and MTEXT, getkword for Prefix/Suffix, getstring with spaces allowed ((getstring T ...)), then the TextString of each object (ActiveX) gets the string before or after it, inside one undo mark. An empty string ends the command.
