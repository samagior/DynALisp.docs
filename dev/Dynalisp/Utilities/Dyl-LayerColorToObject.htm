Layer Color To Object

The developer docs of Layer Color To Object: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-LayerColorToObject.lsp

How It Works

  1. Uses the pre-selected objects, or prompts for a selection (objects on locked layers are left out).
  2. Choose the color mode at Color mode [AsIs/Index/TrueColor/ByLayer]; Enter keeps the last mode of the session (AsIs at first).
  3. Each object gets the color built from its layer (built once per layer), all in one undo step.
  4. The command reports how many objects were changed and how many could not be.
ModeColor applied
AsIsThe layer color exactly as defined: index, true color or color book color.
IndexAn index (ACI) color; for a true color layer, the closest index color stored with the layer.
TrueColorAn RGB true color; index layer colors are converted to their RGB values.
ByLayerReverts the objects to ByLayer.

The Code

c:Dyl-LayerColorToObject takes the selection (lcol:get-selection: the one made first, else a new one without the locked layers), the mode (lcol:get-mode, the last one kept for the session), and runs lcol:process-selection in one undo mark. The color of a layer is built once (lcol:get-layer-data, lcol:build-color, kept by lcol:get-cached-color and freed by lcol:release-cache): an AcCmColor object (lcol:new-color, of the release running) from its TrueColor, its RGB split by lcol:rgb-split.
