Line To Polyline

The developer docs of Line To Polyline: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-LineToPolyline.lsp

How It Works

  1. Answer Join touching polylines? [Yes/No] <No>:.
  2. Select the objects; only lines are kept.
  3. Each line is converted with PEDIT.
  4. With Yes and more than one line, JOIN runs on all the new polylines: the ones that touch end to end become single polylines.

The Code

One command, c:Dyl-LineToPolyline: ssget filtered to LINE, then _.PEDIT on each line (answering Yes to Do you want to turn it into one?, which assumes PEDITACCEPT 0), and _.JOIN on the new polylines when asked.
