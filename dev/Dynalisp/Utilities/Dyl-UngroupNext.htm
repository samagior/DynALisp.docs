Ungroup Nested

The developer docs of Ungroup Nested: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-UngroupNext.lsp

How It Works

  1. Select the objects or groups to ungroup. One pick on any member of a group is enough.
  2. The routine scans every group of the drawing and deletes each group that contains one of the selected objects, printing Ungrouping: <name>.
  3. The scan is repeated until a full pass removes nothing more, then the command confirms that the selection is fully ungrouped.

The Code

One command, c:Dyl-UngroupNext: it walks the ACAD_GROUP dictionary, deletes each group holding one of the objects selected, and walks it again until a whole pass deletes nothing (a group nested in another is found on the next pass).
