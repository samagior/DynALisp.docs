Group Cluster

The developer docs of Group Cluster: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-GroupCluster.lsp

How It Works

  1. Pick two corners of a window (only objects fully inside are kept), or press Enter at the first corner to select objects instead.
  2. Enter the maximum gap between two objects for them to be grouped (default 10 drawing units).
  3. The gap is measured between the bounding boxes of the objects in plan (X/Y only); 0 when the boxes touch or overlap.
  4. Proximity is chained: if A is near B and B is near C, A, B and C go in the same group even when A and C are far apart.
  5. One anonymous group is created per cluster of two or more objects, and the command reports the groups created, the objects left alone and the objects skipped (no bounding box).

The Code

c:Dyl-GroupCluster takes the bounding box of each object (vla-GetBoundingBox), measures the plan gap between two boxes (GC:BBoxGap: 0 when they touch), and joins the objects closer than the gap with a union-find (GC:Find, GC:Union) over every pair. Each cluster of two or more becomes an anonymous group of the Groups collection (GC:SafearrayToList turns the members into a list).
