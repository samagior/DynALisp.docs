Reset Linetype Scale

The developer docs of Reset Linetype Scale: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Utilities\Dyl-ResetLinetypeScale.lsp

How It Works

  1. The routine goes through model space and every layout (external references are skipped).
  2. Each object whose linetype scale (DXF 48) is not 1.0 is set to 1.0, as well as the attributes of block references.
  3. Objects on locked, frozen or off layers are processed too.
  4. The change is one undo step; a REGENALL runs when something changed, and the command reports the number of objects and spaces processed.
