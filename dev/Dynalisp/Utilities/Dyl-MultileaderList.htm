Multileader List

The developer docs of Multileader List: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Utilities\Dyl-MultileaderList.lsp

How It Works

  1. Uses the pre-selected multileaders and blocks, or prompts for a selection.
  2. Each object is keyed on its content:
    • block reference: block name and every TAG=value pair of its attributes;
    • multileader with block content: block name and its attribute values;
    • multileader with text content: the text;
    • anything else: <no content>.
  3. Identical keys are counted together and one line is printed per group, sorted, as content [xN].
  4. A last line gives the total number of objects and of groups.
