Text Fix

The developer docs of Text Fix: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-TextFix.lsp
NeedsDyl:ClaudeRun of DynALisp.Assistant.dll (AutoCAD 2016 or later, see Assistant), Claude Code installed and signed in by the user
SendsThe texts of the objects selected, to Anthropic through Claude Code; nothing is saved

How It Works

  1. c:Dyl-TextFix checks that Dyl:ClaudeRun is defined, then takes the objects selected before the command (right-click menu), else asks for a selection: TEXT, MTEXT and MULTILEADER.
  2. The texts are sent together, one request for at most *ctf:batch-max* texts (40) and *ctf:batch-chars* characters (6000), a longer selection in a few (ctf:batches). Each request is (Dyl:ClaudeRun input system "haiku" schema 180): the input {"texts":["...", ...]}, the instructions *ctf:system-prompt* (correct, never translate, keep terms, codes and lines, one text per text in the same order), the JSON schema *ctf:schema* (an object with a texts array of strings). AutoCAD waits for the answer.
  3. The answer is the JSON of its structured_output, read by ctf:json-strings; a request whose answer has not one text per text sent fails as a whole (its texts counted failed). An error that speaks of a sign-in adds that Dyl-Assistant signs Claude Code in.
  4. When a text changes, the original and the corrected text are shown (Avant / Apres) and the command asks Appliquer la correction ? [Oui/Non/Tous/Quitter] <Oui>: Oui replaces it, Non keeps it, Tous replaces it and every next correction without asking, Quitter stops.
  5. The corrections are written with ActiveX, so objects on locked layers are corrected too. The whole command is one undo step, and a summary gives the objects checked, corrected and failed.

The Code

  • Claude – ctf:correct-texts writes the input (ctf:json-escape), calls Dyl:ClaudeRun and returns (T corrected ...) or (nil error). No API key or token is read or kept: the sign-in is Claude Code's own (the Claude convention).
  • JSON – ctf:json-strings and ctf:json-string-at read the array of the answer (ctf:unicode-to-char for the \uXXXX escapes: any character in AutoCAD 2021 and later, ? outside the code page in an older one).
  • The texts – ctf:get-selection, ctf:text-editable-p, ctf:print-change and ctf:ask-confirmation, then ctf:apply-text through ActiveX; ctf:process-selection runs them in one undo mark.

Dyl-Diagnostics checks Claude Code when Text Fix is turned on (dg:dyl-assistant).
