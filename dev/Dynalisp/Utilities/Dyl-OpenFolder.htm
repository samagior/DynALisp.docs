Open Folder

The developer docs of Open Folder: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Utilities\Dyl-OpenFolder.lsp

How It Works

The command prompts Open folder: [Repository/CurrentDrawing/Template/SheetSet/sUpport] and opens the folder in Windows Explorer:

  • Repository: the DynALisp.bundle folder;
  • CurrentDrawing: the folder of the current drawing;
  • Template: Modules\Dynalisp\Res\Templates\Model;
  • SheetSet: the nearest folder containing a .dst file, searched from the drawing folder up through its parent folders;
  • sUpport (type U): the user Support folder of the AutoCAD running, %APPDATA%\Autodesk\<product>\<language>\Support (ROAMABLEROOTPREFIX): acad.cuix, the copies of partial menus (.cuix) AutoCAD saves there, the user's .pat and .lin files.

A missing folder is reported as Folder not found.
