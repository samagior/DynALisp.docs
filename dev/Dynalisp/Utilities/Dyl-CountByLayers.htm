Count by Layers

The developer docs of Count by Layers: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-CountByLayers.lsp

How It Works

  1. Select lines, arcs, circles, ellipses, polylines and splines (3D meshes and polyface meshes are excluded).
  2. For each object the length is measured; closed objects (closed flag, or start and end points at the same place) also give an area.
  3. Each object gets an Mtext label on its layer, sized to about 35% of the object:
    • open objects: the length, aligned with the object just above its midpoint;
    • closed objects: area and perimeter, centred on the object.
    With INSUNITS set, labels read x ft (y m); in a unitless drawing they show drawing units.
  4. The totals per layer (quantity, length, area, plus metres / feet and m² / ft² when INSUNITS is set) are printed at the command line, with a Total row.
  5. At Output [Table/Csv/None] <None>:, Table inserts an AutoCAD table at a picked point in the current space (text height TEXTSIZE); Csv writes a file, named <drawing>-CountByLayers.csv by default.

The Code

c:Dyl-CountByLayers measures each object with vlax-curve-*, tells a closed one with cbl:closed-p (closed flag, or the same start and end point), labels it with cbl:label (cbl:extents: the size and the place of the mtext, cbl:fmt), totals by layer with cbl:row and cbl:units (the units of INSUNITS, LUPREC), prints them (cbl:print, cbl:line, cbl:pad) and writes cbl:table or cbl:csv.
