Batch Insert

The developer docs of Batch Insert: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-BatchInsert.lsp
RequiresAutoCAD for Windows: the folder browser is BrowseForFolder of Shell.Application

How It Works

  1. Local>>BatchInsertFolder opens the folder browser (option 16: a path can be typed) and returns the folder with its ending backslash, or nil.
  2. The *.dwg files of the folder (vl-directory-files, files only) are sorted by name (acad_strlsort).
  3. The space is paper space when a layout is current with no viewport active (TILEMODE 0, CVPORT 1), else model space. Everything is one undo group.
  4. Each file is inserted with vla-InsertBlock by its full path, scale 1, rotation 0: its block is named after the file. Skipped: the current drawing (DWGPREFIX + DWGNAME), a name that is already a block (inserting would redefine it) or not a valid name (snvalid), and a file that fails to insert (its error printed).
  5. The block is moved so the lower left corner of its bounding box is at (x, 0); x then grows by its width and a gap of a tenth of the widest drawing so far.
  6. The view zooms to the extents and the count of inserted and skipped drawings is printed.
