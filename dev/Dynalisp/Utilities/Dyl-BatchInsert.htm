Batch Insert

The developer docs of Batch Insert: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Utilities\Dyl-BatchInsert.lsp

How It Works

  1. A Windows folder browser opens (Select a folder); the path can be typed in the dialog.
  2. The routine lists the *.dwg files of the folder.
  3. Each file is inserted with -INSERT at scale 1 and rotation 0, the X position being meant to advance by 100 drawing units for each drawing.

The Code

c:Dyl-BatchInsert opens a folder browser (Directory-Dia, BrowseForFolder of Shell.Application) and should run -INSERT for each *.dwg of the folder. The folder picked is not used (the files are listed from a folder written in the code), the point is sent as the text "x,0,0", and the file names have no folder: the three faults of Known Limitations of the guide page.
