Viewport To Paper Space

The developer docs of Viewport To Paper Space: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Utilities\Dyl-ViewportToPaperSpace.lsp

How It Works

  1. Run the command from a layout tab (it refuses to run in model space and switches to paper space if a viewport is active).
  2. Choose the result mode at Mode de resultat [Decouper/Libre]; the last choice is the default:
    • Decouper (clip, default) – the copies are grouped in a block (VP2PS_ prefix) clipped with the viewport boundary, so the result looks exactly like the viewport;
    • Libre (free) – the copies are loose objects in paper space and objects crossing the viewport edge are not trimmed.
  3. Select the viewports to convert (the paper space viewport itself is excluded).
  4. Model space objects are collected once. For each viewport the objects on visible layers are copied and transformed with the viewport scale, view centre and twist angle; rectangular and clipped viewports are supported.
  5. With PSLTSCALE = 0 linetype scales are adjusted to keep dash lengths; dimensions keep their displayed value and size.
  6. Each converted viewport is deleted. Layers temporarily unlocked are relocked, the drawing is regenerated and a report gives the number of viewports and objects converted. The whole operation is one UNDO group.
