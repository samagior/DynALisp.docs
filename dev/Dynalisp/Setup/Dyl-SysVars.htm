System Variables

The developer docs of System Variables: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Setup\Dyl-SysVars.lsp (window) and Modules\Dynalisp\Remote\Dyl-SysVars.lsp (profiles and override, loaded at startup)

How It Works

  • A value is read as the type of the current value of its variable: a whole number (PICKADD 2), a number (LTSCALE 1.5), a text, or a point written x,y or x,y,z.
  • Each drawing opened sets the protected variables and those of the active profile that differ, without marking the drawing as modified; the window shows what differs. A profile saved, or System variables turned on, in another drawing applies to the drawings already open when you switch to them, while Settings sync is on.
  • The profiles are the CSV files of Modules\Dynalisp\Res\SysVars (Variable;Value, one variable per row). Saved profiles go to User\Modules\Dynalisp\Res\SysVars (see Dyl-UserFiles). The Default profile is empty. The protected variables are Modules\Dynalisp\Res\SysVarsProtected.csv (Variable;Value, an empty value: protected only), saved to its copy under User.
