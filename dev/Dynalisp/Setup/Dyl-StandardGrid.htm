Standard Grid

The developer docs of Standard Grid: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Remote\Dyl-DrawingSetup.lsp (the presets and the check of each drawing, loaded at startup), Modules\Dynalisp\Apps\Setup\Dyl-StandardGrid.lsp (the commands)
DataThe grid and snap system variables of the current viewport; the user settings DynalispGridImperial, DynalispGridMetric (a preset key, "": not checked) and DynalispSetupOn
Shared withSet Units (the same Remote file and the same check of every drawing), the Drawing Settings window of Dyl-Settings

The Presets

*ds:grids* holds each preset as (key label (snap grid) (snap grid) major): the spacings in inches for the imperial drawings, in millimeters for the metric ones (MEASUREMENT), and the grid lines per major line. Remote>>Dyl:GridValues returns (snap grid major) in the units of the drawing.

How It Works

The command reads MEASUREMENT (0 = imperial, 1 = metric), sets the snap spacing, the grid spacing and the number of grid lines per major line, then turns the grid on:

CommandImperial snap / gridMetric snap / gridMajor line every
GRID-IN1/8″ / 1/4″3.175 / 6.354 lines (1″)
GRID-FT1/8″ / 1″3.175 / 25.412 lines (1′)
GRID-CM0.0394 / 0.07871 / 25 lines (1 cm)
GRID-M0.9843 / 3.937025 / 10010 lines (1 m)

It also sets SNAPTYPE to grid snap, AUTOSNAP to 15 and turns ORTHOMODE off.

The Commands

  • Each child, c:Pst-GridInch, c:Pst-GridFoot, c:Pst-GridCentimeter, c:Pst-GridMeter, is (sg:apply key): (Remote>>Dyl:GridApply key), then the label is printed.
  • Remote>>Dyl:GridApply sets SNAPUNIT and GRIDUNIT (the same spacing in X and Y), GRIDMAJOR, GRIDMODE 1, SNAPTYPE 0 (grid snap), AUTOSNAP 15 and ORTHOMODE 0.
  • c:Dyl-StandardGrid is Dyl:ChildPicker of dynalisp.mnl, as Set Units; *sg:last* keeps the grid picked last.

Every Drawing

Remote>>Dyl:SetupWatch checks the grid with the units (see Set Units): Remote>>Dyl:Grid-p compares SNAPUNIT, GRIDUNIT (fuzz 1e-6) and GRIDMAJOR with the preset, and GridApply runs when they differ.

Using It In An App

CallDoes
(Remote>>Dyl:GridApply "Inch")Sets the grid of a preset in the current viewport.
(Remote>>Dyl:Grid-p "Inch")T when the current viewport has it.

Known Limitations

  • AUTOSNAP 15 keeps the marker, the tooltip, the magnet and polar tracking, and turns object snap tracking (16) and its tooltips (32) off.
  • The snap and grid variables belong to the current viewport: the other viewports keep theirs, and the check of a drawing looks at the one current when it opens.
