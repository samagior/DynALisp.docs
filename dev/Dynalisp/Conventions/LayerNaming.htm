Layer Naming

The developer docs of Layer Naming: its files and how its code works. What it does and how to use it are in its User Guide page.

ListsModules\Dynalisp\Res\AEC\Standard: Dd1.csv, Dd2.csv (the discipline designators), Major.csv, Minor.csv, Phase.csv (the status), UTF-8 with a BOM, a Description.<code> column for each other language
Read byLayer Phase, Layer Transfer and its drop-downs, Layer Filter, Layer Groups, Draw Order, the layer keys

How The Tools Read A Name

ToolWhat it reads
Layer TransferThe Level transfers (the ribbon drop-downs and LTF) split the name into a designator of 1 or 2 letters, a major group, its minor groups and a status of 1 character, and replace one of them. The phase transfers (E-D, D-N...) replace or add the status.
Layer PhaseThe status: counts the layers of each phase, shows or hides them, and moves the current layer and the new objects to the active phase.
Layer KeysThe unphased layer of each key, to which the active phase is added (A-Detl-Thin → A-Detl-Thin-E).
Layer FiltersWildcards on the fields: A-* for architecture, *-E and *-X for existing, *-@@?? for the unphased layers (a name ending with a group), *-0001 … *-0009 for the stacks, *-Dims*, *-Text*... for the annotation (see its Tokens).
Make LayersBuilds each name from the Designator, Major and Minor columns of its lists, and gives the layer a color, lineweight and linetype from its codes.

The Readers In The Code

FunctionReads
Dyl-LayTransfer-Ncs (Layer Transfer), NcsName (TransferCombos.cs)The fields of an NCS name, (discipline major (minor ...) status): the same rule on both sides, changed together.
Remote>>Dyl:PhaseOf, PhaseBase (Layer Phase)The status of a name, its last field when it is one character of Phase.csv.
Remote>>Dyl:PhaseListPhase.csv, the description in the language of the AutoCAD installed.
Host.Standard (Plugin.cs)The lists, for the drop-downs of the ribbon (a field in quotes may hold a comma).
The tokens of Dyl-LayerFilter (Layer Filter)Wildcard patterns on the fields: *-@@?? for an unphased name, *-0001 for a stack...

The other Lisp readers of these files read their columns by position and keep the English ones (the Ribbon convention on translated data files).
