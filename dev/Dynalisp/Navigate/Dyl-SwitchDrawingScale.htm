Switch Drawing Scale

The developer docs of Switch Drawing Scale: its files and how its code works. What it does and how to use it are in its User Guide page.

Source Files Modules\Dynalisp\Apps\Navigate\Dyl-SwitchDrawingScale.lsp

How It Works

  1. MEASUREMENT = 1 (metric) selects the metric scale name, otherwise the imperial name.
  2. CANNOSCALE is set to that name.
  3. If the scale is not in the list, its name is parsed into paper and drawing units (feet, inches and fractions down to 1/64" are supported), the ratio is reduced, the scale is added with -SCALELISTEDIT, and CANNOSCALE is set again.
  4. The active viewport is regenerated quietly and the new scale is reported.
