Switch Drawing Scale

The developer docs of Switch Drawing Scale: its files and how its code works. What it does and how to use it are in its User Guide page.

Source FilesModules\Dynalisp\Apps\Navigate\Dyl-SwitchDrawingScale.lsp
DataThe CANNOSCALE of the drawing and its scale list; the units come from MEASUREMENT

The Presets

Each scale is a child command, c:Pst-DrawingScale1-<ratio>, run by its alias (1-100). Each one sets three global variables, then calls Dyl-SetDrawingScale:

(defun c:Pst-DrawingScale1-100 ()
  (setq fti "1/8\" = 1'-0\""   ; the scale name in an imperial drawing
        meq "1:96"            ; the ratio of the imperial scale
        met "1:100"           ; the scale name in a metric drawing
  )
  (Dyl-SetDrawingScale)
)

The file has two regions of presets, metric (named after the metric ratio) and imperial (named after the imperial ratio, 1-48); a new scale is one more child command of that form.

Setting A Scale, Step By Step

  1. Dyl-SetDrawingScale takes met when MEASUREMENT is 1 (metric), else fti.
  2. It sets CANNOSCALE to that name, in a vl-catch-all-apply: AutoCAD refuses a name that is not in the scale list of the drawing.
  3. When it is refused, Dyl-EnsureAnnoScale adds the scale:
    • a name "N:M" gives its two numbers; a name "paper = drawing" gives two lengths read by Dyl-ParseFtInches (N', N'-M", A", A/B", A B/C", in decimal inches);
    • both are multiplied by 64, so the smallest fraction (1/64") becomes a whole number, and reduced by their greatest common divisor (Euclid);
    • (command "_.-SCALELISTEDIT" "_A" name "n1:n2" "_E") adds it.
    Then CANNOSCALE is set again; when it is still refused, the command says so.
  4. Dyl-QuietRegen regenerates the active viewport through ActiveX with NOMUTT 1 (no Regenerating model line), and the scale is printed.

The Main Command

  • c:Dyl-SwitchDrawingScale prints CANNOSCALE and asks for a ratio with getstring; ? prints the list, again until another answer.
  • Dyl-DrawingScaleList finds the presets defined, without a list to keep up to date: every symbol of (atoms-family 1) matching C:PST-DRAWINGSCALE1-#* that is a defined function, sorted by ratio.
  • Dyl-DrawingScaleCmd reads 100, 1:100, 1-100 or 1/100, and returns the symbol of its preset when it is defined; the command runs it with (eval (list sym)).

The Ribbon

The Switch Drawing Scale button of the Navigate panel lists, under its arrow, the presets picked in Installer\Ribbon\Ribbon.csv (twelve of them: too many for one list), and follows the one picked last (SplitFollow, see the Ribbon convention).

Known Limitations

  • fti, meq and met are global variables, not locals of the presets; meq is set but not read.
  • The imperial name of Pst-DrawingScale1-384 is 1" = 1'-0", not 1/32" = 1'-0".
  • CANNOSCALE of a layout is the scale of paper space: the command never changes the scale of a viewport.
