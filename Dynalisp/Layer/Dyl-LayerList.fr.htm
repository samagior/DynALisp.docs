Liste des calques dessinée (Layer Drawing List)

Syntaxe DYL-LAYERLIST
Licence Licence publique générale GNU v3

Description

Dessinez une légende des calques dans le dessin : pour chaque calque, une ligne dessinée sur ce calque avec son nom et sa description au-dessus. Pratique pour garder une trace d'une norme de calques ou faire une feuille de normes.

Utilisation

  1. Tapez Dyl-LayerList et choisissez le point de la première rangée.
  2. Choisissez All (chaque calque du dessin, par défaut) ou Select (les calques des objets que vous sélectionnez).
  3. Une rangée par calque est dessinée, chacune sous la précédente : la ligne dans la couleur et le type de ligne du calque, son nom et sa description.

Commandes

CommandeNomDescription
DYL-LAYERLISTLayer Drawing ListDessine une ligne et une étiquette avec la description de chaque calque du dessin ou de la sélection.

Limites connues

  • Les tailles sont des unités de dessin fixes, non mises à l'échelle d'annotation.
  • Avec Select, les calques sont listés dans l'ordre de sélection, non triés.
  • Le texte utilise le style de texte courant.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
