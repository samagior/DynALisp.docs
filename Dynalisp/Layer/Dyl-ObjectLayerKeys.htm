Object Layer Keys

Function Syntax DYL-OBJECTLAYERKEYS
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Put each common kind of object on its own layer, whatever the current layer, as the layer keys of AutoCAD Architecture do: a dimension goes to the layer of the DIMLINE key, a text to the layer of ANNOBJ, a revision cloud to ANNREV...

How To Use

  1. In Dyl-Settings, check Auto layer keys (in Reactors); it needs the DynALisp reactors on.
  2. Draw as usual: each new dimension, leader, text... goes to the layer of its key when its command ends.
  3. To change which key a kind uses, type Dyl-ObjectLayerKeys (or click the open button of Auto layer keys), pick the kind and its key, then OK. No key: the objects of that kind stay on the current layer.

Object Layer Keys Window

  • List – each kind of object, its layer key ((none): left on the current layer) and the layer it gives in this drawing (in the active phase while auto-phase is on; created when used when the drawing does not have it yet). Several kinds can be selected (Ctrl / Shift click) to give them one key at once.
  • Layer key – the key of the kinds selected, picked among the layer keys; (None: the current layer) leaves them as AutoCAD draws them. The square open button beside it opens the Layer Keys window: edit the keys there, or double-click one to give it to the kinds selected (the keys are saved, then this window opens again).
  • Reset Selected / Reset All – the default keys of the kinds selected, or of every kind.
  • Under the buttons, whether Auto layer keys is on. OK saves the keys, Cancel discards the changes, Open Docs opens this page.

Known Limitations

  • Auto layer keys needs the DynALisp reactors (Dyl-Settings).
  • Objects drawn with a Lisp command of another program are not moved.
  • ObjectLayerKeys.csv cannot be saved while it is open in Excel: an alert is shown and the changes are lost.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
