Object Layer Keys

Function Syntax DYL-OBJECTLAYERKEYS
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Each kind of object goes to its own layer by itself: dimensions on the dimension layer, texts on the notes layer, revision clouds on the revisions layer.

How To Use

  1. In Dyl-Settings, turn on Auto layer keys.
  2. Draw as usual.
  3. To choose the layer of a kind, type Dyl-ObjectLayerKeys, pick the kind and its layer key.

Default Layers

ObjectsLayer
Dimensions, tolerancesG-Anno-Dims
Leaders, multileaders, textsG-Anno-Note
TablesG-Schd
Revision cloudsG-Anno-Revs
HatchesA-Detl-Patt
WipeoutsG-Anno-Mask
ViewportsG-View-Nplt
ImagesThe current layer

Known Limitations

  • Objects drawn by some other add-ons stay where they are.
