Make Layers

Function Syntax DYL-LAYERMAKE and 11 layer sets – see Commands
Licence GNU General Public License v3; CSV helpers by Lee Mac

Program Description

Make the whole set of layers of a type of drawing in one command: a basic drawing, an architectural plan, elevation, section or detail, or the NCS layers of one level. Each layer gets its name, color, lineweight, linetype, plot setting and description from the DynALisp layer standard; the layers already there are updated.

How To Use

  1. Type the alias of the set: LL-A-FLOOR for an architectural floor plan... (the table below), or type Dyl-LayerMake and double-click a set.
  2. Answer the questions of the set at the command line, only those it needs:
    • the stack of a stacked drawing: None, or 1-First... 9-Ninth, which ends the names with 0001... 0009;
    • the discipline: General, Architectural, Interior, Structural or Landscape;
    • the major group, 4 characters (Detl by default, Wall, Roof...).
  3. The command line lists each layer, created or updated, then their count. The current layer does not change, and one U undoes it all.

Commands

CommandNameLayers made
LL-BASICDRAWINGMake Basic Drawing LayersThe line layers (fine, thin, medium, wide, hidden, patterns...) of the discipline and major group you choose.
LL-A-ELEVMake Architectural Elevation LayersThe elevation lines and the annotation, of a stack.
LL-A-SECTMake Architectural Section LayersThe same layers as the elevations.
LL-A-DETLMake Architectural Detail LayersThe detail lines of the major group you choose (membranes, insulation, rebar...) and the annotation.
LL-A-FLOORMake Architectural Floor Plan LayersWalls, doors, glazing, columns, floors and equipment, and the annotation.
LL-A-ROOFMake Architectural Roof Plan LayersThe roof layers and the annotation.
LL-A-CEILMake Architectural Ceiling Plan LayersThe ceiling (grid, lights, HVAC, openings...), the walls, doors and glazing it shows, and the annotation.
LL-A-FURNMake Architectural Furniture Plan LayersThe furniture, the floor plan layers and the annotation.
LL-NCS1Make NCS Level 1 LayersThe level 1 layers of the US National CAD Standard, every discipline.
LL-NCS2Make NCS Level 2 LayersThe level 2 layers, every discipline.
LL-NCS3Make NCS Level 3 LayersThe level 3 layers, every discipline (level 2 for interiors and plumbing).

The names follow the Layer Naming standard.

Known Limitations

  • The color, lineweight and linetype of each layer come from the words of its name: they cannot be chosen here. Change them afterwards, or use the Layer Keys.
  • A layer already in the drawing gets the properties of the standard back, its own changes lost.
  • A linetype missing from the linetype file of AutoCAD gives the layer Continuous.
  • The NCS sets make several hundred layers: it takes a moment.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-LayerMake: they are run by their alias, or picked from Dyl-LayerMake when it lists them (their command is named Pst-*).
