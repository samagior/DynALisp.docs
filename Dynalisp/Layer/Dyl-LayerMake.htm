Make Layers

Function Syntax DYL-LAYERMAKE and 11 layer sets – see Commands
Licence GNU General Public License v3; CSV helpers by Lee Mac

Program Description

Make all the layers of a type of drawing in one command: plan, elevation, section, detail or NCS. Each one follows the Layer Naming standard.

How To Use

  1. Type a set, LL-A-FLOOR for a floor plan (the list below), or Dyl-LayerMake to pick one.
  2. Answer its questions: the stack, the discipline, the group.
  3. One U undoes it.

Known Limitations

  • A layer already there gets the properties of the standard back.
  • The NCS sets make hundreds of layers: it takes a moment.
