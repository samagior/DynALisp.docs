Make Layers

Function Syntax DYL-LAYERMAKE and 11 layer sets – see Commands
Source File Modules\Dynalisp\Apps\Layer\Dyl-LayerMake.lsp
Status Work in progress – see Known Limitations
Licence GNU General Public License v3; CSV helpers by Lee Mac

Program Description

DYL-LAYERMAKE lists every layer set with its alias: double-click one (or OK) to create its layers. The layer sets are child commands (Pst-*) run by their aliases, which can be added, renamed or removed in Dyl-Suite (see Command Names And Aliases).

Builds a set of layers from CSV layer lists: the layer names are assembled from the name fields of each row, then the colour, lineweight, linetype and plot setting are derived from the name with the Dynalisp layer rules. Existing layers are updated, missing ones created.

CSV folders are relative to Modules\Dynalisp\Res\Layer\List. Each CSV has the columns Designator, Major, Minor1, Minor2, Minor3, Description.

How It Works

  1. The rows of every CSV of the preset are read (header skipped).
  2. If a row contains the stack placeholder 0000, you are asked for the stack (None, 1-First … 9-Ninth) which replaces it with 0001 … 0009.
  3. If a row contains the discipline placeholder $$, you are asked for the discipline (General, Architectural, Interior, Structural, Landscape) which replaces it with its letter.
  4. The name fields are joined with hyphens to make the layer name; the Description column becomes the layer description.
  5. Properties are derived from the name:
    • colour: 151 by default, then fixed colours by keyword (e.g. Eqpm 1, Plnt 81, Note/Mark 122, Dims/Grid 221, Text 41, Scrn 8, Exst 9, Redl true colour 255,0,0; elevation layers have their own colours);
    • lineweight: from the last digit of the colour number – 0 → 0.13, 1 → 0.18, 2 → 0.25, 3 → 0.35, 4 → 0.50, 5 → 0.70, 6 → 1.00, 7 → 1.40, 8 → 2.00, 9 → 0.13 mm (grey colours always 0.13);
    • linetype: Continuous, or Center/Hidden/Phantom (and their 2 variants) for Cntr, Hdln, Phnt, Grid, Labl, Tags … layers;
    • plot: off for Nplt and Rdme layers.
  6. Each layer is made or updated with -LAYER and the command line shows ...<layer> - created or - updated.

Known Limitations

  • The discipline check passes the whole CSV data list to wcmatch, which only accepts text, so the commands currently stop with a bad argument type error at that step.
  • Rows without the 0000 placeholder produce no layer name (the name is only built inside the stack substitution).
  • Several CSV names do not match the shipped files (e.g. A-Elev.csv vs A-Elevation.csv, folder NCS vs NCSv5); missing files are skipped silently.
  • The colour group option (MinorColor, DesignatorColor, MajorColor, StackColor, PhaseColor) is fixed to MinorColor, which adds no override.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-LayerMake: they are run by their alias, or picked from Dyl-LayerMake when it lists them (their command is named Pst-*).
