Importer des filtres de calques (Import Layer Filters)

Syntaxe LFIMP, LFLIST, IMPORTLAYERFILTER
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Copiez les filtres de calques d'un autre dessin, gabarit ou fichier de normes dans le dessin courant, avec leurs filtres imbriqués. L'autre fichier est seulement lu, jamais modifié, et aucun calque n'est importé : seulement les filtres.

Utilisation

  1. Tapez LFIMP et choisissez le dessin, le gabarit ou le fichier de normes à copier.
  2. Son arbre des filtres s'affiche à la ligne de commande. Tapez les noms des filtres à importer (caractères génériques et virgules permis), ou appuyez sur Entrée pour tous.
  3. Quand un nom est déjà utilisé dans le dessin, choisissez Overwrite, Skip (par défaut) ou Rename (un suffixe _1, _2...).
  4. La ligne de commande donne ce qui a été importé, remplacé, renommé ou sauté. Un U l'annule.
  5. LFLIST affiche l'arbre des filtres du dessin courant.

Commandes

CommandeNomDescription
LFIMPImport Layer FiltersImporte les filtres de calques d'un autre dessin dans le dessin courant.
LFLISTList Layer FiltersListe l'arborescence des filtres de calques du dessin courant à la ligne de commande.
IMPORTLAYERFILTERImport Layer Filters (Alias)Alias de LFIMP qui importe les filtres de calques d'un autre dessin.

Limites connues

  • Les filtres de groupe ne sont pas importés (ils désignent les calques par leur identificateur, qui n'existe que dans la source); tout ce qui est imbriqué sous un filtre de groupe est sauté aussi.
  • Les dessins qui ne contiennent que des filtres de calques antérieurs à 2005 doivent d'abord être ouverts et enregistrés dans un AutoCAD récent.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite. Les rangées marquées ↳ sont ses variantes, lancées par leur nom court.

CommandeAliasNom
Dyl-LayerImportFiltersFromDwgLFIMP, IMPORTLAYERFILTERImport Layer Filters

Notes du programme d'origine (en anglais) 
;;; ==========================================================================
;;; ImportLayerFilters.lsp
;;;
;;; Imports layer property filters from a selected source drawing into the
;;; current drawing.
;;;
;;; Scope:
;;;   - Layer property filters (AcLyLayerFilter), including their nested
;;;     property filters (hierarchy is preserved).
;;;   - Layer group filters (AcLyLayerGroup) are NOT imported: they reference
;;;     layers by handle, which only make sense in the source drawing. Anything
;;;     nested under a group filter is therefore skipped as well.
;;;   - Layers themselves are NOT imported, only the filter definitions.
;;;   - The source drawing is never modified.
;;;
;;; Commands:
;;;   LFIMP              - import filters from a source drawing
;;;   IMPORTLAYERFILTER  - alias of LFIMP
;;;   LFLIST             - list the filter tree of the current drawing
;;;
;;; Storage (undocumented by Autodesk, observed):
;;;   Layer table > extension dictionary > ACLYDICTIONARY
;;;     XRECORD: (1 . "AcLyLayerFilter") (90 . 1) (300 . name) (301 . expr)
;;;   Nested filters: extension dictionary of the parent XRECORD
;;;     > ACLYDICTIONARY > XRECORD ...
;;;   Data is copied as-is (minus pointers), so any extra group codes used
;;;   by a given AutoCAD version are preserved.
;;;
;;; Duplicate names (checked against the whole current filter tree):
;;;   Overwrite - the existing filter (and its nested filters) is deleted,
;;;               then replaced by the source filter.
;;;   Skip      - the source filter (and its nested filters) is not imported.
;;;   Rename    - the source filter is imported with a _1, _2, ... suffix.
;;;
;;; Notes:
;;;   The source is read through ObjectDBX, or directly if the drawing is
;;;   already open in the session.
;;;   The Layer Properties Manager is closed before writing: if left open,
;;;   it could rewrite the filter tree from its in-memory copy and wipe out
;;;   the imported filters.
;;;   The operation is recorded as a single UNDO group.
;;; ==========================================================================
