Importer des filtres de calques (Import Layer Filters)

Syntaxe LFIMP, LFLIST, IMPORTLAYERFILTER

Description

Copiez les filtres de calques d'un autre dessin ou gabarit dans le vôtre. Rien d'autre ne vient avec eux.

Utilisation

  1. Tapez LFIMP et choisissez le fichier.
  2. Tapez les filtres à amener, ou appuyez sur Entrée pour tous.
  3. Pour un nom déjà pris, choisissez Overwrite, Skip ou Rename.
  4. LFLIST liste les filtres de votre dessin.

Limites connues

  • Les filtres de groupe ne sont pas copiés.
  • Un très vieux dessin doit d'abord être enregistré dans un AutoCAD récent.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite. Les rangées marquées ↳ sont ses variantes, lancées par leur nom court.
