Exporter les calques en CSV (Export Layers To CSV)

Syntaxe DYL-LAYEREXPORTTOCSV
Fichier source Modules\Dynalisp\Apps\Layer\Dyl-LayerExportToCsv.lsp
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Écrit chaque calque du dessin courant et ses propriétés dans un fichier CSV qui s'ouvre directement dans Excel. Le fichier utilise les mêmes colonnes que les préréglages de calques que lit Import Layers From CSV : un export peut donc être modifié et réimporté dans un autre dessin.

Commandes

CommandeNomDescription
DYL-LAYEREXPORTTOCSVExport Layers To CSVExporte chaque calque du dessin avec ses propriétés dans un fichier CSV du dossier Téléchargements.

Fonctionnement

  1. Le fichier de sortie est %USERPROFILE%\Downloads\layers_YYYYMMDD.csv; si USERPROFILE n'est pas défini, HOMEDRIVE + HOMEPATH est utilisé, et en dernier recours le dossier du dessin.
  2. Chaque calque de la table des calques est lu (calques dépendants des xréfs compris) et ses valeurs sont converties en texte lisible (voir le tableau ci-dessous).
  3. Les rangées sont triées par nom de calque, sans tenir compte de la casse.
  4. Le fichier est écrit en UTF-8 avec BOM (pour Excel) et une rangée d'en-tête; les valeurs qui contiennent des virgules, des guillemets ou des sauts de ligne sont entre guillemets.
  5. La commande indique le nombre de calques et le chemin complet du fichier.

Colonnes du CSV

ColonneValeurs écrites
Layer NameNom du calque
ColorRed (1) … White/Black (7), ACI n, ByLayer, ByBlock
Lineweight0.25 mm, Default, ByLayer, ByBlock
LinetypeNom du type de ligne
PlotYes / No
Transparency0% … 90%
On/OffOn / Off
FreezeFrozen / Thawed
New VP FreezeVP Frozen / VP Thawed
DescriptionDescription du calque

Limites connues

  • Le nom du fichier ne contient que la date : un second export le même jour remplace le premier.
  • Les couleurs vraies sont exportées comme leur couleur d'index la plus proche.
  • Le message de chargement mentionne EXPORTLAYERS; le nom de la commande est DYL-LAYEREXPORTTOCSV.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
