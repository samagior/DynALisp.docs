Program Description

Applies layer properties stored in a CSV file to the layers of the current drawing. The preset commands load a named CSV for a type of plan and save the result as a named layer state, so the setup can be restored later; IMPORTLAYERS lets you browse for any CSV. The CSV format is the one written by Export Layers To CSV.

How It Works

Preset commands

  1. The preset CSV is looked up in the program folder. If it is missing, a file dialog opens instead.
  2. If the layer state of the preset already exists in the drawing, you choose U (restore the existing state, CSV ignored), I (apply the CSV and overwrite the state) or C (cancel).
  3. Otherwise the CSV is applied and the layer state is created.
  4. All viewports are regenerated.

Applying a CSV

  1. The header row and any UTF-8 BOM are skipped; quoted fields are supported.
  2. Each row is matched to an existing layer by name (case-insensitive). Layers that are not in the drawing are not created: they are counted and listed as MISSING.
  3. Colour, lineweight, linetype, plot, transparency, on/off, freeze, new viewport freeze and description are applied. A missing linetype is loaded from acad.lin / acadiso.lin; if it cannot be found, the layer keeps its linetype and a note is printed.
  4. A summary gives the number of layers updated and missing.

Known Limitations

  • The program folder is found by searching for import_layers_from_csv.lsp, a file name that does not exist in the bundle, so presets are looked up in the drawing folder and the file dialog opens in most cases.
  • Only preset_arch_floor.csv is shipped (in Modules\Dynalisp\Res); the other presets have no CSV yet.
  • Colours are read as index colours (Red (1), ACI 151, 151); true colours are not supported.

Bundled program notes 
;; ============================================================
;; IMPORT-LAYERS-FROM-CSV  (Dedicated preset commands)
;;
;; Each command loads a named CSV from the same folder as this
;; LSP, applies all layer properties to matching layers, then
;; manages a named Layer State in the drawing.
;;
;; COMMANDS:
;;   A-FLOR  - Architectural Floor Plan
;;   A-CEIL  - Architectural Ceiling Plan
;;   A-ROOF  - Architectural Roof Plan
;;   I-FURN  - Interior Furnishing Plan
;;   I-FNSH - Interior Finish Plan
;;   L-PLNT  - Landscape Plantings Identification Plan
;;   C-FLOR  - Civil Property Plan
;;   S-FLOR  - Structural Floor Plan
;;   E-FLOR  - Electrical Floor Plan
;;   P-FLOR  - Plumbing Floor Plan
;;   M-FLOR  - Mechanical Floor Plan
;;   IMPORTLAYERS - Browse for any CSV (no layer state)
;;
;; Preset CSV files must live in the same folder as this LSP.
;; CSV format matches the EXPORTLAYERS companion routine:
;;   Layer Name,Color,Lineweight,Linetype,Plot,Transparency,
;;   On/Off,Freeze,New VP Freeze,Description
;; ============================================================
