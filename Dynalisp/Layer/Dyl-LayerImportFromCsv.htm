Import Layers From CSV

Function Syntax 12 commands – see Commands
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Apply the layer properties of a CSV file to the layers of the drawing: colors, lineweights, linetypes, plot, transparency, on/off and freeze. A preset command does it for one type of plan and saves the result as a layer state, to restore it later. The file is the one Export Layers To CSV writes.

How To Use

  1. Any file – type IMPORTLAYERS and pick the CSV (the window opens in Downloads).
  2. A plan preset – type its alias, A-FLOR for an architectural floor plan... (the table below). Its CSV is applied and saved as a layer state.
  3. When the layer state of the preset already exists, choose U to restore it (the CSV is not read), I to apply the CSV again and replace the state, or C to cancel.
  4. The command line gives the layers updated and those of the file the drawing does not have.

Known Limitations

  • Layers are updated, never created: a layer of the file that the drawing does not have is only listed.
  • Only the architectural floor plan preset has its CSV so far; the other presets open the file window.
  • Colors are index colors only.

Bundled program notes 
;; ============================================================
;; IMPORT-LAYERS-FROM-CSV  (Dedicated preset commands)
;;
;; Each command loads a named CSV from the same folder as this
;; LSP, applies all layer properties to matching layers, then
;; manages a named Layer State in the drawing.
;;
;; COMMANDS:
;;   A-FLOR  - Architectural Floor Plan
;;   A-CEIL  - Architectural Ceiling Plan
;;   A-ROOF  - Architectural Roof Plan
;;   I-FURN  - Interior Furnishing Plan
;;   I-FNSH - Interior Finish Plan
;;   L-PLNT  - Landscape Plantings Identification Plan
;;   C-FLOR  - Civil Property Plan
;;   S-FLOR  - Structural Floor Plan
;;   E-FLOR  - Electrical Floor Plan
;;   P-FLOR  - Plumbing Floor Plan
;;   M-FLOR  - Mechanical Floor Plan
;;   IMPORTLAYERS - Browse for any CSV (no layer state)
;;
;; Preset CSV files must live in the same folder as this LSP.
;; CSV format matches the EXPORTLAYERS companion routine:
;;   Layer Name,Color,Lineweight,Linetype,Plot,Transparency,
;;   On/Off,Freeze,New VP Freeze,Description
;; ============================================================
