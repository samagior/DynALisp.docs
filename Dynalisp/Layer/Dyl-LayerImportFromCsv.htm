Import Layers From CSV

Function Syntax 12 commands – see Commands
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Give the layers of your drawing the colors, lineweights and visibility of a file made with Export Layers To CSV, or of a plan preset.

How To Use

  1. A file – type IMPORTLAYERS and pick it.
  2. A plan preset – type A-FLOR for a floor plan (the list below). It is saved as a layer state.
  3. When that state exists, choose U to restore it, I to apply the file again, or C to cancel.

Known Limitations

  • No layer is added: only those of the drawing change.
  • Only the floor plan preset is ready so far.
