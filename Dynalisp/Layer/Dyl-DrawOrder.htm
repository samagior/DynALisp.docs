Draw Order

Function Syntax DYL-DRAWORDER (DRO), DO-APPLY, DO-AUTO, DO-COUNT, DO-REBUILD, DO-RESET
Rules Modules\Dynalisp\Res\DrawOrder\<preset>.csv (one file per preset, Default.csv...)
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3. Based on Layer Draw Order (LDOrder) by Lee Mac.

Program Description

Annotation always on top, hatches always below, the lines in between, without a thought. Each object you draw goes to its level by itself.

How To Use

  1. Type DO-APPLY to put the whole drawing in order.
  2. Type DO-AUTO to keep it in order as you draw.
  3. Type DRO to change the levels.

The Levels

LevelWhat
9Redlines and non-plotting notes
8Annotation layers
7Texts, dimensions, leaders and tables on any other layer
0Everything else: walls, doors, detail lines
-4Hatches
-7Screened and background layers
-8Images and underlays
-9Xrefs

Draw Order Window

  • Presets – keep several sets of levels; pick the one of every drawing, or of this drawing only.
  • The list – each rule, its level and how many objects it holds. Move up and Move down change its level.
  • Rule – the layers or the kinds of objects it takes. When two rules take an object, the lower Order wins.
  • Content – the objects of the rule; Select and zoom shows them.
  • Apply to drawing – puts the drawing in order now.

Known Limitations

  • After a command, the first U undoes the order, the second the command.
  • A layer changed in the Properties palette waits for DO-APPLY.
  • Pan slow? DO-REBUILD cleans the order up.
