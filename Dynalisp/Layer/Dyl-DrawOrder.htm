Draw Order

Function Syntax DYL-DRAWORDER (DRO), DO-APPLY, DO-AUTO, DO-COUNT, DO-REBUILD, DO-RESET
Rules Modules\Dynalisp\Res\DrawOrder\<preset>.csv (one file per preset, Default.csv...)
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3. Based on Layer Draw Order (LDOrder) by Lee Mac.

Program Description

Stack the objects of the drawing by level, from their layer and their kind: annotation always on top, hatches and backgrounds always at the bottom, the other lines in between. With auto draw order on, each object you draw goes to its level by itself: a new hatch under the lines, a new line under the annotation.

How To Use

  1. Restack the drawing – type DO-APPLY: model space, every layout and every block are stacked by level, in one undo step.
  2. Keep it stacked – type DO-AUTO, or check Auto draw order in Dyl-Settings (it needs the DynALisp reactors on). New objects go to their level when their command ends; the commands that change layers (LAYMCH, MATCHPROP...) restack the current space.
  3. Change the levels – type DRO to open the Draw Order window: pick a preset, edit its rules, choose the preset of this drawing.
  4. When panning slows down – DO-COUNT counts the entries of the draw order tables, DO-REBUILD builds them again from scratch.

The Levels

Each rule has a name and a level: the objects no rule matches are at level 0, the positive levels above them (the highest on top), the negative ones below. The default levels, from top to bottom:

LevelNameLayers / Objects
9Redlines*-Anno-Redl*, *-Anno-Revc*, *-Anno-Revs*, *-Anno-Rdme*, *-Anno-Nplt*, *-Nplt
8Annotation*-Anno-[~R]* (A-Anno-Text, A-Anno-Dims, G-Anno-Ttlb...: every Anno minor except those starting with R, so that *-Anno-Refr stays with the references), *-Tags
7Annotation objectsText, Mtext, dimensions, leaders, multileaders, tables and attribute definitions on any other layer
0Other objectsEverything no rule matches: walls, doors, detail lines (A-Detl-Medm)...
-4Hatch layers / Hatch objects*-Patt (A-Detl-Patt, A-Wall-Patt...), and hatches on any other layer
-7Background*-Scrn, *-Bgrd, *-Exst (screened coordination lines, background solid fills)
-8ImagesRaster images and PDF / DWF / DGN underlays on any other layer
-9References*-Anno-Refr* (external references)

A phased layer keeps the level of its layer: A-Detl-Patt-N is a hatch layer like A-Detl-Patt (see Layer Phase). With Command Optimizer on, REGEN restacks the drawing first, by default.

Presets

The rules are saved in presets, each with its own name: one file per preset in Modules\Dynalisp\Res\DrawOrder, named after it (Default.csv, Details.csv...). One preset is active: auto draw order and DO-APPLY use its rules. The active preset is the one saved in the drawing; a drawing without one uses your preferred preset (user setting DynalispDrawOrderPreset, for every drawing). Both are chosen in the Draw Order dialog. When neither is set or its file is missing, Default is used, and the default rules below when there is no preset file at all.

The Rules

One rule per row, separated by semicolons: Name;Level;Layers;Objects;Description;Order.

  • Layers – layer name wildcards, separated by commas (*-Anno,*-Anno-*). Empty: any layer.
  • Objects – DXF object types, separated by commas (HATCH,MPOLYGON). Empty: any object.
  • Order – a whole number from 1 to 999. When several rules match an object, the rule with the lowest order gives it its level (the first row of them when their orders are equal), whatever their levels: the order of the rows in the file does not matter otherwise. With the default rules, a hatch on A-Anno-Symb matches Annotation (order 20, level 8) and Hatch objects (order 50, level -4) and stays with the annotation; a text on A-Detl-Patt matches Annotation objects (order 30) before Hatch layers (order 40) and goes up with the annotation objects (7). Give a rule a lower order to make it win over a wider one: the Annotation layers leave out the Refr minor so that xrefs stay at the bottom, giving References a lower order than Annotation would do the same.
  • A preset file written before the Order column gets one when it is read: the highest level first, 10 apart, so that its rules still give an object the highest level of the rules matching it, as they did. It is saved with the column the next time OK is clicked in the Draw Order dialog.
  • A rule at level 0 brings the objects it matches back with the other objects.
  • Rules with the same level number are stacked together.

The rules are edited in the Draw Order dialog (DRO), which saves them to the preset files.

Draw Order Dialog

  • Presets – Edit is the preset whose rules are shown, the active one marked (active). The rules edited in each preset are kept while the dialog is open. New... makes a copy of the selected preset under a new name, Rename... renames it and Delete removes it (the last one cannot be deleted). A preset name cannot contain \ / : * ? " < > | and two presets cannot have the same name.
  • Preferred (every drawing) – your preferred preset, used by every drawing without its own (user setting DynalispDrawOrderPreset).
  • This drawing – Preferred preset (...), or a preset saved in the drawing as its own, over the preferred one. The active preset is this one.
  • Sort by – sorts the rule list by Level (highest first, the default), Order (lowest first: the rules in the order they win), Type (then by level) or Name. Sorting only changes the display.
  • Move up / Move down – move the selected rule one line in the list, by changing the value it is sorted by. Sorted by Level, the rule trades its level with the rule shown above or below it (up: a higher level, drawn above); when both have the same level, its level changes by 1 instead, and moving past the === OTHER OBJECTS === line gives it level 1 (up) or 0 (down). Sorted by Order, it trades its order the same way (up: a lower order, the rule wins first; the same order changes by 1). The buttons are disabled in the other sorts and on the first or last rule.
  • Rule list – the rules, under a header naming the columns: Order, Level, Type (what the rule matches: Layers, Objects, Layers + objects or All objects), Name, Objects in drawing (the objects the rule gives its level to, counted again after each change) and Description (the layers and objects of each rule are shown in the Rule section when it is selected). The === OTHER OBJECTS === line is always shown, in capitals so it stands out: it counts the objects no rule matches, at level 0. Sorted by level, it sits between the positive levels and the others, which is where those objects are stacked; with the other sorts it is the last line. It is not a rule: selecting it shows its content and disables the Rule section.
  • Several rules at once – Ctrl+click adds a rule to the selection (or removes it), Shift+click selects a range. The section reads Rule (3 selected) and shows the rule clicked first: a Description, Level, Order or Type changed is given to every rule selected (a new Type keeps the layers or objects of each rule when it uses them), their other values are left as they are. The name, the Layers and Objects lists, Copy and Move up / down are for one rule only (greyed out); Delete removes them all. The line of the other objects is selected alone.
  • Rule – the Name, Description, Level (a whole number from -99 to 99), Order (a whole number from 1 to 999, the lowest wins), Type, Layers and Objects of the selected rule. The type comes from the fields used and only those are enabled: Layers lists one layer name or wildcard per line (*-Anno, *-Anno-*...) – type one in the box under it and click Add, select a line to Replace or Remove it (the last line cannot be removed: change the type instead); the commas are added when the rules are saved. Objects is picked in a list, after choosing the Product whose objects it lists. Only the objects whose stacking shows in a 2D view are listed: annotation, linework, fills and masks, images and underlays, blocks (construction lines, cameras, lights, section planes or single surface types are left out). AutoCAD: groups (Annotation, Text, Dimensions, All leaders, Fills and masks, Hatches and gradients, Images and underlays, Lineworks, 3D objects), then, after an Object types separator line (it cannot be picked), each object type on its own (Mtext, Wipeouts, PDF underlays, Single-line text...). AutoCAD Architecture (AEC_*), grouped by the cut plane of the plan views: Cut objects (walls, curtain walls, structural members), Openings (doors, windows, openings in the cut walls), Below cut plane objects (stairs, railings, slabs), Above cut plane objects (roofs, roof slabs, ceilings), Spaces and zones, Mass elements, Annotation objects (tags, schedules, AEC dimensions, grids), Sections and elevations. Draw order moves a whole object: the components of an Architecture object (its cut lines, hatch, lines above the cut plane) are drawn by its display representation, set in its display properties. AutoCAD MEP (AECB_*: Ducts, Pipes and plumbing, Trays and conduits, Equipment, Electrical objects for devices panels and wires, Schematics), Civil 3D (AECC_*: Surfaces, Points, Alignments, Profiles, Sections, Corridors, Parcels, Grading objects for feature lines gradings and survey figures, Pipe networks, Labels and tables), Plant 3D P&ID (ACPP*), AutoCAD Mechanical (ACM*: Annotation objects), each with an All ... objects item first, or In this drawing: the exact object types the drawing has, whatever product made them. The groups of the other products match the prefix of their object names with wildcards (AEC_*DOOR*), since these names change between releases; use In this drawing to pick an exact one. Without the product or its object enabler, its objects are proxies (ACAD_PROXY_ENTITY, in the AutoCAD list). A value that is in none of the lists (written by hand in a preset file) shows as Custom. The line under the Objects list shows the AutoCAD names (DXF object types) the selected item stands for: AutoCAD names: HATCH, MPOLYGON for Hatches and gradients, AutoCAD name: MTEXT for Mtext. Choosing another type clears the field it does not use and fills the one it needs when empty (placeholder layers *-Name,*-Name-*, first item of the Objects list). All objects matches every object (every object takes at least its level). A wrong value is reported under the buttons and must be fixed before another rule is selected.
  • Content – under the Rule section: the objects of the drawing that the selected rule gives its level to (the objects it matches and no rule with a lower order matches), one line per object type and layer with the number of objects (MTEXT / A-ANNO-TEXT  100), sorted by type then layer. The line above it gives the total. With the === OTHER OBJECTS === line selected, it lists the objects no rule matches: the layers to add to a rule. Counted again after each change of the rules. Search filters the lines: type part of an object type or layer name and press Enter (the * and ? wildcards work, an empty search shows every line). Select one or more lines and click Select and zoom to close the dialog, select their objects and zoom on them: in the current space when it has some of them, else in the layout that has the most (the command line says how many are in other layouts). When changes are not saved yet, a warning asks to Save and close, Close without saving or Cancel (the dialog stays open).
  • New / Copy – adds a rule after the selected one: a new one (on the placeholder layers *-Name,*-Name-*, to replace, its order 10 after the highest one: it wins last) or a copy of the selected rule (same order: the original, first in the file, wins on a tie). Delete removes the selected rule.
  • Restore defaults – replaces the rules of the selected preset with the default ones.
  • Auto draw order – turns auto draw order on or off at once. It is a user setting (DynalispDrawOrderAuto), so it applies to every drawing. It is also in Dyl-Settings (Auto draw order), next to the open button that opens this window. It runs only while the DynALisp reactors of Dyl-Settings are on (greyed out there otherwise).
  • Apply to drawing – restacks model space, every layout and every block definition with the rules shown, saved or not, as one undo step, and regenerates the drawing.
  • OK saves every preset (the files of the presets deleted or renamed are removed), then the preferred preset and the preset of this drawing when they were changed: the next command uses the rules of the active preset, DO-APPLY restacks the drawing with them. Cancel leaves the presets as they were: a restacking done with Apply to drawing stays, U undoes it. Open Docs opens this page.

Known Limitations

  • Auto draw order restacks after the command, as a separate step: the first U after a command undoes the restacking, the second one undoes the command.
  • A layer changed in the Properties palette (no command) does not restack: use DO-APPLY.
  • Restacking overrides a DRAWORDER set by hand between objects of different levels; within a level, it is kept.
  • The commands that change layers restack only the current space; DO-APPLY restacks every layout.
  • If the screen does not show the new order after a command, REGEN (plotting always uses it).
  • DO-COUNT compares the entries of the model space draw order table with its objects; DO-RESET deletes that table, putting model space back in creation order (U undoes it). Both work on model space only; with auto draw order on, the next command restacks the levels again.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-DrawOrder: they are run by their alias (their command is named Pst-*).
