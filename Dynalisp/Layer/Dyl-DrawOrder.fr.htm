Ordre de tracé (Draw Order)

Syntaxe DYL-DRAWORDER (DRO), DO-APPLY, DO-AUTO, DO-COUNT, DO-REBUILD, DO-RESET
Fichier source Modules\Dynalisp\Apps\Layer\Dyl-DrawOrder.lsp (commandes), Modules\Dynalisp\Remote\Dyl-DrawOrder.lsp (niveaux et paramètre d'ordre de tracé automatique, chargé au démarrage) et Modules\Dynalisp\Reactor\Dyl-DrawOrder.lsp (réacteurs de l'ordre de tracé automatique, chargés au démarrage tant que les réacteurs DynALisp sont activés)
Règles Modules\Dynalisp\Res\DrawOrder\<preset>.csv (un fichier par préréglage, Default.csv...)
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3. D'après Layer Draw Order (LDOrder) de Lee Mac.

Description

Empile les objets du dessin par niveau, lu dans les noms de calques Dynalisp : l'annotation toujours au-dessus, les hachures et les arrière-plans toujours en dessous, les autres lignes entre les deux. Chaque règle a un nom et un numéro de niveau : les objets qu'aucune règle ne touche sont au niveau 0, les niveaux positifs sont empilés au-dessus (le plus haut en haut) et les niveaux négatifs en dessous (le plus bas tout en bas).

Les niveaux par défaut, de haut en bas :

NiveauNomCalques / Objets
9Redlines*-Anno-Redl*, *-Anno-Revc*, *-Anno-Revs*, *-Anno-Rdme*, *-Anno-Nplt*, *-Nplt
8Annotation*-Anno-[~R]* (A-Anno-Text, A-Anno-Dims, G-Anno-Ttlb... : chaque mineur Anno sauf ceux qui commencent par R, pour que *-Anno-Refr reste avec les références), *-Tags
7Annotation objectsTextes, textes multilignes, cotes, lignes de repère, lignes de repère multiples, tableaux et définitions d'attributs sur tout autre calque
0Other objectsTout ce qu'aucune règle ne touche : murs, portes, lignes de détail (A-Detl-Medm)...
-4Hatch layers / Hatch objects*-Patt (A-Detl-Patt, A-Wall-Patt...), et les hachures sur tout autre calque
-7Background*-Scrn, *-Bgrd, *-Exst (lignes de coordination tramées, remplissages pleins d'arrière-plan)
-8ImagesImages raster et calques sous-jacents PDF / DWF / DGN sur tout autre calque
-9References*-Anno-Refr* (références externes)

Les calques en phase gardent le niveau de leur calque : A-Detl-Patt-N est un calque de hachures comme A-Detl-Patt (voir Phase des calques).

Avec l'ordre de tracé automatique activé (désactivé par défaut, voir Paramètres), les objets créés par une commande sont mis à leur niveau à la fin de la commande : une nouvelle hachure va sous les lignes, une nouvelle ligne sous l'annotation. Les commandes qui changent le calque d'objets (LAYMCH, MATCHPROP, CHPROP, LAYMRG...) réempilent l'espace courant. Tant qu'il est activé, REGEN réempile aussi tout le dessin avant de le régénérer, quand Command Optimizer est activé et que Apply the draw order preset est coché pour REGEN dans la fenêtre de préparation des sorties (Dyl-PrepSuite, ou le bouton ouvrir à côté de Commands dans Dyl-Settings) (par défaut; il peut être coché pour les autres commandes de sortie aussi).

Préréglages

Les règles sont enregistrées dans des préréglages, chacun avec son nom : un fichier par préréglage dans Modules\Dynalisp\Res\DrawOrder, nommé d'après lui (Default.csv, Details.csv...). Un préréglage est actif : l'ordre de tracé automatique et DO-APPLY utilisent ses règles. Le préréglage actif est celui enregistré dans le dessin; un dessin qui n'en a pas utilise votre préréglage préféré (paramètre utilisateur DynalispDrawOrderPreset, pour tous les dessins). Les deux se choisissent dans la fenêtre Draw Order. Quand aucun n'est défini ou que son fichier manque, Default est utilisé, et les règles par défaut ci-dessous quand il n'y a aucun fichier de préréglage.

Les règles

Une règle par rangée, séparée par des points-virgules : Name;Level;Layers;Objects;Description;Order.

  • Layers – des noms de calques génériques, séparés par des virgules (*-Anno,*-Anno-*). Vide : tout calque.
  • Objects – des types d'objets DXF, séparés par des virgules (HATCH,MPOLYGON). Vide : tout objet.
  • Order – un nombre entier de 1 à 999. Quand plusieurs règles touchent un objet, la règle à l'ordre le plus bas lui donne son niveau (la première rangée d'entre elles quand leurs ordres sont égaux), quels que soient leurs niveaux : l'ordre des rangées dans le fichier n'a pas d'importance autrement. Avec les règles par défaut, une hachure sur A-Anno-Symb touche Annotation (ordre 20, niveau 8) et Hatch objects (ordre 50, niveau -4) et reste avec l'annotation; un texte sur A-Detl-Patt touche Annotation objects (ordre 30) avant Hatch layers (ordre 40) et monte avec les objets d'annotation (7). Donnez à une règle un ordre plus bas pour qu'elle l'emporte sur une plus large : les calques Annotation laissent de côté le mineur Refr pour que les xréfs restent en dessous; donner à References un ordre plus bas qu'Annotation ferait de même.
  • Un fichier de préréglage écrit avant la colonne Order en reçoit une quand il est lu : le niveau le plus haut d'abord, de 10 en 10, pour que ses règles donnent toujours à un objet le niveau le plus haut des règles qui le touchent, comme avant. Il est enregistré avec la colonne la prochaine fois qu'OK est cliqué dans la fenêtre Draw Order.
  • Une règle au niveau 0 ramène les objets qu'elle touche avec les autres objets.
  • Les règles de même numéro de niveau sont empilées ensemble.

Les règles se modifient dans la fenêtre Draw Order (DRO), qui les enregistre dans les fichiers de préréglages.

Fenêtre Draw Order

  • Presets – Edit est le préréglage dont les règles sont affichées, l'actif marqué (active). Les règles modifiées dans chaque préréglage sont gardées tant que la fenêtre est ouverte. New... fait une copie du préréglage sélectionné sous un nouveau nom, Rename... le renomme et Delete le retire (le dernier ne peut pas être supprimé). Un nom de préréglage ne peut pas contenir \ / : * ? " < > | et deux préréglages ne peuvent pas avoir le même nom.
  • Preferred (every drawing) – votre préréglage préféré, utilisé par chaque dessin qui n'a pas le sien (paramètre utilisateur DynalispDrawOrderPreset).
  • This drawing – Preferred preset (...), ou un préréglage enregistré dans le dessin comme le sien, à la place du préféré. Le préréglage actif est celui-ci.
  • Sort by – trie la liste des règles par Level (le plus haut d'abord, par défaut), Order (le plus bas d'abord : les règles dans l'ordre où elles l'emportent), Type (puis par niveau) ou Name. Le tri ne change que l'affichage.
  • Move up / Move down – déplacent la règle sélectionnée d'une ligne dans la liste, en changeant la valeur par laquelle elle est triée. Triée par Level, la règle échange son niveau avec la règle affichée au-dessus ou en dessous (vers le haut : un niveau plus haut, tracé au-dessus); quand les deux ont le même niveau, son niveau change plutôt de 1, et dépasser la ligne === OTHER OBJECTS === lui donne le niveau 1 (haut) ou 0 (bas). Triée par Order, elle échange son ordre de la même façon (vers le haut : un ordre plus bas, la règle l'emporte en premier; un ordre égal change de 1). Les boutons sont grisés dans les autres tris et sur la première ou la dernière règle.
  • Liste des règles – les règles, sous un en-tête qui nomme les colonnes : Order, Level, Type (ce que la règle touche : Layers, Objects, Layers + objects ou All objects), Name, Objects in drawing (les objets auxquels la règle donne son niveau, recomptés après chaque changement) et Description (les calques et les objets de chaque règle sont affichés dans la section Rule quand elle est sélectionnée). La ligne === OTHER OBJECTS === est toujours affichée, en majuscules pour qu'elle ressorte : elle compte les objets qu'aucune règle ne touche, au niveau 0. Triée par niveau, elle se place entre les niveaux positifs et les autres, là où ces objets sont empilés; avec les autres tris, c'est la dernière ligne. Ce n'est pas une règle : la sélectionner montre son contenu et grise la section Rule.
  • Plusieurs règles à la fois – Ctrl+clic ajoute une règle à la sélection (ou l'en retire), Maj+clic sélectionne une plage. La section affiche Rule (3 selected) et montre la règle cliquée en premier : une Description, un Level, un Order ou un Type changé est donné à chaque règle sélectionnée (un nouveau Type garde les calques ou les objets de chaque règle quand il les utilise), leurs autres valeurs restent telles quelles. Le nom, les listes Layers et Objects, Copy et Move up / down sont pour une seule règle (grisés); Delete les retire toutes. La ligne des autres objets se sélectionne seule.
  • Rule – les Name, Description, Level (un nombre entier de -99 à 99), Order (un nombre entier de 1 à 999, le plus bas l'emporte), Type, Layers et Objects de la règle sélectionnée. Le type vient des champs utilisés et seuls ceux-là sont actifs : Layers liste un nom de calque ou un motif générique par ligne (*-Anno, *-Anno-*...) – tapez-en un dans la case en dessous et cliquez Add, sélectionnez une ligne pour la remplacer (Replace) ou la retirer (Remove) (la dernière ligne ne peut pas être retirée : changez plutôt le type); les virgules sont ajoutées quand les règles sont enregistrées. Objects se choisit dans une liste, après le choix du Product dont elle liste les objets. Seuls les objets dont l'empilement se voit dans une vue 2D sont listés : annotation, traits, remplissages et masques, images et calques sous-jacents, blocs (les lignes de construction, caméras, lumières, plans de coupe ou types de surfaces seuls sont laissés de côté). AutoCAD : des groupes (Annotation, Text, Dimensions, All leaders, Fills and masks, Hatches and gradients, Images and underlays, Lineworks, 3D objects), puis, après une ligne de séparation Object types (qui ne peut pas être choisie), chaque type d'objet seul (Mtext, Wipeouts, PDF underlays, Single-line text...). AutoCAD Architecture (AEC_*), groupés selon le plan de coupe des vues en plan : Cut objects (murs, murs-rideaux, éléments structuraux), Openings (portes, fenêtres, ouvertures dans les murs coupés), Below cut plane objects (escaliers, garde-corps, dalles), Above cut plane objects (toits, dalles de toit, plafonds), Spaces and zones, Mass elements, Annotation objects (étiquettes, nomenclatures, cotes AEC, grilles), Sections and elevations. L'ordre de tracé déplace un objet entier : les composants d'un objet Architecture (ses lignes coupées, sa hachure, ses lignes au-dessus du plan de coupe) sont dessinés par sa représentation d'affichage, réglée dans ses propriétés d'affichage. AutoCAD MEP (AECB_* : Ducts, Pipes and plumbing, Trays and conduits, Equipment, Electrical objects pour les appareils, panneaux et fils, Schematics), Civil 3D (AECC_* : Surfaces, Points, Alignments, Profiles, Sections, Corridors, Parcels, Grading objects pour les lignes caractéristiques, les nivellements et les figures de levé, Pipe networks, Labels and tables), Plant 3D P&ID (ACPP*), AutoCAD Mechanical (ACM* : Annotation objects), chacun avec un élément All ... objects en premier, ou In this drawing : les types d'objets exacts du dessin, quel que soit le produit qui les a faits. Les groupes des autres produits touchent le préfixe des noms de leurs objets avec des caractères génériques (AEC_*DOOR*), car ces noms changent d'une version à l'autre; utilisez In this drawing pour en choisir un exact. Sans le produit ou son activateur d'objets, ses objets sont des proxys (ACAD_PROXY_ENTITY, dans la liste AutoCAD). Une valeur qui n'est dans aucune liste (écrite à la main dans un fichier de préréglage) s'affiche comme Custom. La ligne sous la liste Objects montre les noms AutoCAD (types d'objets DXF) que représente l'élément sélectionné : AutoCAD names: HATCH, MPOLYGON pour Hatches and gradients, AutoCAD name: MTEXT pour Mtext. Choisir un autre type vide le champ qu'il n'utilise pas et remplit celui dont il a besoin quand il est vide (calques temporaires *-Name,*-Name-*, premier élément de la liste Objects). All objects touche tous les objets (chaque objet prend au moins son niveau). Une valeur erronée est signalée sous les boutons et doit être corrigée avant de sélectionner une autre règle.
  • Content – sous la section Rule : les objets du dessin auxquels la règle sélectionnée donne son niveau (les objets qu'elle touche et qu'aucune règle d'ordre plus bas ne touche), une ligne par type d'objet et calque avec le nombre d'objets (MTEXT / A-ANNO-TEXT  100), triées par type puis par calque. La ligne au-dessus donne le total. Avec la ligne === OTHER OBJECTS === sélectionnée, il liste les objets qu'aucune règle ne touche : les calques à ajouter à une règle. Recompté après chaque changement des règles. Search filtre les lignes : tapez une partie d'un type d'objet ou d'un nom de calque et appuyez sur Entrée (les caractères génériques * et ? fonctionnent, une recherche vide montre toutes les lignes). Sélectionnez une ou plusieurs lignes et cliquez Select and zoom pour fermer la fenêtre, sélectionner leurs objets et zoomer dessus : dans l'espace courant quand il en a, sinon dans la présentation qui en a le plus (la ligne de commande dit combien sont dans d'autres présentations). Quand des changements ne sont pas encore enregistrés, un avertissement demande Save and close, Close without saving ou Cancel (la fenêtre reste ouverte).
  • New / Copy – ajoute une règle après celle sélectionnée : une nouvelle (sur les calques temporaires *-Name,*-Name-*, à remplacer, son ordre 10 après le plus haut : elle l'emporte en dernier) ou une copie de la règle sélectionnée (même ordre : l'originale, première dans le fichier, l'emporte en cas d'égalité). Delete retire la règle sélectionnée.
  • Restore defaults – remplace les règles du préréglage sélectionné par celles par défaut.
  • Auto draw order – active ou désactive tout de suite l'ordre de tracé automatique. C'est un paramètre utilisateur (DynalispDrawOrderAuto) : il s'applique donc à tous les dessins. Il est aussi dans Dyl-Settings (Auto draw order), à côté du bouton ouvrir qui ouvre cette fenêtre. Il ne s'exécute que tant que les DynALisp reactors de Dyl-Settings sont activés (grisé sinon).
  • Apply to drawing – réempile l'espace objet, chaque présentation et chaque définition de bloc avec les règles affichées, enregistrées ou non, en une seule étape d'annulation, et régénère le dessin.
  • OK enregistre chaque préréglage (les fichiers des préréglages supprimés ou renommés sont retirés), puis le préréglage préféré et celui de ce dessin s'ils ont changé : la commande suivante utilise les règles du préréglage actif, DO-APPLY réempile le dessin avec elles. Cancel laisse les préréglages comme ils étaient : un réempilement fait avec Apply to drawing reste, U l'annule. Open Docs ouvre cette page.

Fonctionnement

  1. Chaque niveau garde l'ordre de tracé de ses propres objets : le réempilement déplace des niveaux entiers en haut (le niveau positif le plus bas d'abord) ou en bas (le niveau négatif le plus haut d'abord) avec la table d'ordre de tracé de l'espace.
  2. L'ordre de tracé automatique surveille les objets ajoutés au dessin et réempile à la fin de la commande qui les a créés, comme l'auto-phase. Les objets créés par une commande Lisp sont réempilés à la fin de la commande Lisp.
  3. Seuls les nouveaux objets sont déplacés, juste sous l'objet le plus bas des niveaux qui doivent rester au-dessus : une nouvelle ligne va sous l'annotation, une nouvelle hachure sous les lignes, un nouveau texte au niveau le plus haut ne déplace rien. Les niveaux déjà empilés ne sont pas touchés. Quand l'ordre de tracé ne peut pas être lu, ce sont les niveaux au-dessus ou en dessous des nouveaux objets qui sont réempilés.
  4. Chaque réempilement ajoute des entrées à la table d'ordre de tracé de l'espace, et une grande table ralentit les panoramiques et les zooms. DO-REBUILD supprime les tables de l'espace objet, des présentations et des définitions de blocs, puis réempile les niveaux à partir de l'ordre de création, en une seule étape d'annulation. L'étape de préparation des sorties Rebuild the draw order (Dyl-PrepSuite, désactivée par défaut) fait de même avant les commandes pour lesquelles elle est cochée, à la place d'Apply the draw order. Un DRAWORDER fait à la main dans un niveau est perdu par une reconstruction.
  5. Les objets de l'espace objet, des présentations et des définitions de blocs sont réempilés : une hachure dans un bloc va sous les lignes de ce bloc, comme dans le dessin. Les niveaux sont ceux des objets du bloc (souvent le calque 0 : ce sont donc les règles par type d'objet qui s'appliquent). L'ordre de tracé automatique réempile une définition de bloc quand des objets y sont ajoutés (BLOCK, BEDIT, REFEDIT...) et régénère le dessin pour que ses références le montrent. Les xréfs et leurs blocs ne changent jamais, ni les blocs anonymes qu'AutoCAD refait lui-même (cotes, tableaux...); ceux des blocs dynamiques sont réempilés. Les fenêtres sont laissées de côté.
  6. Les objets ramenés par U, UNDO, REDO et OOPS restent où ils sont. La liste peut être remplacée par la variable d'environnement DynalispDrawOrderSkip, et les commandes qui réempilent l'espace courant par DynalispDrawOrderRefresh, par exemple (setenv "DynalispDrawOrderRefresh" "LAYMCH,MATCHPROP,CHPROP").

Utiliser l'ordre de tracé dans une App

  • (Remote>>Dyl:DrawOrderApply nil nil) – réempile l'espace objet, chaque présentation et chaque définition de bloc avec les règles du préréglage actif, renvoie le nombre d'objets déplacés.
  • (Remote>>Dyl:DrawOrderApply "Model" nil) – réempile un espace, donné par son nom de présentation. Le second argument peut donner d'autres règles (voir Remote>>Dyl:DrawOrderParse).
  • (Remote>>Dyl:DrawOrderRebuild nil nil) – supprime les tables d'ordre de tracé de l'espace objet, de chaque présentation et de chaque définition de bloc, puis les réempile; un nom de présentation à la place du premier nil reconstruit un seul espace.
  • (Remote>>Dyl:DrawOrderPreset) – renvoie le nom du préréglage actif, (Remote>>Dyl:DrawOrderPresetSet "Details") en enregistre un autre dans le dessin (nil : le dessin utilise le préréglage préféré), (Remote>>Dyl:DrawOrderPresetDefault) renvoie le préréglage préféré.
  • (Remote>>Dyl:DrawOrderAutoSet T) – active l'ordre de tracé automatique (nil : désactivé).

Limites connues

  • L'ordre de tracé automatique réempile après la commande, en une étape séparée : le premier U après une commande annule le réempilement, le second annule la commande.
  • Un calque changé dans la palette Propriétés (sans commande) ne réempile pas : utilisez DO-APPLY.
  • Le réempilement remplace un DRAWORDER fait à la main entre des objets de niveaux différents; dans un niveau, il est gardé.
  • Les commandes qui changent les calques ne réempilent que l'espace courant; DO-APPLY réempile chaque présentation.
  • Si l'écran ne montre pas le nouvel ordre après une commande, faites REGEN (le traçage l'utilise toujours).
  • DO-COUNT compare les entrées de la table d'ordre de tracé de l'espace objet avec ses objets; DO-RESET supprime cette table, remettant l'espace objet dans l'ordre de création (U l'annule). Les deux ne travaillent que sur l'espace objet; avec l'ordre de tracé automatique activé, la commande suivante réempile de nouveau les niveaux.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-DrawOrder : elles se lancent par leur alias (leur commande se nomme Pst-*).

CommandeAliasNom
Dyl-DrawOrderDRODraw Order
  ↳ DO-APPLY–Draw Order Apply
  ↳ DO-AUTO–Draw Order Auto Toggle
  ↳ DO-COUNT–Draw Order Count
  ↳ DO-RESET–Draw Order Reset
