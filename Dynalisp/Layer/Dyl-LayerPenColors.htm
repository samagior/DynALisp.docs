Layer Pen Colors

Function Syntax DYL-LAYERPENCOLORS

Program Description

Switch your layers to the pen colors 1 to 7, for a plotter or a client that wants them, and back.

How To Use

  1. Type PENS: each layer gets the pen of its lineweight.
  2. Type UNPENS to get the colors back.

Good To Know

  • Text, dimensions, non-plotting and existing layers keep their color; patterns get 40, screened 8, existing 9.
  • A layer with no lineweight is left as it is: set it first with LWC.
