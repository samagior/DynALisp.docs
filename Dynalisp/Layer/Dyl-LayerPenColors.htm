Layer Pen Colors

Function Syntax DYL-LAYERPENCOLORS
Licence GNU General Public License v3

Program Description

Switch the layers from the 255 colors of the Dyl Standard to a few pen colors, 1 to 7, chosen from the lineweight of each layer, for a plotter or a client that wants them. A few colors and layer names keep theirs or get one of their own. The colors are saved in the drawing: Restore gives them back at any time.

How To Use

  1. Type Dyl-LayerPenColors and choose Pens (the default) or Restore. The two child commands of the table below skip this question.
  2. Choose All (every layer, the default) or Select (the layers of the objects you select).
  3. The command line says how many layers changed, matched already or were kept by a rule, and which it left. One U undoes it all.
  4. To go back, run it again with Restore: each layer gets its former color.

Commands

Rules

The layers matching a rule of Res\Layer\PenColors.csv are not switched by their lineweight. The first rule matching a layer applies. Layers are layer names (wildcards, any case), Colors the current colors (wildcards: 20# is 200 to 209), and Color the color given to the layer, empty to keep its color as is. Edit the file in Excel. Your copy is saved in User\ (see Dyl-UserFiles).

Known Limitations

  • Layers with lineweight Default or 2.00 mm (no pen color) are not switched. Set their lineweight first, for example from their color with Pst-LayerWeightByColor (LWC).
  • Xref layers are not changed.
  • Only the layers are changed: objects with their own color are not.
  • A layer color changed by hand while on pen colors is replaced by the saved one on Restore.
