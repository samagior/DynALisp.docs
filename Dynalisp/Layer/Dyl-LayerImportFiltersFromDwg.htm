Import Layer Filters

Function Syntax LFIMP, LFLIST, IMPORTLAYERFILTER

Program Description

Copy the layer filters of another drawing or template into yours. Nothing else comes with them.

How To Use

  1. Type LFIMP and pick the file.
  2. Type the filters to bring, or press Enter for all.
  3. For a name already used, choose Overwrite, Skip or Rename.
  4. LFLIST lists the filters of your drawing.

Known Limitations

  • Group filters are not copied.
  • A very old drawing must be saved in a recent AutoCAD first.
