Layer Groups

Function Syntax DYL-LAYERGROUP
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Creates (or refreshes) one layer group filter per discipline in the Layer Properties Manager, based on the discipline designator at the start of the layer names. The Architectural group also gets Detail, Elevation, Plan and Section sub-groups.

Commands

CommandNameDescription
DYL-LAYERGROUPLayer GroupsCreates the standard Dynalisp layer group filters in the Layer Properties Manager.

Known Limitations

  • Group filters list layers explicitly: layers created after running the command are not added. Run it again to refresh the groups.
  • The Mechanical group uses the Landscape pattern L-* instead of M-*.
  • Close the Layer Properties Manager before running the command: when left open it can rewrite the filter tree from its own copy.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
