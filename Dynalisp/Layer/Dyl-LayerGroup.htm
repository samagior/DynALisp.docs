Layer Groups

Function Syntax DYL-LAYERGROUP
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Sort the Layer Properties Manager by discipline: Architectural, Structural, Mechanical... in one command.

How To Use

  1. Close the Layer Properties Manager.
  2. Type Dyl-LayerGroup.
  3. Run it again after adding layers.

Known Limitations

  • The Mechanical group shows the Landscape layers (L-*).

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
