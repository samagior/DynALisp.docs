Layer Color Weight

Function Syntax DYL-LAYERCOLORWEIGHT
Licence GNU General Public License v3

Program Description

Match the lineweight of each layer to its color, as the Dyl Standard plots them, or the color to the lineweight.

How To Use

  1. Type LWC (lineweight from color) or CLW (color from lineweight).
  2. Choose All or Select.
  3. One U undoes it.

Known Limitations

  • True colors and the layers of xrefs are left as they are.
  • Only the layers change, not objects with their own color.
