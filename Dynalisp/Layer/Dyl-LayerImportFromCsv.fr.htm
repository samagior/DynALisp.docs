Importer des calques d'un CSV (Import Layers From CSV)

Syntaxe 12 commandes – voir Commandes
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Applique aux calques du dessin courant les propriétés de calques enregistrées dans un fichier CSV. Les commandes préréglées chargent un CSV nommé pour un type de plan et enregistrent le résultat comme état de calques nommé, pour pouvoir rétablir la configuration plus tard; IMPORTLAYERS permet de choisir n'importe quel CSV. Le format du CSV est celui qu'écrit Export Layers To CSV.

Limites connues

  • Le dossier du programme est trouvé en cherchant import_layers_from_csv.lsp, un nom de fichier absent du paquet : les préréglages sont donc cherchés dans le dossier du dessin et la boîte de dialogue de fichier s'ouvre dans la plupart des cas.
  • Seul preset_arch_floor.csv est livré (dans Modules\Dynalisp\Res); les autres préréglages n'ont pas encore de CSV.
  • Les couleurs sont lues comme couleurs d'index (Red (1), ACI 151, 151); les couleurs vraies ne sont pas prises en charge.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-LayerImportFromCsv : elles se lancent par leur alias, ou se choisissent dans Dyl-LayerImportFromCsv quand elle les liste (leur commande se nomme Pst-*).

Notes du programme d'origine (en anglais) 
;; ============================================================
;; IMPORT-LAYERS-FROM-CSV  (Dedicated preset commands)
;;
;; Each command loads a named CSV from the same folder as this
;; LSP, applies all layer properties to matching layers, then
;; manages a named Layer State in the drawing.
;;
;; COMMANDS:
;;   A-FLOR  - Architectural Floor Plan
;;   A-CEIL  - Architectural Ceiling Plan
;;   A-ROOF  - Architectural Roof Plan
;;   I-FURN  - Interior Furnishing Plan
;;   I-FNSH - Interior Finish Plan
;;   L-PLNT  - Landscape Plantings Identification Plan
;;   C-FLOR  - Civil Property Plan
;;   S-FLOR  - Structural Floor Plan
;;   E-FLOR  - Electrical Floor Plan
;;   P-FLOR  - Plumbing Floor Plan
;;   M-FLOR  - Mechanical Floor Plan
;;   IMPORTLAYERS - Browse for any CSV (no layer state)
;;
;; Preset CSV files must live in the same folder as this LSP.
;; CSV format matches the EXPORTLAYERS companion routine:
;;   Layer Name,Color,Lineweight,Linetype,Plot,Transparency,
;;   On/Off,Freeze,New VP Freeze,Description
;; ============================================================
