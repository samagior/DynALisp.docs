Layer Drawing List

Function Syntax DYL-LAYERLIST
Source File Modules\Dynalisp\Apps\Layer\Dyl-LayerList.lsp
Licence GNU General Public License v3

Program Description

Draws a legend of layers in the drawing: for each layer, a line drawn on that layer with its name and description written above it. Useful to back up a layer standard or to build a standard sheet.

Commands

CommandNameDescription
DYL-LAYERLISTLayer Drawing ListDraws a line and a label with the description of each layer of the drawing or of the selection.

How It Works

  1. Pick the insertion point of the first row.
  2. Choose All (default, every layer of the drawing in layer table order) or Select (the layers of the objects you select, each once).
  3. For each layer the routine creates, on that layer: a 200-unit horizontal line, the layer name as text (height 2.25) 1 unit above the line and, if the layer has one, its description 75 units to the right.
  4. The next row starts 7.5 units below.

Known Limitations

  • Sizes are fixed drawing units, not scaled to the annotation scale.
  • With Select, the layers are listed in selection order, not sorted.
  • Text uses the current text style.
