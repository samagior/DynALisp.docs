Layer Drawing List

Function Syntax DYL-LAYERLIST
Licence GNU General Public License v3

Program Description

Draw a legend of the layers in the drawing: for each layer, a line drawn on that layer with its name and its description above it. Handy to back up a layer standard or to make a standards sheet.

How To Use

  1. Type Dyl-LayerList and pick the point of the first row.
  2. Choose All (every layer of the drawing, the default) or Select (the layers of the objects you select).
  3. One row per layer is drawn, each below the last: the line in the color and linetype of the layer, its name, and its description.

Commands

CommandNameDescription
DYL-LAYERLISTLayer Drawing ListDraws a line and a label with the description of each layer of the drawing or of the selection.

Known Limitations

  • Sizes are fixed drawing units, not scaled to the annotation scale.
  • With Select, the layers are listed in selection order, not sorted.
  • Text uses the current text style.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
