Layer Drawing List

Function Syntax DYL-LAYERLIST

Program Description

Draw a legend of your layers: a line on each layer, with its name and description.

How To Use

  1. Type Dyl-LayerList and pick a point.
  2. Choose All or Select.

Known Limitations

  • The size does not follow the annotation scale.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
