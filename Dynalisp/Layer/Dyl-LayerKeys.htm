Layer Keys

Function Syntax DYL-LAYERKEYS
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Choose once the layer of each kind of line, and every DynALisp tool draws on it. A layer key is a short name, THIN or HATCH, that stands for a layer.

How To Use

  1. Type Dyl-LayerKeys.
  2. Pick a key and change its layer, color, linetype or lineweight; or click New.
  3. Click OK.

Layer Keys Window

  • Filter and Sort by – find a key fast.
  • Parameters – the layer of the key and its properties. Select several keys to change them together.
  • Keep this color in every phase – the layer keeps its color in existing and demolition.
  • Reset key and Restore defaults – go back to the default values.

Layers That Differ From Their Key

When a layer of the drawing does not match its key, DynALisp asks whether to update it. Check Remember my answer to stop the question; take it back in Dyl-Settings.

AEC Layer Overrides

The keys of AutoCAD Architecture (ANNOBJ, DIMLINE, DOOR...) are in the list too, with their AIA layers. With AutoCAD Architecture, they follow the layer key style of the drawing.

Known Limitations

  • Index colors only.
  • A key changed does not change the layers already made.

The short names are aliases of the command: change them in Dyl-Suite.
