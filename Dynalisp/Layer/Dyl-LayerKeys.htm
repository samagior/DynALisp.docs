Layer Keys

Function Syntax DYL-LAYERKEYS
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Name your layers once and let every tool use them: a layer key is a short name, such as THIN or HATCH, that the DynALisp tools draw on in place of a layer name. Each key gives its layer and the properties to make it with when the drawing does not have it. Change the layer of a key, and every tool that uses it draws there, as the layer keys of AutoCAD Architecture do, in any AutoCAD.

How To Use

  1. Type Dyl-LayerKeys: the Layer Keys window lists every key with its layer and properties.
  2. Select a key and change its layer, color, linetype, lineweight or description; or click New for a key of your own.
  3. Click OK. From then on, the tools draw on the layers of their keys, made with these properties when missing.
  4. The same window opens from the open button beside each layer key of the Hatch Presets window: there, a double-click on a key gives it to the hatch preset.

Layer Keys Dialog

  • Layer key list – one column per value of each key: key, layer, color, linetype, lineweight, plot, its color in the phases (Phase color or Same color) and description, under their titles. The buttons under the list add, copy, delete and reset keys; the Parameters box under them edits the key selected. Its heading says whether the key is (modified) (an edited default key), (custom) (created by the user) or an (AEC layer override) (see AEC Layer Overrides); nothing for a default key with its default values.
  • Filter – lists only the keys that have the text typed in any of their values (key, layer, color, linetype, lineweight, plot, description; any case), for example a-door or hidden. Empty: every key. Beside it, the number of keys listed (12 of 109). The key shown stays listed. Sort by – the order of the list: Key (the default), Layer, Color, Linetype, Lineweight, Description or Status (custom keys, then modified ones, then the AEC layer overrides, then the default keys). The sort is kept until AutoCAD is closed.
  • Several keys at once – Ctrl+click adds a key to the selection (or removes it), Shift+click selects a range. The box reads Parameters (3 selected) and shows the values of the key clicked first: a value changed is given to every key selected, their other values are left as they are. The key name and Copy are greyed out while several are selected; Delete removes them all (only when they are all custom), Reset key resets the default ones among them.
  • Key – the name used by the Apps (upper case). The name of a default key cannot be changed.
  • Layer name, Description, Color, Linetype, Lineweight, Plot – the layer and the properties it is created with. Click the color swatch to pick a color in the AutoCAD color dialog. The linetype is picked from the .lin files of the support path and the linetypes already in the drawing.
  • Phase – every key is phased: while auto-phase is on (see Layer Phase), a key gives its layer in the active phase of the drawing: A-Detl-Thin-E in existing, A-Detl-Thin-N in new work, A-Detl-Thin when auto-phase is off or the drawing has no active phase. The box shows the layer of the active phase.
  • Keep this color in every phase – checked, the layers of the key keep its color in every phase: A-Detl-Thin-E and A-Detl-Thin-D are created with the color of THIN, not the phase colors (20#, 2#), whether they are made by the key or by auto-phase moving an object to its phase. The list shows Same color for these keys.
  • Under the values, the dialog says whether the layer (in the active phase) is missing in the current drawing (created when a key is used), exists with these values, or exists with other values, and which ones (see Layers That Differ From Their Key).
  • New – adds a custom key. Copy – adds a custom key with the values of the selected one. Delete – removes the selected custom key (the layer itself is not deleted).
  • AEC layer overrides – as for any default key, only the key is locked: every other value can be edited (the heading then reads Parameters (AEC layer override, modified)), and Reset key gives it its AIA values back. A grey note under the box says where its layer comes from.
  • Reset key – restores the default values of the selected default key. Restore defaults – restores every default key; custom keys are kept.
  • OK saves LayerKeys.csv, Cancel discards every change. Open Docs opens this page.

Layers That Differ From Their Key

The first time a key gives a layer that already exists in the drawing (in a session), or a Layer Transfer to a phase moves objects to an existing phase layer of a key,its color, linetype, lineweight and plot setting are compared with those of the key (the description is not). In the active phase, the color expected is the phase color, or the key color when the key keeps its color. When they differ, a small window lists the differences (Color: 5 (layer key: 2)) and asks Update the layer to the values of its layer key?

  • Yes – the layer gets the color, linetype (loaded when needed), lineweight and plot setting of the key; its name, description and on / off, frozen and locked states are kept. No – it is used as it is.
  • Either way, it is not asked again for that layer until the drawing is opened again, or until its key changes (a value edited, Keep this color in every phase checked...): OK in the Layer Keys window has every layer checked again against the keys as saved.
  • Remember my answer and do not ask again – checked, the answer is kept for every layer of every drawing: Yes updates them without asking (a line on the command line says so), No keeps them without asking. It is a setting: the Layer keys section of Dyl-Settings shows it and takes it back (both checkboxes off: asked again).
  • The question is only asked while no command is running (an App asks it before it draws); otherwise it is asked the next time the key is used.

AEC Layer Overrides

The keys of the AutoCAD Architecture layer key styles are default keys too, marked AEC layer override. Their layer and properties are those of the AIA (256 Color) layer key style of AutoCAD Architecture (below). As shipped (its AIA values), with AutoCAD Architecture, such a key puts an object on the layer the layer key style of the drawing gives it, exactly as AECREMAPLAYERS does (the command creates the layer, with the properties and overrides of the style, when the drawing does not have it). Without AutoCAD Architecture, when the style of the drawing has no such key, or once the key is edited in the Layer Keys window, its own layer is used, created with its properties. MASS ELEM is not in the AIA (256 Color) style: its layer is named after it (color 7, Continuous, default lineweight). The G-DS-ANNO-STD-* keys are kept for compatibility (the display configurations of AutoCAD Architecture): they are never given to a hatch preset, so the Hatch Presets window does not list them, and a hatch preset that had one gets HATCH instead. A key cannot be resolved while a command or a dialog is active: its own layer is used then too. Only their key is locked; they are not phased unless Phased is checked. The keys of the details (FINE, THIN, MED, WIDE, XLINE, HATCH) stay the DynALisp keys above, editable and phased.

Known Limitations

  • Colors are AutoCAD Color Index values (1–255); true colors and color books are not supported.
  • Editing a key does not update layers already created in drawings.
  • LayerKeys.csv cannot be saved while it is open in Excel: an alert is shown and the changes are lost.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
