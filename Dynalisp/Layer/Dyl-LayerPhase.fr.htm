Phase des calques (Layer Phase)

Syntaxe DYL-LAYERPHASE (PH), PH-E, PH-D, PH-N, PH-F, PH-T, PH-NONE, PH-NEXT, PH-AUTO
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Dessinez chaque phase d'une rénovation sur ses propres calques, et changez de phase en une commande. Un calque en phase finit par un tiret et sa phase : A-Wall-Full-E pour un mur existant à conserver, A-Wall-Full-D à démolir, A-Wall-Full-N pour les travaux neufs (voir Nommage des calques).

Chaque dessin a une phase active, affichée dans la barre d'état et dans le ruban. Avec l'auto-phase activée, tout ce que vous dessinez va dans la phase active : copiez un mur existant pendant la phase des travaux neufs, et la copie arrive sur A-Wall-Full-N.

Utilisation

  1. Choisissez la phase active – tapez PH-E (existant), PH-D (démolition), PH-N (travaux neufs), PH-F (travaux futurs) ou PH-T (travaux temporaires), ou choisissez-la dans la liste déroulante Phase du ruban. Le calque courant passe dans cette phase avec elle : A-Wall-Full-E devient A-Wall-Full-N. PH-NEXT passe à la phase suivante, PH-NONE la retire.
  2. Activez l'auto-phase – tapez PH-AUTO, choisissez Auto-phase activée dans le ruban, ou cochez Auto-phase new objects dans Dyl-Settings. Elle demande les DynALisp reactors activés dans Dyl-Settings; la barre d'état affiche alors [Auto].
  3. Dessinez comme d'habitude – chaque objet que vous créez va sur le calque de sa phase, créé quand le dessin ne l'a pas encore. Les clés de calque donnent aussi leur calque dans la phase active : QD-BRICK dessine sur A-Detl-Medm-E en existant.
  4. Affichez ou masquez une phase – tapez PH pour ouvrir la fenêtre Layer Phases (ci-dessous).

Fenêtre Layer Phases

  • Liste des phases – chaque phase avec son nombre de calques et d'objets dans le dessin, et si ses calques sont Shown, Hidden ou Partial. La phase active est marquée >; Unphased compte les calques sans phase. Sélectionnez plusieurs phases avec Ctrl ou Maj.
  • Double-cliquez une phase pour en faire la phase active (Unphased : aucune phase active).
  • Show / Hide – affiche les phases sélectionnées, ou les masque quand elles sont toutes affichées. Hide les masque quel que soit leur état. Isolate phase les affiche et masque les autres phases (jamais les calques sans phase). Le dessin se met à jour derrière la fenêtre.
  • Layer keys Editor – ouvre la fenêtre Layer Keys, puis revient ici.

Ruban

Le groupe de fonctions Comportements du dessin de l'onglet DynALisp a le bouton Phase des calques (la fenêtre) et deux listes déroulantes : Auto-phase (activée, désactivée; activée (réacteurs désactivés) tant que les réacteurs de DynALisp sont désactivés) et Phase (la phase active du dessin courant). Comme la liste déroulante Calque d'AutoCAD, elles montrent toujours l'état courant. Les listes déroulantes demandent AutoCAD 2025 ou suivant (voir Ruban) : dans une version antérieure, utilisez les alias PH-* et la barre d'état.

Bon à savoir

  • Les calques 0, Defpoints et ceux des xréfs ne reçoivent jamais de phase; les objets sur un calque sans phase y restent, sauf sur le calque d'une clé de calque.
  • Les commandes de modification laissent leurs objets où ils sont : TRIM, BREAK, FILLET, JOIN, EXPLODE, le collage et UNDO ne déplacent jamais rien dans la phase active.
  • Un nouveau calque de phase copie son calque source, avec les couleurs de phase de Layer Transfer pour la démolition et l'existant.
  • La ligne de commande indique combien d'objets ont été déplacés, et avertit quand leur calque est désactivé ou gelé.

Limites connues

  • L'auto-phase déplace les objets juste après leur commande : le premier U les remet sur le calque où ils ont été dessinés, le second annule la commande.
  • La barre d'état n'affiche la phase que quand MODEMACRO n'est pas utilisée par autre chose.
  • Après un UNDO qui ramène une phase précédente, la liste déroulante et la barre d'état ne l'affichent qu'au prochain changement de phase, ou quand le dessin redevient courant.
  • MIRROR avec Erase source objects déplace les objets symétriques dans la phase active, comme toute copie.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-LayerPhase : elles se lancent par leur alias (leur commande se nomme Pst-*).
