Layer Transfer

Function Syntax DYL-LAYERTRANSFER and 58 transfers – see Commands
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Move objects to the same layer of another phase, discipline or level in one command: E-D moves A-Wall-Full-E to A-Wall-Full-D. A missing layer is made for you.

How To Use

  1. Type a transfer, E-D for existing to demolition, then select the objects.
  2. Or, in the Layer Transfer panel of the ribbon, pick what to change, from and to, select the objects and click Transfer.

Phase Transfers

The first letter is the phase now, the second the new one: E existing, D demolition, N new work, R refurbished, M moved, S saved, A abandoned, F future, T temporary, X not in contract, U no phase.

Other Transfers

  • G-ARCHITECTURAL, A-STRUCTURAL... – from one discipline to another.
  • LINE-HIDD and HIDD-LINE – visible to hidden lines, and back.
  • 0001-2... – from one level of a stacked drawing to another.
  • DETL-SECT and SECT-DETL – detail to section, and back.

Known Limitations

  • For a discipline transfer, select only objects of that discipline.
  • Some blocks change for all their copies.
