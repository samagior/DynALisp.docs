Layer Transfer

Function Syntax DYL-LAYERTRANSFER and 58 transfers – see Commands
Source File Modules\Dynalisp\Apps\Layer\Dyl-LayerTransfer.lsp
Requires AutoCAD for Windows (ActiveX / Visual LISP) with ObjectDBX
Licence GNU General Public License v3

Program Description

DYL-LAYERTRANSFER lists every transfer with its alias: double-click one (or OK), then select the objects. The transfers are child commands (Pst-*) run by their aliases, which can be added, renamed or removed in Dyl-Suite (see Command Names And Aliases).

Moves the selected objects to the matching layer of another phase, discipline, stack or view type, by replacing one field of their layer name (e.g. A-Wall-E → A-Wall-D with E-D). Missing target layers are created with the properties of the source layer. Blocks are handled without editing the original block: a renamed copy of the definition is transferred and only the selected references are switched to it.

Ribbon

The Layer Transfer panel of the DynALisp tab holds the Transfer button, three drop-downs and the Manager button. Transfer and the drop-downs transfer any value of a level of the layer names to another one, for the layers named as the NCS (United States National CAD Standard) names them: A-Wall-Full-E is the discipline designator A, the major group Wall, the minor group Full and the status E (see Layer Naming). The Manager button opens the list of transfers (DYL-LAYERTRANSFER).

  • Level – Discipline designator, Major group, Minor group or Status (the phase). The other levels of the names are kept.
  • From – Any, or a value of the level found in the layers of the drawing. None (minor group) or Unphased (status): the layers that have no value for the level.
  • To – shows Select replacement... until a value is picked. The values of the drawing first, then the other values of the AEC lists of DynALisp (Res\AEC\Standard: Dd1.csv and Dd2.csv for the discipline designators, Major.csv, Phase.csv; the minor groups of the drawing only, Minor.csv being too long for a list). None or Unphased removes the level. A value is shown with its description when the AEC lists have it, in the language of the AutoCAD installed (Wall - Wall, Wall - Mur in a French AutoCAD).
  • Picking a value only chooses it. Select the objects, then click Transfer: they are transferred with the Level, From and To shown (with none selected, you are asked to select them). The choice stays, so the next selection is transferred the same way with one click.
  • The lists follow the layers of the current drawing: they are read again after each command and when another drawing is made current. From keeps its value while the drawing has it.
  • With Any, a minor group transfer changes the first minor group of each name, and adds one after the major group to the names that have none (A-Detl-E → A-Detl-Patt-E); a status transfer gives the status to the unphased names too.
  • The Transfer button runs Pst-TransferField (alias LTF, which does the same when typed). Before a To value is picked, or without the drop-downs, it asks for the level, the From value (Enter: any) and the To value (None to remove it).
  • The drop-downs are added by Resources\DynALisp.Ribbon.dll, which needs AutoCAD 2025 or later (see Ribbon). In an older version, the Transfer button asks for the level and the values.

How It Works

  1. Select objects. Objects whose layer contains the source field are pickable, and block references are always pickable so their content can be transferred.
  2. Each selected object is checked: its own layer, its attributes and, for blocks, every entity of the definition (nested blocks included) are tested. Objects with nothing to change are dropped.
  3. The target name of each source layer is computed (see rules below). A missing target layer is created with the linetype, lineweight, plot setting, description and transparency of the source, and a colour shifted for the phase: -D → 2 + last digit, -E → 20 + last digit, unphased from -D/-E → last digit only. A phase layer of a layer key (the target name without its phase, G-Detl-Exst-D → G-Detl-Exst, is the layer of that key) gets the color of its key in that phase instead: the phase color of the key color, or the key color itself when the key keeps it in every phase (Keep this color in every phase) or the transfer is to unphased.
  4. A target layer of a layer key that already exists is checked against its key (color in that phase, linetype, lineweight, plot), as when an App uses the key: when it differs, the same window lists the differences and asks whether to update it to its key, before the objects are moved (Yes / No, Remember my answer; see Layer Keys – Layers That Differ From Their Key).
  5. If a source layer is off, frozen or locked, an alert lists it and nothing is changed.
  6. In one UNDO group, objects and attributes are moved to their target layers. A block whose content changes is copied (through ObjectDBX, which keeps dynamic block data) to a new name – 2X6 → 2X6-N, 2X6-E → 2X6-N – the copy is transferred and the selected references are pointed to it, with their dynamic property values restored. A copy made by an earlier run is reused.

Name Rules

  • Phase – the suffix is replaced at the end of the name (A-Wall-E → A-Wall-D). A name ending with a 4-character field and no phase (A-Wall-Full) gets the new suffix appended. The Unphased commands remove the suffix.
  • Designator – the first occurrence of the discipline letter is replaced.
  • Major – the first occurrence after the designator is replaced (e.g. Detl ↔ Sect).
  • Minor – the first occurrence from the 8th character on is replaced (Line ↔ Hidd, stack numbers).
  • Level (the Transfer button of the ribbon and LTF) – the name is read as an NCS name: a discipline designator of 1 or 2 letters, a major group of 4 characters, minor groups of 4 characters (none or more) and an optional status of 1 character, divided by -. Only that level is replaced, so a designator transfer never touches the other levels. The layers with other names (0, Defpoints, the layers of the xrefs...) are left as they are.

Known Limitations

  • Designator transfers replace the first matching letter anywhere in the name (e.g. G-ARCHITECTURAL on A-Glaz gives A-Alaz): select only objects on layers of the source discipline.
  • Anonymous blocks cannot be renamed and are transferred in place, which affects all their references.
  • Command line messages for empty selections are in French.
