Export Layers To CSV

Function Syntax DYL-LAYEREXPORTTOCSV
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Writes every layer of the current drawing and its properties to a CSV file that opens directly in Excel. The file uses the same columns as the layer presets read by Import Layers From CSV, so an export can be edited and imported back into another drawing.

Commands

CommandNameDescription
DYL-LAYEREXPORTTOCSVExport Layers To CSVExports every layer of the drawing with its properties to a CSV file in the Downloads folder.

Known Limitations

  • The file name only contains the date: a second export on the same day overwrites the first one.
  • True colours are exported as their nearest index colour.
  • The load message mentions EXPORTLAYERS; the command name is DYL-LAYEREXPORTTOCSV.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
