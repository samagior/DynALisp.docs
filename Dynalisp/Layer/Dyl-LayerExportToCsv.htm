Export Layers To CSV

Function Syntax DYL-LAYEREXPORTTOCSV
Works with Import Layers From CSV – brings the file into a drawing

Program Description

Save every layer and its properties in a file for Excel. Edit it, then bring it into another drawing with Import Layers From CSV.

How To Use

  1. Type Dyl-LayerExportToCsv.
  2. The file goes in your Downloads folder.

Known Limitations

  • A second export the same day replaces the first.
  • True colors become their nearest index color.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
