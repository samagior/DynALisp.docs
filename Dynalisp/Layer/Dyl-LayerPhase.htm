Layer Phase

Function Syntax DYL-LAYERPHASE (PH), PH-E, PH-D, PH-N, PH-F, PH-T, PH-NONE, PH-NEXT, PH-AUTO
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Draw each phase of a renovation on its own layers, and switch phase in one command: existing, demolition, new work. A wall copied during new work lands on A-Wall-Full-N by itself.

How To Use

  1. Pick the phase: PH-E existing, PH-D demolition, PH-N new work, PH-F future, PH-T temporary. Or use the Phase list of the ribbon.
  2. Type PH-AUTO so that what you draw goes to that phase.
  3. Type PH to show, hide or isolate a phase.

Good To Know

  • A phase layer ends with its letter: A-Wall-Full-E (see Layer Naming).
  • Trim, fillet, explode, paste and undo never change the phase of an object.

Known Limitations

  • After a command, the first U undoes the change of phase, the second the command.

The short names are aliases of the command: change them in Dyl-Suite. The rows marked ↳ are its variants, run by their short name.
