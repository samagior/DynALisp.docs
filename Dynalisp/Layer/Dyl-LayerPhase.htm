Layer Phase

Function Syntax DYL-LAYERPHASE (PH), PH-E, PH-D, PH-N, PH-F, PH-T, PH-NONE, PH-NEXT, PH-AUTO
Source File Modules\Dynalisp\Apps\Layer\Dyl-LayerPhase.lsp (commands), Modules\Dynalisp\Remote\Dyl-LayerPhase.lsp (active phase and the auto-phase setting, loaded at startup) and Modules\Dynalisp\Reactor\Dyl-LayerPhase.lsp (auto-phase reactors, loaded at startup while the DynALisp reactors are on)
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

A phased layer ends with a dash and a phase code: A-Wall-Full-E (existing to remain), A-Wall-Full-D (existing to demolish), A-Wall-Full-N (new work), A-Wall-Full-F (future work)... The codes and their descriptions are read from Modules\Dynalisp\Res\AEC\Standard\Phase.csv (its Description.fr column gives the French descriptions, shown in the status bar, the Layer Phases window, the command line and the ribbon in a French AutoCAD, whatever the Language of Dyl-Settings, which is the language of the docs only); the phase is the status field of the layer names (see Layer Naming).

Each drawing has an active phase, saved in the drawing. It is shown in the status bar (Phase: N - New Work [Auto]) and switched in one command with the PH-* aliases. Switching the phase also moves the current layer to the new phase (A-Wall-Full-E becomes A-Wall-Full-N), and while auto-phase is on, the layer keys marked Phased give their layer in the active phase: QD-BRICK draws its outline on A-Detl-Medm-E and its hatch on A-Detl-Patt-E in existing.

With auto-phase on, every object created by a command goes to the active phase: a copy of an existing wall on A-Wall-Full-E lands on A-Wall-Full-N while the active phase is new work. Objects on layers without a phase are not changed, except on the layers of the layer keys, which get the phase added.

Ribbon

  • Layer Phase – the button of the Drawing Behaviors panel of the DynALisp tab opens the Layer Phases dialog.
  • Auto-phase drop-down – Auto-phase On or Auto-phase Off, as PH-AUTO and the Auto-phase new objects setting of Dyl-Settings. It reads Auto-phase On (reactors off) while the DynALisp reactors are off: auto-phase is on but does nothing until they are turned on.
  • Phase drop-down – the active phase of the current drawing (None, then every phase of Phase.csv). Pick a phase to make it the active phase, as the PH-* aliases do.
  • Like the Layer drop-down of AutoCAD, both always show the current state, whatever changed it (an alias, the dialog, Dyl-Settings, another drawing made current). Picking an item cancels the command running, as the buttons of the ribbon do.
  • The drop-downs are added by Resources\DynALisp.Ribbon.dll, which needs AutoCAD 2025 or later (see Ribbon). In an older version, the Drawing Behaviors panel has only the Layer Phase button: use the PH-* aliases and the status bar.

Layer Phases Dialog

  • Active phase and current layer, at the top.
  • Phase list – every phase of Phase.csv with the number of layers and objects of the drawing in that phase, and whether its layers are Shown, Hidden or Partial (some hidden). The first line, Unphased, counts the layers without a phase (marked > when there is no active phase). The active phase is marked with >. Several phases can be selected.
  • Double-click a phase to make it the active phase (the instruction is shown above the list). Double-click Unphased to clear the active phase.
  • Show / Hide – one button that follows the selection: it reads Hide when every selected phase is shown, and then turns their layers off and freezes them (the current layer is only turned off); otherwise it reads Show and turns them on and thaws them. Hide – the opposite of Show: turns off and freezes the layers of the selected phases, whatever their state (disabled when they are all hidden already). Isolate phase – shows the selected phases and hides the other phases; the unphased layers are never hidden by it (they are shown when Unphased is selected). Show / Hide and Hide also work on the Unphased line. Xref layers are included. The drawing is regenerated at once, so the change shows behind the dialog without closing it.
  • Layer keys Editor – opens the Layer Keys dialog (every layer key is phased while auto-phase is on).
  • Auto-phase is turned on or off in Dyl-Settings (Auto-phase new objects, next to the open button that opens this window) or with PH-AUTO. It runs only while the DynALisp reactors of Dyl-Settings are on (greyed out there otherwise, and the status bar no longer shows [Auto]).

How It Works

  1. The active phase is saved in the drawing (dictionary dyl-layer), so each drawing keeps its own phase. Auto-phase is a user setting (DynalispPhaseAuto, off by default): it is on or off in every drawing, and a drawing already open follows a change when it is made current.
  2. Auto-phase watches the objects added to the drawing and moves them when the command that created them ends (an object cannot be changed while it is being added). Objects created by a Lisp command are moved when the Lisp command ends.
  3. Only objects in model space and in the layouts are moved; block definitions are never changed. The attributes of a block reference follow it.
  4. A layer of the active phase that the drawing does not have yet is created from the source layer: same linetype, lineweight, plot setting and description, and the phase colors of Layer Transfer (2# for existing to demolish, 20# for existing to remain). The layer of a layer key that keeps its color in every phase (Layer Keys, Keep this color in every phase) gets the color of its key instead.
  5. Layers 0, Defpoints and xref layers are never phased.
  6. The objects created by commands that edit or split existing objects (BREAK, TRIM, FILLET, PEDIT, JOIN, EXPLODE...) or bring objects in (PASTECLIP, COPYTOLAYER, XBIND...) and by UNDO / REDO are left on their layer. The list can be replaced with the DynalispPhaseSkip environment variable, for example (setenv "DynalispPhaseSkip" "U,UNDO,EXPLODE,BREAK,TRIM,PASTE*").
  7. The command line says how many objects were moved, and names the target layers that are off or frozen.

Using Phases In An App

  • (Remote>>Dyl:PhaseGet) – returns the active phase code ("N"), or nil when there is none.
  • (Remote>>Dyl:PhaseSet "N") – sets the active phase (nil: no phase).
  • (Remote>>Dyl:PhaseLayer "A-Wall-Full-E" "N") – returns "A-Wall-Full-N", created if missing.
  • (Remote>>Dyl:LayerKeyLayer "THIN") – gives the layer of the key in the active phase while auto-phase is on.

Known Limitations

  • Auto-phase moves the objects after their command, as a separate step: the first U after a command puts the objects back on the layer they were created on, the second one undoes the command.
  • The status bar shows the phase only when MODEMACRO is not used by something else.
  • The Phase drop-down follows the changes made by DynALisp. An UNDO that takes the drawing back before a phase change gives the drawing its former phase, but the drop-down shows it only after the next change of phase or when the drawing is made current again (the status bar does the same).
  • MIRROR with Erase source objects moves the mirrored objects to the active phase like any copy.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-LayerPhase: they are run by their alias (their command is named Pst-*).
