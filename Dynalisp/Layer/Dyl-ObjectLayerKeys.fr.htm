Clés de calque des objets (Object Layer Keys)

Syntaxe DYL-OBJECTLAYERKEYS
Fichier source Modules\Dynalisp\Apps\Layer\Dyl-ObjectLayerKeys.lsp (fenêtre), Modules\Dynalisp\Remote\Dyl-LayerKey.lsp (types, clés, paramètre) et Modules\Dynalisp\Reactor\Dyl-ObjectLayerKeys.lsp (réacteurs)
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Donne à chaque type d'objet courant une clé de calque par défaut, comme le font les clés de calque d'AutoCAD Architecture : une cote dessinée avec DIM va sur le calque de DIMLINE, un texte sur le calque de ANNOBJ, quel que soit le calque courant. Cela fonctionne tant que Auto layer keys est activé (Dyl-Settings, Reactors, désactivé par défaut); son bouton ouvrir y ouvre aussi cette fenêtre.

Fenêtre Object Layer Keys

  • Liste – chaque type d'objet, sa clé de calque ((none) : laissé sur le calque courant) et le calque qu'elle donne dans ce dessin (dans la phase active tant que l'auto-phase est activée; created when used quand le dessin ne l'a pas encore). Plusieurs types peuvent être sélectionnés (Ctrl / Maj clic) pour leur donner une clé d'un coup.
  • Layer key – la clé des types sélectionnés, choisie parmi les clés de calque; (None: the current layer) les laisse comme AutoCAD les dessine. Le bouton carré ouvrir à côté ouvre la fenêtre Layer Keys : modifiez-y les clés, ou double-cliquez-en une pour la donner aux types sélectionnés (les clés sont enregistrées, puis cette fenêtre se rouvre).
  • Reset Selected / Reset All – les clés par défaut des types sélectionnés, ou de tous les types.
  • Sous les boutons, si Auto layer keys est activé. OK enregistre les clés, Cancel annule les changements, Open Docs ouvre cette page.

Fonctionnement

  1. Pendant qu'une commande s'exécute, les nouveaux objets sont rassemblés; à sa fin, chacun d'un type qui a une clé va sur le calque de cette clé (créé avec les propriétés de la clé quand le dessin ne l'a pas, libéré s'il est gelé, voir Layer Keys). Un message en donne le nombre.
  2. Tant que l'auto-phase est activée, le calque de la clé est celui de la phase active (G-Anno-Dims-E).
  3. Les objets faits par une commande Lisp sont laissés tels quels : les outils DynALisp (Quick Draw, Quick Shape...) mettent les leurs sur leurs propres clés de calque.
  4. Les copies gardent le calque de leur original : les objets faits par COPY, MIRROR, ARRAY, OFFSET, une copie par poignées, un collage, une insertion, une décomposition et les autres commandes qui modifient ou apportent des objets (celles de l'auto-phase) sont laissés sur leur calque. Les objets d'une définition de bloc ne changent jamais, ni la fenêtre de l'espace papier d'une présentation.
  5. Aucune fenêtre ne peut s'ouvrir depuis un réacteur : un calque qui diffère de sa clé est vérifié la prochaine fois qu'un outil utilise la clé (Layers That Differ From Their Key). Une dérogation de calque AEC telle que livrée y utilise son propre calque (le style de clés de calque du dessin est lu par une commande, qui ne peut pas s'exécuter depuis un réacteur).
  6. Les clés sont enregistrées dans Modules\Dynalisp\Res\ObjectLayerKeys.csv (sa copie sous User) : une rangée par type, son identifiant et sa clé. Un type absent du fichier reçoit sa clé par défaut.

Limites connues

  • Auto layer keys demande les réacteurs DynALisp (Dyl-Settings).
  • Les objets dessinés avec une commande Lisp d'un autre programme ne sont pas déplacés.
  • ObjectLayerKeys.csv ne peut pas être enregistré pendant qu'il est ouvert dans Excel : une alerte s'affiche et les changements sont perdus.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
