Layer Filters

Function Syntax DYL-LAYERFILTER and 46 presets – see Commands
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Set up the layer visibility of a view in one word: show or hide a phase, isolate one level of a stacked drawing, screen the other disciplines... In model space the layers themselves change; in a layout the same filter applies to the viewports you select only, as viewport overrides.

How To Use

  1. Type the alias of the view: SH-EXST to show the existing layers, HI-ANNO to hide the annotation, N2 for the new work of level 2... (the table below).
  2. Or type Dyl-LayerFilter: the window lists every filter with its alias; double-click one (or OK).
  3. In a layout, select the viewports to filter when asked; the other objects of the selection are left out.
  4. A filter marked Reset hides everything first and shows only its layers; one marked Keep is applied on top of what is shown now. One U goes back.

Layer Names

The filters read the names made of fields divided by hyphens: the last field can be a phase, and a field can be a level of a stacked drawing (0001 to 0009, as in A-Wall-0002-N, for elevations or floors drawn in one file). See Layer Naming.

SuffixPhase
-EExisting to remain
-DExisting to demolish
-NNew work
-RBeing refurbished
-MBeing moved
-STo be saved
-AAbandoned
-FFuture work
-TTemporary work
-XNot in contract

Known Limitations

  • Every model space run resets the transparency and lock of all layers, including those screened or locked by hand.
  • Xref layers are meant to be screened when the xref drawing is found in a Model views sub-folder of the drawing folder, but the xref name is compared with the file name including .dwg, so this never matches.
  • Screening relies on layer transparency: turn on TRANSPARENCYDISPLAY to see it.
