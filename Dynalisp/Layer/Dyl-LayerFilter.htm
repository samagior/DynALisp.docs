Layer Filters

Function Syntax DYL-LAYERFILTER and 46 presets – see Commands
Source File Modules\Dynalisp\Apps\Layer\Dyl-LayerFilter.lsp
Requires AIA / NCS style layer names; AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

DYL-LAYERFILTER lists every filter preset with its alias: double-click one (or OK) to apply it. The presets are child commands (Pst-*) run by their aliases, which can be added, renamed or removed in Dyl-Suite (see Command Names And Aliases).

One-word commands that set up the layer visibility for a type of view: show or hide a phase, isolate one level of a stacked drawing, screen the other disciplines, and so on. In model space the layers themselves are changed; in a layout the same filter is applied as viewport overrides on the viewports you select.

The program works with layer names built from fields separated by hyphens, where the last field can be a phase suffix and a field can be a stack (level) number:

SuffixPhase
-EExisting to remain
-DExisting to demolish
-NNew work
-RBeing refurbished
-MBeing moved
-STo be saved
-AAbandoned
-FFuture work
-TTemporary work
-XNot in contract

Stack numbers are four-digit fields 0001 to 0009 (e.g. A-Wall-0002-N), used for stacked elevations or floors drawn in the same file.

How It Works

Each command is a preset made of five pattern lists (show, hide, secondary show, secondary hide, screen), a lock flag and a start state. When the command runs:

  1. Xrefs – xrefs inserted on a layer that has the same name as the xref (sheet set convention) have that layer added to the show list, along with layers 0 and Defpoints.
  2. Tokens – group names in the lists are expanded into wildcard patterns (see table below).
  3. Phases – for Existing views, -E and -X variants of the show patterns are added; New views also add -N -R -M; Demolition views add -D -S -T.
  4. Model space – an UNDO mark is set, every layer is reset to 0% transparency and unlocked; presets with a Reset start state then set layer 0 current and turn off and freeze every layer. -LAYER then turns on/thaws the show lists and turns off/freezes the hide lists (primary first, secondary last, so the secondary lists win), applies 50% transparency to the screen list, optionally locks it, and regenerates.
  5. Paper space – select the viewports (other objects are ignored). The same lists are applied with VPLAYER (freeze/thaw and 50% transparency) to the selected viewports only; the layers themselves are not changed.
  6. If the command fails, the drawing is rolled back to the UNDO mark.

Known Limitations

  • Every model space run resets the transparency and lock of all layers, including those screened or locked by hand.
  • Xref layers are meant to be screened when the xref drawing is found in a Model views sub-folder of the drawing folder, but the xref name is compared with the file name including .dwg, so this never matches.
  • Screening relies on layer transparency: turn on TRANSPARENCYDISPLAY to see it.
