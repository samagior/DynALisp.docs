Layer Filters

Function Syntax DYL-LAYERFILTER and 46 presets – see Commands
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Set up what a view shows in one word: show or hide a phase, isolate one level, screen the existing. In a layout, it applies to the viewports you select.

How To Use

  1. Type a filter: SH-EXST shows the existing, HI-ANNO hides the annotation, N2 shows the new work of level 2.
  2. Or type Dyl-LayerFilter and double-click one.
  3. One U goes back.

The Filters

  • SH-* show and HI-* hide: all, non-plotting, new work, demolition, existing, key plan.
  • SC-EXST screens the existing.
  • E1–E9, D1–D9, N1–N9 show the existing, demolition or new work of one level, the levels above screened.
  • They read the phase at the end of the layer names (see Layer Naming).

Known Limitations

  • In model space, it resets the layers you screened or locked by hand.
  • Turn on TRANSPARENCYDISPLAY to see the screening.
