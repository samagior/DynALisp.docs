Transfert de calques (Layer Transfer)

Syntaxe DYL-LAYERTRANSFER et 58 transferts – voir Commandes
Requis AutoCAD pour Windows (ActiveX / Visual LISP) avec ObjectDBX
Licence Licence publique générale GNU v3

Description

Déplacez des objets vers le calque correspondant d'une autre phase, discipline, niveau ou genre de vue, en une commande : A-Wall-Full-E devient A-Wall-Full-D avec E-D. Un calque manquant est créé avec les propriétés de celui d'où il vient. Les blocs sont transférés sans toucher l'original : une copie du bloc est transférée et seules les références sélectionnées l'utilisent.

Utilisation

  1. Tapez l'alias du transfert : E-D (existant vers démolition), E-N, N-E... (le tableau ci-dessous), puis sélectionnez les objets.
  2. Ou tapez Dyl-LayerTransfer : la fenêtre liste chaque transfert avec son alias; double-cliquez-en un, puis sélectionnez les objets.
  3. Dans le ruban (AutoCAD 2025 et suivants), choisissez le niveau, la valeur à transférer et la nouvelle valeur dans les listes déroulantes du groupe de fonctions Transfert de calques, sélectionnez les objets, puis cliquez Transférer.
  4. La ligne de commande liste les calques créés et les calques sources désactivés, verrouillés ou gelés.

Ruban

Le groupe de fonctions Transfert de calques de l'onglet DynALisp contient le bouton Transférer, trois listes déroulantes et le bouton Gestion. Transférer et les listes déroulantes transfèrent toute valeur d'un niveau des noms de calques vers une autre, pour les calques nommés comme le fait la NCS (United States National CAD Standard) : A-Wall-Full-E est la désignation de discipline A, le groupe majeur Wall, le groupe mineur Full et le statut E (voir Nommage des calques). Le bouton Gestion ouvre la liste des transferts (DYL-LAYERTRANSFER).

  • Niveau – Désignation de discipline, Groupe principal, Groupe secondaire ou Statut (la phase). Les autres niveaux des noms sont gardés.
  • De – Toutes, ou une valeur du niveau trouvée dans les calques du dessin. Aucune (groupe secondaire) ou Sans phase (statut) : les calques qui n'ont pas de valeur pour ce niveau.
  • À – affiche Choisir la valeur... tant qu'aucune valeur n'est choisie. Les valeurs du dessin d'abord, puis les autres valeurs des listes AEC de DynALisp (Res\AEC\Standard : Dd1.csv et Dd2.csv pour les désignations de discipline, Major.csv, Phase.csv; seulement les groupes mineurs du dessin, Minor.csv étant trop long pour une liste). Aucune ou Sans phase retire le niveau. Une valeur est affichée avec sa description quand les listes AEC l'ont, dans la langue de l'AutoCAD installé (Wall - Mur dans un AutoCAD français).
  • Choisir une valeur ne fait que la choisir. Sélectionnez les objets, puis cliquez Transférer : ils sont transférés avec le Niveau, le De et le À affichés (si aucun n'est sélectionné, vous êtes invité à les sélectionner). Le choix reste : la sélection suivante est transférée de la même façon d'un clic.
  • Les listes suivent les calques du dessin courant : elles sont relues après chaque commande et quand un autre dessin devient courant. De garde sa valeur tant que le dessin l'a.
  • Avec Toutes, un transfert de groupe mineur change le premier groupe mineur de chaque nom, et en ajoute un après le groupe majeur aux noms qui n'en ont pas (A-Detl-E → A-Detl-Patt-E); un transfert de statut donne le statut aux noms sans phase aussi.
  • Le bouton Transférer lance Pst-TransferField (alias LTF, qui fait de même quand il est tapé). Avant qu'une valeur À soit choisie, ou sans les listes déroulantes, il demande le niveau, la valeur De (Entrée : toutes) et la valeur À (None pour la retirer).
  • Les listes déroulantes sont ajoutées par Resources\DynALisp.Ribbon.dll, qui demande AutoCAD 2025 ou suivant (voir Ruban). Dans une version antérieure, le bouton Transférer demande le niveau et les valeurs.

Limites connues

  • Les transferts de désignation remplacent la première lettre correspondante n'importe où dans le nom (p. ex. G-ARCHITECTURAL sur A-Glaz donne A-Alaz) : ne sélectionnez que des objets sur des calques de la discipline source.
  • Les blocs anonymes ne peuvent pas être renommés et sont transférés sur place, ce qui touche toutes leurs références.
  • Les messages de la ligne de commande pour les sélections vides sont en français.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-LayerTransfer : elles se lancent par leur alias, ou se choisissent dans Dyl-LayerTransfer quand elle les liste (leur commande se nomme Pst-*).
