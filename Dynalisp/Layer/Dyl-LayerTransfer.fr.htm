Transfert de calques (Layer Transfer)

Syntaxe DYL-LAYERTRANSFER et 58 transferts – voir Commandes
Fichier source Modules\Dynalisp\Apps\Layer\Dyl-LayerTransfer.lsp
Requis AutoCAD pour Windows (ActiveX / Visual LISP) avec ObjectDBX
Licence Licence publique générale GNU v3

Description

DYL-LAYERTRANSFER liste chaque transfert avec son alias : double-cliquez-en un (ou OK), puis sélectionnez les objets. Les transferts sont des commandes enfants (Pst-*) lancées par leurs alias, qui s'ajoutent, se renomment ou se retirent dans Dyl-Suite (voir Noms des commandes et alias).

Déplace les objets sélectionnés sur le calque correspondant d'une autre phase, discipline, pile ou type de vue, en remplaçant un champ de leur nom de calque (p. ex. A-Wall-E → A-Wall-D avec E-D). Les calques cibles manquants sont créés avec les propriétés du calque source. Les blocs sont traités sans modifier le bloc original : une copie renommée de la définition est transférée et seules les références sélectionnées passent à elle.

Ruban

Le groupe de fonctions Transfert de calques de l'onglet DynALisp contient le bouton Transférer, trois listes déroulantes et le bouton Gestion. Transférer et les listes déroulantes transfèrent toute valeur d'un niveau des noms de calques vers une autre, pour les calques nommés comme le fait la NCS (United States National CAD Standard) : A-Wall-Full-E est la désignation de discipline A, le groupe majeur Wall, le groupe mineur Full et le statut E (voir Nommage des calques). Le bouton Gestion ouvre la liste des transferts (DYL-LAYERTRANSFER).

  • Niveau – Désignation de discipline, Groupe principal, Groupe secondaire ou Statut (la phase). Les autres niveaux des noms sont gardés.
  • De – Toutes, ou une valeur du niveau trouvée dans les calques du dessin. Aucune (groupe secondaire) ou Sans phase (statut) : les calques qui n'ont pas de valeur pour ce niveau.
  • À – affiche Choisir la valeur... tant qu'aucune valeur n'est choisie. Les valeurs du dessin d'abord, puis les autres valeurs des listes AEC de DynALisp (Res\AEC\Standard : Dd1.csv et Dd2.csv pour les désignations de discipline, Major.csv, Phase.csv; seulement les groupes mineurs du dessin, Minor.csv étant trop long pour une liste). Aucune ou Sans phase retire le niveau. Une valeur est affichée avec sa description quand les listes AEC l'ont, dans la langue de l'AutoCAD installé (Wall - Mur dans un AutoCAD français).
  • Choisir une valeur ne fait que la choisir. Sélectionnez les objets, puis cliquez Transférer : ils sont transférés avec le Niveau, le De et le À affichés (si aucun n'est sélectionné, vous êtes invité à les sélectionner). Le choix reste : la sélection suivante est transférée de la même façon d'un clic.
  • Les listes suivent les calques du dessin courant : elles sont relues après chaque commande et quand un autre dessin devient courant. De garde sa valeur tant que le dessin l'a.
  • Avec Toutes, un transfert de groupe mineur change le premier groupe mineur de chaque nom, et en ajoute un après le groupe majeur aux noms qui n'en ont pas (A-Detl-E → A-Detl-Patt-E); un transfert de statut donne le statut aux noms sans phase aussi.
  • Le bouton Transférer lance Pst-TransferField (alias LTF, qui fait de même quand il est tapé). Avant qu'une valeur À soit choisie, ou sans les listes déroulantes, il demande le niveau, la valeur De (Entrée : toutes) et la valeur À (None pour la retirer).
  • Les listes déroulantes sont ajoutées par Resources\DynALisp.Ribbon.dll, qui demande AutoCAD 2025 ou suivant (voir Ruban). Dans une version antérieure, le bouton Transférer demande le niveau et les valeurs.

Fonctionnement

  1. Sélectionnez les objets. Les objets dont le calque contient le champ source peuvent être choisis, et les références de blocs le peuvent toujours pour que leur contenu puisse être transféré.
  2. Chaque objet sélectionné est vérifié : son propre calque, ses attributs et, pour les blocs, chaque entité de la définition (blocs imbriqués compris) sont testés. Les objets sans rien à changer sont retirés.
  3. Le nom cible de chaque calque source est calculé (voir les règles ci-dessous). Un calque cible manquant est créé avec le type de ligne, l'épaisseur de ligne, le réglage de traçage, la description et la transparence de la source, et une couleur décalée selon la phase : -D → 2 + dernier chiffre, -E → 20 + dernier chiffre, sans phase depuis -D/-E → dernier chiffre seulement. Un calque de phase d'une clé de calque (le nom cible sans sa phase, G-Detl-Exst-D → G-Detl-Exst, est le calque de cette clé) reçoit plutôt la couleur de sa clé dans cette phase : la couleur de phase de la couleur de la clé, ou la couleur de la clé elle-même quand la clé la garde dans chaque phase (Keep this color in every phase) ou que le transfert est vers sans phase.
  4. Un calque cible d'une clé de calque qui existe déjà est comparé à sa clé (couleur dans cette phase, type de ligne, épaisseur de ligne, traçage), comme quand une App utilise la clé : s'il diffère, la même fenêtre liste les différences et demande s'il faut le mettre à jour selon sa clé, avant que les objets soient déplacés (Yes / No, Remember my answer; voir Layer Keys – Layers That Differ From Their Key).
  5. Si un calque source est désactivé, gelé ou verrouillé, une alerte le liste et rien ne change.
  6. En un seul groupe d'annulation, les objets et les attributs sont déplacés sur leurs calques cibles. Un bloc dont le contenu change est copié (par ObjectDBX, qui garde les données des blocs dynamiques) sous un nouveau nom – 2X6 → 2X6-N, 2X6-E → 2X6-N – la copie est transférée et les références sélectionnées pointent vers elle, avec leurs valeurs de propriétés dynamiques rétablies. Une copie faite par une exécution antérieure est réutilisée.

Règles de nom

  • Phase – le suffixe est remplacé à la fin du nom (A-Wall-E → A-Wall-D). Un nom qui finit par un champ de 4 caractères sans phase (A-Wall-Full) reçoit le nouveau suffixe à la fin. Les commandes Unphased retirent le suffixe.
  • Désignation – la première occurrence de la lettre de discipline est remplacée.
  • Majeur – la première occurrence après la désignation est remplacée (p. ex. Detl ↔ Sect).
  • Mineur – la première occurrence à partir du 8e caractère est remplacée (Line ↔ Hidd, numéros de pile).
  • Niveau (le bouton Transférer du ruban et LTF) – le nom est lu comme un nom NCS : une désignation de discipline de 1 ou 2 lettres, un groupe majeur de 4 caractères, des groupes mineurs de 4 caractères (aucun ou plusieurs) et un statut facultatif de 1 caractère, séparés par -. Seul ce niveau est remplacé : un transfert de désignation ne touche donc jamais les autres niveaux. Les calques aux autres noms (0, Defpoints, les calques des xréfs...) restent tels quels.

Limites connues

  • Les transferts de désignation remplacent la première lettre correspondante n'importe où dans le nom (p. ex. G-ARCHITECTURAL sur A-Glaz donne A-Alaz) : ne sélectionnez que des objets sur des calques de la discipline source.
  • Les blocs anonymes ne peuvent pas être renommés et sont transférés sur place, ce qui touche toutes leurs références.
  • Les messages de la ligne de commande pour les sélections vides sont en français.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-LayerTransfer : elles se lancent par leur alias, ou se choisissent dans Dyl-LayerTransfer quand elle les liste (leur commande se nomme Pst-*).
