Module Dynalisp

Le module Dynalisp regroupe les programmes maison de DynALisp : outils de dessin et de hachures, normes de calques (création, phases, filtres, transferts), unités de dessin, grilles et échelles, configuration de l'environnement, utilitaires généraux et diagnostics qui trouvent ce qui ne va pas. Il compte 44 programmes et 306 commandes : 44 commandes principales, 251 commandes enfants et les 11 commandes AutoCAD redéfinies par Command Optimizer.

Chaque fenêtre de DynALisp a un bouton Open Docs, à côté de ses boutons OK / Cancel ou Close, qui ouvre sa page de ces docs (la fenêtre reste ouverte). Les docs s'ouvrent dans la langue de DynALisp (Language dans Dyl-Settings), en anglais pour une page pas encore traduite; le sélecteur EN | FR en haut à droite de chaque page passe d'une langue à l'autre. Les fenêtres, le ruban et les commandes de DynALisp sont en anglais : les pages citent leurs libellés tels qu'ils apparaissent.

Chaque programme a une commande principale nommée Dyl-*. Ses préréglages et variantes sont des commandes enfants (Pst-*), lancées par leurs alias (les noms courts, p. ex. QD-CONCRETE) ou choisies depuis la commande principale. Dans Dyl-Suite, une commande principale qui a des commandes enfants affiche [+] / [-] : double-cliquez-la (ou Fold/Unfold) pour afficher ou masquer ses commandes enfants; double-cliquez toute autre commande (ou Command docs) pour ouvrir sa page, les commandes sans page propre ouvrant cet index. La liste se trie par commande, alias, nom, module ou groupe avec Sort by, chaque commande principale gardant ses commandes enfants sous elle. Les alias s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
