Color ByLayer

Function Syntax CHCOLOR, CC
Licence GNU General Public License v3

Program Description

Two quick color clean-ups: put a selection back to the color of its layer, or give it one color picked in the AutoCAD color window.

How To Use

  1. Back to ByLayer – type CHCOLOR, select the objects (or select them first), press Enter. Their color is now ByLayer.
  2. One color for all – type CC, pick a color in the Select Color window, then select the objects and press Enter.

Commands

CommandNameDescription
CHCOLORColor ByLayerSets the color of the selected objects to ByLayer.
CCChange ColorSets the color of the selected objects to a color picked in the color window.

Known Limitations

  • In CC, cancelling the color window opens it again: pick any color, then press Esc at the selection prompt.
  • The color window of CC has the index colors only: no true colors or color books.
  • Objects on locked layers are not changed.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-ColorByLayer: they are run by their alias, or picked from Dyl-ColorByLayer when it lists them (their command is named Pst-*).
