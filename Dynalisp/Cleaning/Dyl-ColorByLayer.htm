Color ByLayer

Function Syntax CHCOLOR, CC
Source File Modules\Dynalisp\Apps\Cleaning\Dyl-ColorByLayer.lsp
Licence GNU General Public License v3

Program Description

Two quick colour clean-up commands: one resets the colour of a selection to ByLayer, the other applies a colour picked in the standard AutoCAD colour dialog.

Commands

CommandNameDescription
CHCOLORColor ByLayerSets the color of the selected objects to ByLayer.
CCChange ColorSets the color of the selected objects to a color picked in the color dialog.

How It Works

CHCOLOR

  1. Select the objects (any selection method, pre-selection supported).
  2. The routine runs CHPROP → Color → BYLAYER on the selection and reports Objects' color changed to Bylayer.

CC

  1. The Select Color dialog opens (index colours only, ByLayer shown as the default).
  2. At the prompt Select all object to change to one color. select the objects.
  3. CHPROP applies the chosen colour to the selection.

Known Limitations

  • In CC, cancelling the colour dialog reopens it: pick any colour, then press Esc at the selection prompt to abort.
  • True colours and colour books are not available from the dialog used by CC.
  • Objects on locked layers are skipped by CHPROP.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-ColorByLayer: they are run by their alias, or picked from Dyl-ColorByLayer when it lists them (their command is named Pst-*).
