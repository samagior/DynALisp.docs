Color ByLayer

Function Syntax CHCOLOR, CC
Licence GNU General Public License v3

Program Description

Put objects back to the color of their layer, or give them one color.

How To Use

  1. Back to ByLayer – type CHCOLOR, select the objects, press Enter.
  2. One color for all – type CC, pick a color, select the objects, press Enter.

Known Limitations

  • CC offers the index colors only.
  • Objects on locked layers are not changed.
