Data Links

Function Syntax DYL-DATALINKS, DLPURGE
Source File Modules\Dynalisp\Apps\Cleaning\Dyl-DataLinks.lsp
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

A data link connects tables to an Excel file. Links are left behind when their tables are erased or when tables are copied from another drawing, and links whose Excel file was moved or deleted slow down DATALINKUPDATE and the Update all data links output prep step of Dyl-Settings. These commands find those links and delete them. The tables themselves are never modified or deleted.

Commands

CommandDescription
DYL-DATALINKSOpens the Data Links dialog: every link with its status and its tables, to review and delete them.
DLPURGEDeletes every link that no table uses after one Yes/No prompt, then lists the used links whose Excel file is missing.

Data Links Dialog

  • Data link list – name, status, number of tables using the link and source file. Several links can be selected. Status: OK (the Excel file was found), Missing file (it was not found) or No source (the link has no file).
  • Under the list: the full source of the selected link (file, sheet and range) and the layouts of the tables that use it, or a summary of the drawing when nothing is selected.
  • Select unused – selects every link no table uses. Select missing file – selects every link whose Excel file was not found.
  • Delete selected – deletes the selected links after a confirmation. When some are used by tables, the confirmation says so: the tables keep their content but are no longer linked to Excel.
  • Update tables – closes the dialog, runs DATALINKUPDATE on the tables of the selected links, then reopens the dialog.
  • Data Link Manager... – closes the dialog and opens the AutoCAD Data Link Manager, to change the file of a link or detach it from a table.

How It Works

  1. The links are read from the ACAD_DATALINK dictionary of the drawing.
  2. A link is used when a table of the drawing points to it, or when the link lists a table that still exists as one of its users. Both checks are made so that a link is never reported unused by mistake.
  3. The source file is read from the connection string of the link. A relative path is looked up from the drawing folder.
  4. Each delete runs in one undo group: U restores the deleted links.

Known Limitations

  • Tables are found in model space and the layouts. A link used only by a table inside a block definition can be reported unused if the link does not list that table itself; Update tables skips those tables.
  • A file on a disconnected network drive is reported Missing file.
