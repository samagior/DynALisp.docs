Data Links

Function Syntax DYL-DATALINKS, DLPURGE
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Find and delete the Excel data links a drawing no longer needs. Links stay behind when their tables are erased or copied from another drawing, and a link whose Excel file was moved slows down every update of the data links. The tables themselves are never changed or deleted.

How To Use

  1. The quick way – type DLPURGE: it names the links no table uses and asks to delete them (Yes by default), then names the used links whose Excel file is missing.
  2. To review them first – type Dyl-DataLinks. The Data Links window lists every link of the drawing.
  3. Click Select unused or Select missing file, check the list, then click Delete selected.
  4. One U brings the deleted links back.

Data Links Window

  • The list – each link with its status, the number of tables using it and its Excel file. OK: the file was found; Missing file: it was not; No source: the link has no file. Select several links with Ctrl or Shift.
  • Under the list, the full source of the link selected (file, sheet and range) and the layouts of its tables, or a summary of the drawing.
  • Select unused, Select missing file – select every link of that kind.
  • Delete selected – deletes the selected links after a confirmation. A table that used one keeps its content, no longer linked to Excel.
  • Update tables – updates the tables of the selected links from Excel, then comes back to the window.
  • Data Link Manager... – opens the AutoCAD Data Link Manager, to give a link another file or detach it from a table.

Commands

CommandDescription
Dyl-DataLinksOpens the Data Links window, to review and delete the links.
DLPURGEDeletes every link no table uses after one Yes/No prompt, then names the used links whose Excel file is missing.

Known Limitations

  • A link used only by a table inside a block can show as unused; Update tables skips those tables (update them from the Data Link Manager).
  • A file on a disconnected network drive shows as Missing file.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-DataLinks: they are run by their alias, or picked from Dyl-DataLinks when it lists them (their command is named Pst-*).
