Data Links

Function Syntax DYL-DATALINKS, DLPURGE
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Delete the Excel data links your drawing no longer needs. Your tables stay as they are.

How To Use

  1. Quick – type DLPURGE and answer Yes.
  2. To review first – type Dyl-DataLinks, click Select unused or Select missing file, then Delete selected.
  3. One U brings them back.

Data Links Window

  • The list – each link, its status, its tables and its Excel file.
  • Update tables – refreshes the tables of the selected links from Excel.
  • Data Link Manager... – to give a link another file.

Known Limitations

  • A link used only by a table inside a block may show as unused.
  • A file on a disconnected network drive shows as Missing file.
