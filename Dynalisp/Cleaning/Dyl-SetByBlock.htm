Fix Blocks ByBlock

Function Syntax FIXBLKS, SL-BLOCKALL
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence FIXBLKS: routine by Tom Beauford; SL-BLOCKALL: GNU General Public License v3

Program Description

Make blocks follow the properties of where they are inserted: everything inside the selected blocks goes to layer 0, with ByBlock color, linetype and lineweight. Insert the block on any layer, and it takes the color and linetype of that layer.

How To Use

  1. Type FIXBLKS and select one reference of each block to fix, then press Enter.
  2. Every reference of those blocks in the drawing changes, the selected ones and all the others, and the blocks nested inside them too.
  3. To fix every block of the drawing, type SL-BLOCKALL first: it selects every block reference; then run FIXBLKS.

Commands

CommandNameDescription
FIXBLKSFix Blocks ByBlockMoves the content of the selected blocks to layer 0 with ByBlock color, linetype and lineweight.
SL-BLOCKALLSelect All BlocksSelects every block reference in the drawing.

Good To Know

  • The whole change is one step: one U undoes it.
  • The block definitions change, not the references: the position, scale and layer of each reference stay as they are.

Known Limitations

  • The attributes already filled in the references keep their properties; only the attribute definitions inside the block change.
  • Pressing Enter with nothing selected ends FIXBLKS with an error.
  • Plot styles are not changed.
