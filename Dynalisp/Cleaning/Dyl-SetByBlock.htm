Fix Blocks ByBlock

Function Syntax FIXBLKS, SL-BLOCKALL

Program Description

Make blocks take the color and linetype of the layer you insert them on.

How To Use

  1. Type FIXBLKS, select one of each block to fix, press Enter.
  2. Every copy of those blocks changes.
  3. To fix them all, type SL-BLOCKALL first, then FIXBLKS.

Good To Know

  • One U undoes it.
  • Attributes already filled in keep their properties.
