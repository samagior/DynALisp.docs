Fix Blocks ByBlock

Function Syntax FIXBLKS, SL-BLOCKALL
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence FIXBLKS: routine by Tom Beauford; SL-BLOCKALL: GNU General Public License v3

Program Description

Normalises block definitions so that their content follows the properties of the block reference: every entity inside the selected definitions is moved to layer 0 with ByBlock colour, linetype and lineweight. A companion command selects every block reference of the drawing.

Commands

CommandNameDescription
FIXBLKSFix Blocks ByBlockMoves the entities of the selected block definitions to layer 0 with ByBlock color, linetype and lineweight.
SL-BLOCKALLSelect All BlocksSelects every block reference in the drawing.

Known Limitations

  • Attributes already attached to existing references keep their properties; only the attribute definitions inside the block are changed.
  • Pressing Enter at the selection prompt with nothing selected ends FIXBLKS with an error.
  • Plot style names are not changed (the line is commented out in the source).

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
