Couleur DuCalque (Color ByLayer)

Syntaxe CHCOLOR, CC
Licence Licence publique générale GNU v3

Description

Deux commandes rapides de nettoyage des couleurs : l'une ramène la couleur d'une sélection à DuCalque, l'autre applique une couleur choisie dans la boîte de dialogue des couleurs standard d'AutoCAD.

Commandes

CommandeNomDescription
CHCOLORColor ByLayerRègle la couleur des objets sélectionnés sur DuCalque.
CCChange ColorRègle la couleur des objets sélectionnés sur une couleur choisie dans la boîte de dialogue des couleurs.

Limites connues

  • Dans CC, annuler la boîte de dialogue des couleurs la rouvre : choisissez une couleur quelconque, puis appuyez sur Échap à l'invite de sélection pour abandonner.
  • Les couleurs vraies et les carnets de couleurs ne sont pas offerts par la boîte de dialogue qu'utilise CC.
  • CHPROP ignore les objets sur des calques verrouillés.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-ColorByLayer : elles se lancent par leur alias, ou se choisissent dans Dyl-ColorByLayer quand elle les liste (leur commande se nomme Pst-*).
