Blocs DuBloc (Fix Blocks ByBlock)

Syntaxe FIXBLKS, SL-BLOCKALL
Fichier source Modules\Dynalisp\Apps\Cleaning\Dyl-SetByBlock.lsp
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence FIXBLKS : routine de Tom Beauford; SL-BLOCKALL : licence publique générale GNU v3

Description

Normalise les définitions de blocs pour que leur contenu suive les propriétés de la référence de bloc : chaque entité des définitions sélectionnées est placée sur le calque 0 avec couleur, type de ligne et épaisseur de ligne DuBloc. Une commande complémentaire sélectionne chaque référence de bloc du dessin.

Commandes

CommandeNomDescription
FIXBLKSFix Blocks ByBlockPlace les entités des définitions de blocs sélectionnées sur le calque 0, avec couleur, type de ligne et épaisseur de ligne DuBloc.
SL-BLOCKALLSelect All BlocksSélectionne chaque référence de bloc du dessin.

Fonctionnement

FIXBLKS

  1. Sélectionnez des références de blocs (la sélection est filtrée sur les objets INSERT).
  2. Pour la définition de chaque référence sélectionnée, la routine parcourt chaque entité de la définition :
    • les références de blocs imbriquées sont suivies et leurs propres définitions corrigées aussi (chaque définition une fois);
    • les autres entités reçoivent le calque 0, la couleur DuBloc, le type de ligne DuBloc et l'épaisseur de ligne DuBloc. Les échecs (p. ex. entités en lecture seule) sont ignorés.
  3. Les changements sont regroupés dans un seul groupe d'annulation et le dessin est régénéré.

Comme c'est la définition qui est modifiée, chaque référence du même bloc dans le dessin change, pas seulement celles sélectionnées.

SL-BLOCKALL

Construit une sélection de chaque référence de bloc du dessin (tous les espaces, xréfs comprises) et l'affiche avec ses poignées par PSELECT, pour la donner à la commande suivante.

Limites connues

  • Les attributs déjà attachés aux références existantes gardent leurs propriétés; seules les définitions d'attributs dans le bloc changent.
  • Appuyer sur Entrée à l'invite de sélection sans rien sélectionner termine FIXBLKS par une erreur.
  • Les noms de styles de tracé ne sont pas changés (la ligne est en commentaire dans la source).

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-SetByBlock : elles se lancent par leur alias, ou se choisissent dans Dyl-SetByBlock quand elle les liste (leur commande se nomme Pst-*).
