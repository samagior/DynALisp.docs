Blocs DuBloc (Fix Blocks ByBlock)

Syntaxe FIXBLKS, SL-BLOCKALL
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence FIXBLKS : routine de Tom Beauford; SL-BLOCKALL : licence publique générale GNU v3

Description

Faites suivre aux blocs les propriétés de l'endroit où ils sont insérés : tout ce qui est dans les blocs sélectionnés passe sur le calque 0, avec la couleur, le type de ligne et l'épaisseur de ligne DuBloc. Insérez le bloc sur n'importe quel calque, il prend la couleur et le type de ligne de ce calque.

Utilisation

  1. Tapez FIXBLKS et sélectionnez une référence de chaque bloc à corriger, puis appuyez sur Entrée.
  2. Chaque référence de ces blocs dans le dessin change, celles sélectionnées et toutes les autres, ainsi que les blocs imbriqués dedans.
  3. Pour corriger chaque bloc du dessin, tapez d'abord SL-BLOCKALL : il sélectionne chaque référence de bloc; lancez ensuite FIXBLKS.

Commandes

CommandeNomDescription
FIXBLKSFix Blocks ByBlockPasse le contenu des blocs sélectionnés sur le calque 0 avec la couleur, le type de ligne et l'épaisseur de ligne DuBloc.
SL-BLOCKALLSelect All BlocksSélectionne chaque référence de bloc du dessin.

Bon à savoir

  • Tout le changement est une seule étape : un U l'annule.
  • Les définitions de blocs changent, pas les références : la position, l'échelle et le calque de chaque référence restent les mêmes.

Limites connues

  • Les attributs déjà remplis dans les références gardent leurs propriétés; seules les définitions d'attributs dans le bloc changent.
  • Appuyer sur Entrée sans rien sélectionner termine FIXBLKS par une erreur.
  • Les styles de tracé ne sont pas modifiés.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-SetByBlock : elles se lancent par leur alias, ou se choisissent dans Dyl-SetByBlock quand elle les liste (leur commande se nomme Pst-*).
