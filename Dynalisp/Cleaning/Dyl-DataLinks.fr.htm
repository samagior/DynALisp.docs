Liaisons de données (Data Links)

Syntaxe DYL-DATALINKS, DLPURGE
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Supprimez les liaisons de données Excel dont votre dessin n'a plus besoin. Vos tableaux restent tels quels.

Utilisation

  1. Rapide – tapez DLPURGE et répondez Oui.
  2. Pour vérifier d'abord – tapez Dyl-DataLinks, cliquez Select unused ou Select missing file, puis Delete selected.
  3. Un U les ramène.

Fenêtre Data Links

  • La liste – chaque liaison, son état, ses tableaux et son fichier Excel.
  • Update tables – met à jour depuis Excel les tableaux des liaisons choisies.
  • Data Link Manager... – pour donner un autre fichier à une liaison.

Limites connues

  • Une liaison utilisée seulement par un tableau dans un bloc peut paraître inutilisée.
  • Un fichier sur un lecteur réseau déconnecté paraît Missing file.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite. Les rangées marquées ↳ sont ses variantes, lancées par leur nom court.

CommandeAliasNom
Dyl-DataLinks–Data Links
  ↳ DLPURGE–Purge Data Links
