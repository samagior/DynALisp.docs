Liaisons de données (Data Links)

Syntaxe DYL-DATALINKS, DLPURGE
Fichier source Modules\Dynalisp\Apps\Cleaning\Dyl-DataLinks.lsp
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Une liaison de données relie des tableaux à un fichier Excel. Des liaisons restent derrière quand leurs tableaux sont effacés ou quand des tableaux sont copiés d'un autre dessin, et les liaisons dont le fichier Excel a été déplacé ou supprimé ralentissent DATALINKUPDATE et l'étape de préparation de sortie Update all data links de Dyl-Settings. Ces commandes trouvent ces liaisons et les suppriment. Les tableaux eux-mêmes ne sont jamais modifiés ni supprimés.

Commandes

CommandeDescription
DYL-DATALINKSOuvre la fenêtre Data Links : chaque liaison avec son état et ses tableaux, pour les examiner et les supprimer.
DLPURGESupprime, après une seule question Oui/Non, chaque liaison qu'aucun tableau n'utilise, puis liste les liaisons utilisées dont le fichier Excel est manquant.

Fenêtre Data Links

  • Liste des liaisons – nom, état, nombre de tableaux qui utilisent la liaison et fichier source. Plusieurs liaisons peuvent être sélectionnées. État : OK (le fichier Excel a été trouvé), Missing file (il est introuvable) ou No source (la liaison n'a pas de fichier).
  • Sous la liste : la source complète de la liaison sélectionnée (fichier, feuille et plage) et les présentations des tableaux qui l'utilisent, ou un résumé du dessin quand rien n'est sélectionné.
  • Select unused – sélectionne chaque liaison qu'aucun tableau n'utilise. Select missing file – sélectionne chaque liaison dont le fichier Excel est introuvable.
  • Delete selected – supprime les liaisons sélectionnées après confirmation. Quand certaines sont utilisées par des tableaux, la confirmation le dit : les tableaux gardent leur contenu mais ne sont plus liés à Excel.
  • Update tables – ferme la fenêtre, exécute DATALINKUPDATE sur les tableaux des liaisons sélectionnées, puis rouvre la fenêtre.
  • Data Link Manager... – ferme la fenêtre et ouvre le Gestionnaire des liaisons de données d'AutoCAD, pour changer le fichier d'une liaison ou la détacher d'un tableau.

Fonctionnement

  1. Les liaisons sont lues dans le dictionnaire ACAD_DATALINK du dessin.
  2. Une liaison est utilisée quand un tableau du dessin pointe vers elle, ou quand la liaison liste parmi ses utilisateurs un tableau qui existe encore. Les deux vérifications sont faites pour qu'une liaison ne soit jamais signalée inutilisée par erreur.
  3. Le fichier source est lu dans la chaîne de connexion de la liaison. Un chemin relatif est cherché à partir du dossier du dessin.
  4. Chaque suppression se fait dans un seul groupe d'annulation : U rétablit les liaisons supprimées.

Limites connues

  • Les tableaux sont cherchés dans l'espace objet et les présentations. Une liaison utilisée seulement par un tableau dans une définition de bloc peut être signalée inutilisée si la liaison ne liste pas elle-même ce tableau; Update tables ignore ces tableaux.
  • Un fichier sur un lecteur réseau déconnecté est signalé Missing file.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-DataLinks : elles se lancent par leur alias, ou se choisissent dans Dyl-DataLinks quand elle les liste (leur commande se nomme Pst-*).
