Liaisons de données (Data Links)

Syntaxe DYL-DATALINKS, DLPURGE
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Trouvez et supprimez les liaisons de données Excel dont un dessin n'a plus besoin. Les liaisons restent quand leurs tables sont effacées ou copiées d'un autre dessin, et une liaison dont le fichier Excel a été déplacé ralentit chaque mise à jour des liaisons de données. Les tables elles-mêmes ne sont jamais modifiées ni supprimées.

Utilisation

  1. La façon rapide – tapez DLPURGE : il nomme les liaisons qu'aucune table n'utilise et propose de les supprimer (Oui par défaut), puis nomme les liaisons utilisées dont le fichier Excel est introuvable.
  2. Pour les vérifier d'abord – tapez Dyl-DataLinks. La fenêtre Data Links liste chaque liaison du dessin.
  3. Cliquez Select unused ou Select missing file, vérifiez la liste, puis cliquez Delete selected.
  4. Un U ramène les liaisons supprimées.

Fenêtre Data Links

  • La liste – chaque liaison avec son état, le nombre de tables qui l'utilisent et son fichier Excel. OK : le fichier a été trouvé; Missing file : il ne l'a pas été; No source : la liaison n'a pas de fichier. Sélectionnez plusieurs liaisons avec Ctrl ou Maj.
  • Sous la liste, la source complète de la liaison sélectionnée (fichier, feuille et plage) et les présentations de ses tables, ou un résumé du dessin.
  • Select unused, Select missing file – sélectionnent chaque liaison de ce genre.
  • Delete selected – supprime les liaisons sélectionnées après une confirmation. Une table qui en utilisait une garde son contenu, sans liaison à Excel.
  • Update tables – met à jour depuis Excel les tables des liaisons sélectionnées, puis revient à la fenêtre.
  • Data Link Manager... – ouvre le Gestionnaire des liaisons de données d'AutoCAD, pour donner un autre fichier à une liaison ou la détacher d'une table.

Commandes

CommandeDescription
Dyl-DataLinksOuvre la fenêtre Data Links, pour vérifier et supprimer les liaisons.
DLPURGESupprime chaque liaison qu'aucune table n'utilise après une question Oui/Non, puis nomme les liaisons utilisées dont le fichier Excel est introuvable.

Limites connues

  • Une liaison utilisée seulement par une table dans un bloc peut paraître inutilisée; Update tables ignore ces tables (mettez-les à jour depuis le Gestionnaire des liaisons de données).
  • Un fichier sur un lecteur réseau déconnecté paraît Missing file.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-DataLinks : elles se lancent par leur alias, ou se choisissent dans Dyl-DataLinks quand elle les liste (leur commande se nomme Pst-*).
