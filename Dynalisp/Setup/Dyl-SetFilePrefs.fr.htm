Préférences de fichiers (Set File Preferences)

Syntaxe DYL-SETFILEPREFS
Requis AutoCAD pour Windows (ActiveX / Visual LISP); AutoCAD Architecture pour les chemins AEC
État Nouveau – voir Limites connues
Licence Licence publique générale GNU v3

Description

Réglez les chemins d'AutoCAD selon votre façon de travailler, à partir de trois choix : la classification de la bibliothèque AEC, les unités de dessin et la langue du contenu. Les gabarits, le contenu, les catalogues d'outils et les bases de détails d'AutoCAD Architecture, et les dictionnaires de l'orthographe suivent. Vos autres options sont gardées : DynALisp les règle dans un profil à lui.

Utilisation

  1. Dans Dyl-Settings, cochez File Preferences (dans Overrides) et cliquez son bouton ouvrir.
  2. Choisissez les trois préférences ci-dessous, et s'il faut utiliser le dictionnaire personnalisé DynALisp de la langue, puis enregistrez.
  3. AutoCAD utilise maintenant le profil DynALisp (Options > Profils), créé la première fois comme copie de votre profil courant. Il reste courant pour les sessions suivantes.
  4. Ou tapez Dyl-SetFilePrefs : les mêmes choix à la ligne de commande (Entrée garde le choix courant).

Les préférences

  • Classification de la bibliothèque AEC – NBS CAWS (Global), CSI MasterFormat (US) ou OmniClass : les composants de détail et les notes clés d'AutoCAD Architecture.
  • Unités de dessin – Metric (Global) ou Imperial (US) : les gabarits et les dossiers de contenu.
  • Langue – une des langues dans lesquelles AutoCAD est installé (anglais, français, allemand, espagnol...) : le contenu d'AutoCAD Architecture et l'orthographe. Par défaut, la langue d'AutoCAD. Ce n'est pas la langue de DynALisp et de ses docs, choisie à part dans la section Environment de Dyl-Settings.

Orthographe

  • Le vérificateur d'orthographe utilise le dictionnaire principal de la langue; AutoCAD n'en a pas pour le chinois, le hongrois, le japonais, le coréen ni le polonais, qui utilisent l'anglais américain.
  • En français, le dictionnaire personnalisé DynALisp ajoute environ 4 450 mots d'architecture et de construction, les chiffres romains et les sigles des plans québécois (CNB, RBQ, CSA...). Les mots que vous ajoutez en vérifiant l'orthographe sont gardés dans votre propre copie. Voir Dictionary.

Bon à savoir

  • Chaque dessin ouvert vérifie le profil. Quand il n'est plus courant, ou que les préférences ont changé, la dernière ligne du démarrage vous dit de lancer Dyl-SetFilePrefs : un dessin ne change jamais le profil de lui-même.
  • Désactivez File Preferences dans Dyl-Settings pour revenir à votre profil précédent; le profil DynALisp est gardé.
  • Chaque langue d'AutoCAD (anglais, français...) a ses propres profils : le profil DynALisp est créé dans chacune.

Commandes

CommandeNomDescription
DYL-SETFILEPREFSSet File PreferencesDemande les préférences de fichiers et règle le profil DynALisp à partir d'elles.

Limites connues

  • AutoCAD Architecture n'a pas de base de détails ni de notes clés OmniClass : OmniClass n'en règle aucune.
  • Seul le contenu installé est utilisé : une langue ou des unités dont le contenu d'AutoCAD Architecture n'est pas installé laissent ces chemins tels qu'ils sont.
  • La langue d'AutoCAD elle-même ne change pas : elle est choisie au démarrage d'AutoCAD.
  • Tant que le profil DynALisp est activé, passer à la main à un autre profil donne un rappel dans chaque dessin ouvert; désactivez File Preferences pour utiliser un autre profil.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
