Préférences de fichiers (Set File Preferences)

Syntaxe DYL-SETFILEPREFS
Fichiers source Modules\Dynalisp\Apps\Setup\Dyl-SetFilePrefs.lsp (commande), Modules\Dynalisp\Remote\Dyl-FilePrefs.lsp (profil, vérifié dans chaque dessin), Modules\Dynalisp\Res\FilePrefs.csv (chemins)
Requis AutoCAD pour Windows (ActiveX / Visual LISP); AutoCAD Architecture pour les chemins AEC
État Nouveau – voir Limites connues
Licence Licence publique générale GNU v3

Description

Règle les chemins d'AutoCAD à partir de trois préférences de fichiers, choisies dans Dyl-Settings (le bouton ouvrir de File Preferences, dans Overrides, ouvre la fenêtre des préférences de fichiers) ou avec cette commande :

  • AEC library classification : NBS CAWS (Global), CSI MasterFormat (US) ou OmniClass;
  • Drawing units : Metric (Global) ou Imperial (US);
  • Language : l'une des langues dans lesquelles AutoCAD s'installe – anglais, français, chinois (simplifié), chinois (traditionnel), tchèque, allemand, hongrois, italien, japonais, coréen, polonais, portugais (Brésil), russe ou espagnol. C'est la langue du contenu d'AutoCAD Architecture et du correcteur d'orthographe. Par défaut, la langue d'AutoCAD.

Cette langue est celle des dessins (dossiers de contenu, dictionnaires). La langue de DynALisp lui-même, ses docs, se règle à part : Language dans la section Environment de Dyl-Settings.

La langue règle aussi le dictionnaire principal du correcteur d'orthographe (Options > Fichiers > Éditeur de texte, dictionnaire et noms de fichiers de polices > Dictionnaire principal, DCTMAIN). AutoCAD n'a pas de dictionnaire pour le chinois, le hongrois, le japonais, le coréen ni le polonais (pas de fichier <code>.dct dans son dossier Support) : le dictionnaire anglais américain (enu) est utilisé pour ces langues.

En français, le dictionnaire personnalisé (DCTCUST) est réglé sur Res\Dictionaries\fra.cus : environ 4 450 mots français d'architecture et de construction et des chiffres romains (I à C et les centaines jusqu'à M, les siècles Ier à XXIe, i à xx en minuscules pour les listes numérotées; structure, enveloppe du bâtiment, ouvertures, intérieurs, dessins et site, mécanique et électricité, matériaux comme le néoprène, le polyéthylène ou la géomembrane et leurs sigles, aciers inoxydables (austénitique, duplex, passivation) et corrosion des métaux, adjuvants et traitements de protection, styles architecturaux, formes et ornements des bâtiments, églises, patrimoine bâti, restauration traditionnelle de la pierre, ferblanterie, charpente lourde et maisons pièce-sur-pièce, mots composés comme anti-rafale, pare-vapeur ou sous-plancher, calcul des structures, chantier et contrats, accessibilité) et les sigles utilisés sur les plans québécois (CNB, RBQ, CSA, ULC...). AutoCAD utilise votre copie sous User\, faite la première fois, et les mots que vous ajoutez en vérifiant l'orthographe y vont; Dyl-UserFiles peut faire de cette copie le fichier par défaut. Ses mots, avec leur définition et leur catégorie, se cherchent dans la fenêtre Dictionary (Res\Dictionaries\fra-def.csv). Décochez Use the DynALisp custom dictionary of the language dans la fenêtre File Preferences de Dyl-Settings (ou répondez Non dans DYL-SETFILEPREFS) pour garder le vôtre. Il n'est utilisé que si la langue en a un : une rangée Files:CustomDictionary de FilePrefs.csv y correspond et son fichier existe. Sinon (désactivé, ou autre langue), un dictionnaire personnalisé de DynALisp qui est courant est remplacé par celui qu'il avait remplacé, sinon par le sample.cus d'AutoCAD; un dictionnaire personnalisé à vous est laissé tel quel. Ajoutez une rangée Files:CustomDictionary pour donner le sien à une autre langue.

Les chemins sont réglés dans un profil DynALisp (Options > Profils), créé la première fois comme copie du profil courant : vos autres options sont donc conservées. AutoCAD le garde courant pour les sessions suivantes, et chaque dessin ouvert vérifie qu'il est toujours courant et réglé selon les préférences.

Commandes

CommandeNomDescription
DYL-SETFILEPREFSSet File PreferencesDemande les préférences de fichiers et règle le profil DynALisp à partir d'elles.

Fonctionnement

  1. Dans Dyl-Settings, cochez File Preferences (Overrides), choisissez les préférences dans sa fenêtre (son bouton ouvrir) et enregistrez. DYL-SETFILEPREFS demande les mêmes préférences à la ligne de commande (Entrée garde la valeur courante) et active le profil.
  2. La première fois, le profil DynALisp est créé comme copie du profil courant, mémorisé comme sa base.
  3. Les rangées de Res\FilePrefs.csv qui correspondent aux préférences donnent les chemins. Pour chaque réglage, la première rangée correspondante dont le fichier ou le dossier existe est utilisée; les rangées suivantes sont des solutions de repli. Un réglage sans rangée correspondante est laissé tel quel.
  4. Les options d'AutoCAD Architecture dans le registre sont écrites pendant que le profil n'est pas courant, puis le profil est rendu courant. AutoCAD garde le profil courant en mémoire et relit un profil quand il est rendu courant. Les options de l'onglet Fichiers sont ensuite réglées dans le profil courant, et le dictionnaire principal de la langue avec elles.
  5. Chaque dessin ouvert ne fait que vérifier le profil : un avertissement à la dernière ligne du résumé de démarrage (--> ... run Dyl-SetFilePrefs ...) vous dit de lancer DYL-SETFILEPREFS quand le profil n'est pas courant, ou quand les préférences ou FilePrefs.csv ont changé depuis son réglage. Un dessin ne rend jamais le profil courant lui-même : un profil rendu courant pendant l'ouverture d'un dessin recharge les menus de chaque dessin ouvert et peut arrêter AutoCAD. Il règle toutefois les dictionnaires principal et personnalisé des préférences, dans le profil courant quel qu'il soit : un raccourci qui démarre AutoCAD avec un autre profil (/p "AutoCAD Architecture (Global)") a donc quand même la bonne orthographe.
  6. Désactivé dans Dyl-Settings, le profil de base redevient courant. Le profil DynALisp est conservé.

Fichier des chemins

Modules\Dynalisp\Res\FilePrefs.csv (une copie sous User\ est utilisée quand il y en a une, voir Dyl-UserFiles), un chemin par rangée : Setting;Classification;Units;Language;Value.

  • Setting :
    • Files:<property> règle une option de l'onglet Fichiers, par exemple Files:TemplateDwgPath ou Files:QNewTemplateFile.
    • Reg:<key>|<value>[,<value>...] règle des valeurs du profil dans le registre, par exemple Reg:Preferences\AecGuiBase80|SILocationRoot (le dossier de contenu des styles AEC).
    • Aec:<key>|<value>[,<value>...] règle une option d'AutoCAD Architecture partagée par tous les profils de cet AutoCAD (sous AEC\<version>), par exemple Aec:General\Tools|ToolContentRoot (le chemin racine du contenu du catalogue d'outils). AutoCAD Architecture la lit à son démarrage, et elle reste réglée quand le profil est désactivé.
    • Db:Components et Db:Keynotes règlent les bases de données courantes des composants de détail et des notes clés. Une base pas encore inscrite dans AutoCAD Architecture est ajoutée à sa liste sous l'identifiant écrit dans le fichier de la base (lu avec PowerShell), puisqu'AutoCAD Architecture connaît une base par cet identifiant.
  • Classification (CAWS, MasterFormat, OmniClass), Units (Metric, Imperial), Language (English, French, German, Chinese-Simplified...) donnent la préférence visée par la rangée. * ou vide correspond à toutes.
  • Value est un chemin (plusieurs chemins sont séparés par ;). {ACA} est le dossier de contenu d'AutoCAD Architecture de la langue (C:\ProgramData\Autodesk\ACA 2027\enu, fra, deu..., trouvé à partir du dossier de contenu AEC du profil). {ACA*} essaie le dossier de contenu de chaque langue installée, celle choisie en premier : une base absente de ce contenu est trouvée dans celui de l'autre langue. {DYL} est Modules\Dynalisp\Res. {DYLU} est sa copie utilisateur sous User\ : le fichier y est copié de son fichier par défaut la première fois, pour un fichier dans lequel AutoCAD écrit, comme un dictionnaire personnalisé qui reçoit les mots ajoutés en vérifiant l'orthographe. Un nom de fichier peut utiliser * et ? (AecDtlComponents*.mdb) : le premier fichier correspondant du dossier est utilisé.

Les rangées par défaut règlent le dossier de gabarits et le gabarit QNEW de DynALisp, le dictionnaire personnalisé français, et règlent les dossiers de contenu AEC, de styles, IFC et de gabarits de projet et le chemin racine du contenu du catalogue d'outils selon les unités et la langue. Elles règlent aussi les bases courantes des composants de détail et des notes clés (Configurer les bases de données de composants de détail / notes clés), cherchées dans le contenu installé et ajoutées à la liste d'AutoCAD Architecture quand elles y manquent :

  • NBS CAWS : Details (Global) en métrique (repli sur Details (UK)), Details (UK) en impérial (repli sur Global). Les deux utilisent les groupes CAWS (D - Groundwork, E - In Situ Concrete...).
  • CSI MasterFormat : Details (FR) en français (repli sur Details (US)), Details (US) en anglais (repli sur Details (FR)), pour les deux unités.
  • Chacune est prise dans le contenu de la langue choisie, sinon dans celui de l'autre langue installée. Le contenu anglais 2027 n'a pas de dossier US ni FR : MasterFormat en anglais utilise donc les bases US du contenu français.

Limites connues

  • AutoCAD Architecture ne fournit pas de base de composants de détail ni de notes clés OmniClass : OmniClass ne règle donc aucune base. Ajoutez des rangées Db: pour les vôtres.
  • Seul le contenu installé est utilisé. Le contenu anglais d'ACA 2027 n'a pas de dossiers Imperial ni US ici, et le contenu français n'a pas de dossier Global : les rangées de repli (ou aucune) s'appliquent donc.
  • La langue est celle des dossiers de contenu et du dictionnaire principal. Elle ne change pas la langue d'AutoCAD lui-même, choisie au démarrage d'AutoCAD. Une langue dont le contenu d'AutoCAD Architecture n'est pas installé laisse les chemins {ACA} tels quels.
  • Chaque langue d'AutoCAD (anglais, français...) a ses propres profils : le profil DynALisp est créé dans chacune.
  • Tant que le profil est activé et que vous passez à un autre profil à la main, chaque dessin ouvert vous rappelle de lancer DYL-SETFILEPREFS. Désactivez-le dans Dyl-Settings pour utiliser un autre profil.
  • Acad (Imperial Ctb).dwt n'est pas dans Res\Templates\Model : l'impérial utilise donc Acad (Imperial Stb).dwt.
