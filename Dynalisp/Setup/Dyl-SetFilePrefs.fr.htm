Préférences de fichiers (Set File Preferences)

Syntaxe DYL-SETFILEPREFS
Requis AutoCAD 2025 ou plus récent pour Windows; AutoCAD Architecture pour les chemins AEC
État Nouveau – voir Limites connues
Licence Licence publique générale GNU v3

Description

Réglez les dossiers d'AutoCAD selon votre façon de travailler : votre classification, vos unités et votre langue. Les gabarits, le contenu d'AutoCAD Architecture et le correcteur d'orthographe suivent. Vos propres options restent intactes.

Utilisation

  1. Dans Dyl-Settings, activez File Preferences et cliquez son bouton carré.
  2. Choisissez vos trois préférences, puis enregistrez.
  3. AutoCAD utilise maintenant le profil DynALisp. Désactivez File Preferences pour revenir à votre ancien profil.

Les préférences

  • AEC library classification – NBS CAWS, CSI MasterFormat ou OmniClass.
  • Drawing units – métrique ou impérial.
  • Content language – la langue du contenu et du correcteur d'orthographe.
  • Use the custom dictionary of the language – ajoute des milliers de mots de la construction au correcteur (Dictionnaire).

Limites connues

  • OmniClass n'a pas de contenu de détails ni de notes clés dans AutoCAD Architecture.
  • Seul le contenu installé avec AutoCAD est utilisé.
