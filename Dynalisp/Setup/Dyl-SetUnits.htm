Set Units

Function Syntax DYL-SETUNITS and 4 unit settings (UNITS-M0, UNITS-M1, UNITS-M2, UNITS-I16)
Source File Modules\Dynalisp\Apps\Setup\Dyl-SetUnits.lsp
Licence GNU General Public License v3

Program Description

DYL-SETUNITS lists every unit setting with its alias: double-click one (or OK) to apply it. The unit settings are child commands (Pst-*) run by their aliases, which can be added, renamed or removed in Dyl-Suite (see Command Names And Aliases).

Four shortcuts that set the drawing units format and precision in one step, for metric drawings at 1, 0.1 or 0.01 mm and for imperial drawings at 1/16″.

Commands

CommandNameDescription
UNITS-M0Units Metric 1 mmSets the drawing units to decimal with a 1 mm precision.
UNITS-M1Units Metric 0.1 mmSets the drawing units to decimal with a 0.1 mm precision.
UNITS-M2Units Metric 0.01 mmSets the drawing units to decimal with a 0.01 mm precision.
UNITS-I16Units Imperial 1/16 inSets the drawing units to architectural with a 1/16 in precision.

How It Works

Each command sets the unit system variables (LUNITS, LUPREC, AUNITS, AUPREC, ANGBASE, ANGDIR) and prints a confirmation:

CommandLengthLength precisionAngleAngle precision
UNITS-M0Decimal0Decimal degrees0
UNITS-M1Decimal0.0Decimal degrees0.0
UNITS-M2Decimal0.00Decimal degrees0.00
UNITS-I16Architectural1/16Decimal degrees0

All four set the base angle to East (0°) and angles counter-clockwise.

Drawing Defaults

In Dyl-Settings, the open button of Drawing Settings (in Overrides; unchecked, no drawing is checked) opens the window that picks the units of the imperial drawings and the units of the metric drawings (MEASUREMENT 0 or 1). Each time a drawing opens, its units are compared with the default of its kind and set when they differ. The drawing is not marked as modified by it: save it to keep the units in the file. (Not checked) leaves the drawings of that kind as they are. This works whether the commands of this page are turned on or not (the presets are in Modules\Dynalisp\Remote\Dyl-DrawingSetup.lsp).

Known Limitations

  • Only the display format and precision change: the insertion units (INSUNITS) and MEASUREMENT are not set, and the metric precisions assume one drawing unit is one millimetre.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-SetUnits: they are run by their alias, or picked from Dyl-SetUnits when it lists them (their command is named Pst-*).
