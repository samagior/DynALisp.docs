Set Units

Function Syntax DYL-SETUNITS and 4 unit settings (UNITS-M0, UNITS-M1, UNITS-M2, UNITS-I16)
Licence GNU General Public License v3

Program Description

Set the units of a drawing in one command: millimetres for metric drawings, 1/16" for imperial ones.

How To Use

  1. Type UNITS-M0 (1 mm), UNITS-M1 (0.1 mm), UNITS-M2 (0.01 mm) or UNITS-I16 (1/16").
  2. Or type Dyl-SetUnits and double-click a choice.

Units Of Every Drawing

Pick your units in Dyl-Settings > Drawing Settings: each drawing you open gets them.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite. The rows marked ↳ are its variants, run by their short name.

CommandAliasesName
