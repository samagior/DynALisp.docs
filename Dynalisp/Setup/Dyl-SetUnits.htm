Set Units

Function Syntax DYL-SETUNITS and 4 unit settings (UNITS-M0, UNITS-M1, UNITS-M2, UNITS-I16)
Licence GNU General Public License v3

Program Description

Set the units format and precision of a drawing in one command: decimal at 1, 0.1 or 0.01 mm for metric drawings, architectural at 1/16" for imperial ones. DynALisp can also give every drawing the units of its kind when it opens.

How To Use

  1. Type the alias of the units: UNITS-M0 (1 mm), UNITS-M1 (0.1 mm), UNITS-M2 (0.01 mm) or UNITS-I16 (1/16").
  2. Or type Dyl-SetUnits: the window lists the unit settings with their aliases; double-click one (or OK).

Commands

CommandNameDescription
UNITS-M0Units Metric 1 mmSets the drawing units to decimal with a 1 mm precision.
UNITS-M1Units Metric 0.1 mmSets the drawing units to decimal with a 0.1 mm precision.
UNITS-M2Units Metric 0.01 mmSets the drawing units to decimal with a 0.01 mm precision.
UNITS-I16Units Imperial 1/16 inSets the drawing units to architectural with a 1/16 in precision.

Units Of Every Drawing

  1. In Dyl-Settings, check Drawing Settings (in Overrides) and click its open button.
  2. Pick the units of the imperial drawings and of the metric drawings; (Not checked) leaves the drawings of that kind as they are.
  3. From then on, each drawing that opens gets the units of its kind when its own differ. The drawing is not marked as modified: save it to keep them in the file.

This works even when the commands of this page are turned off in Dyl-Suite.

Known Limitations

  • Only the display of the lengths and angles changes: the insertion units and the metric or imperial kind of the drawing do not, and the metric precisions take one drawing unit as one millimetre.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-SetUnits: they are run by their alias, or picked from Dyl-SetUnits when it lists them (their command is named Pst-*).
