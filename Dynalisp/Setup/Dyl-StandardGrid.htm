Standard Grid

Function Syntax DYL-STANDARDGRID and 4 grids (GRID-IN, GRID-FT, GRID-CM, GRID-M)
Source File Modules\Dynalisp\Apps\Setup\Dyl-StandardGrid.lsp
Licence GNU General Public License v3

Program Description

DYL-STANDARDGRID lists every grid setting with its alias: double-click one (or OK) to apply it. The grids are child commands (Pst-*) run by their aliases, which can be added, renamed or removed in Dyl-Suite (see Command Names And Aliases).

Switches the model space grid and snap between four standard configurations (inch, foot, centimetre and metre). The spacings are converted for the drawing units, so the same command works in metric and imperial drawings.

Commands

CommandNameDescription
GRID-INGrid InchSets a 1/4 in grid with a 1 in major grid and a 1/8 in snap, converted in metric drawings.
GRID-FTGrid FootSets a 1 in grid with a 1 ft major grid and a 1/8 in snap, converted in metric drawings.
GRID-CMGrid CentimeterSets a 2 mm grid with a 1 cm major grid and a 1 mm snap, converted in imperial drawings.
GRID-MGrid MeterSets a 100 mm grid with a 1 m major grid and a 25 mm snap, converted in imperial drawings.

How It Works

The command reads MEASUREMENT (0 = imperial, 1 = metric), sets the snap spacing, the grid spacing and the number of grid lines per major line, then turns the grid on:

CommandImperial snap / gridMetric snap / gridMajor line every
GRID-IN1/8″ / 1/4″3.175 / 6.354 lines (1″)
GRID-FT1/8″ / 1″3.175 / 25.412 lines (1′)
GRID-CM0.0394 / 0.07871 / 25 lines (1 cm)
GRID-M0.9843 / 3.937025 / 10010 lines (1 m)

It also sets SNAPTYPE to grid snap, AUTOSNAP to 15 and turns ORTHOMODE off.

Drawing Defaults

In Dyl-Settings, the open button of Drawing Settings (in Overrides; unchecked, no drawing is checked) opens the window that picks the grid of the imperial drawings and the grid of the metric drawings (MEASUREMENT 0 or 1). Each time a drawing opens, its snap spacing, grid spacing and major lines are compared with the default of its kind and the grid is set when they differ. The drawing is not marked as modified by it: save it to keep the grid in the file. (Not checked) leaves the drawings of that kind as they are. This works whether the commands of this page are turned on or not (the presets are in Modules\Dynalisp\Remote\Dyl-DrawingSetup.lsp).

Known Limitations

  • AUTOSNAP 15 turns object snap tracking and the tracking tooltips off, whatever they were before.
  • Snap and grid are viewport settings: only the current viewport changes.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-StandardGrid: they are run by their alias, or picked from Dyl-StandardGrid when it lists them (their command is named Pst-*).
