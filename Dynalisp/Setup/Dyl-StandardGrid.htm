Standard Grid

Function Syntax DYL-STANDARDGRID and 4 grids (GRID-IN, GRID-FT, GRID-CM, GRID-M)
Licence GNU General Public License v3

Program Description

Switch the grid and snap of model space between four standard spacings: inch, foot, centimeter and meter. The spacings follow the units of the drawing, so the same command works in metric and imperial drawings. DynALisp can also give every drawing the grid of its kind when it opens.

How To Use

  1. Type the alias of the grid: GRID-IN, GRID-FT, GRID-CM or GRID-M. The grid turns on, with grid snap.
  2. Or type Dyl-StandardGrid: the window lists the grids with their aliases; double-click one (or OK).

Commands

CommandNameDescription
GRID-INGrid InchSets a 1/4 in grid with a 1 in major grid and a 1/8 in snap, converted in metric drawings.
GRID-FTGrid FootSets a 1 in grid with a 1 ft major grid and a 1/8 in snap, converted in metric drawings.
GRID-CMGrid CentimeterSets a 2 mm grid with a 1 cm major grid and a 1 mm snap, converted in imperial drawings.
GRID-MGrid MeterSets a 100 mm grid with a 1 m major grid and a 25 mm snap, converted in imperial drawings.

Grid Of Every Drawing

  1. In Dyl-Settings, check Drawing Settings (in Overrides) and click its open button.
  2. Pick the grid of the imperial drawings and of the metric drawings; (Not checked) leaves the drawings of that kind as they are.
  3. From then on, each drawing that opens gets the grid of its kind when its own differs. The drawing is not marked as modified: save it to keep the grid in the file.

This works even when the commands of this page are turned off in Dyl-Suite.

Known Limitations

  • Setting a grid turns object snap tracking and its tooltips off, and Ortho off, whatever they were before.
  • Snap and grid belong to a viewport: only the current viewport changes.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-StandardGrid: they are run by their alias, or picked from Dyl-StandardGrid when it lists them (their command is named Pst-*).
