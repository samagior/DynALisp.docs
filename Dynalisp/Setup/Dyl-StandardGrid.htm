Standard Grid

Function Syntax DYL-STANDARDGRID and 4 grids (GRID-IN, GRID-FT, GRID-CM, GRID-M)
Works with Settings – checks the grid as each drawing opens

Program Description

Switch the grid and snap between four standard spacings: inch, foot, centimeter and meter. Works in metric and imperial drawings.

How To Use

  1. Type GRID-IN, GRID-FT, GRID-CM or GRID-M.
  2. Or type Dyl-StandardGrid and double-click a choice.
CommandGridMajorSnap
GRID-IN1/4 in1 in1/8 in
GRID-FT1 in1 ft1/8 in
GRID-CM2 mm1 cm1 mm
GRID-M100 mm1 m25 mm

Grid Of Every Drawing

Pick your grid in Dyl-Settings > Drawing Settings: each drawing you open gets it.

Known Limitations

  • Setting a grid turns Ortho and object snap tracking off.
  • Only the current viewport changes.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite. The rows marked ↳ are its variants, run by their short name.
