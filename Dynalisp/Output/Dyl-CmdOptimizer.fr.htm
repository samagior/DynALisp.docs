Optimiseur de commandes (Command Optimizer)

Syntaxe Dyl-CmdOptimizer, SAVE, QSAVE, SAVEAS, +SAVEAS, PLOT, PUBLISH, PREVIEW, EXPORTPDF, EXPORTDWF, EXPORTDWFX, REGEN
Requis AutoCAD pour Windows (ActiveX / Visual LISP), la préparation de sortie de Resources\dynalisp.mnl
Licence Licence publique générale GNU v3

Description

Préparez le dessin chaque fois que vous l'enregistrez ou l'imprimez, sans y penser : avec Command Optimizer activé, les commandes d'enregistrement et d'impression d'AutoCAD (et REGEN) lancent d'abord les étapes de préparation que vous avez cochées – calques activés et libérés, objets cachés affichés, xréfs rechargées, liaisons de données et tables mises à jour, ordre de tracé appliqué, régénération – puis font leur travail habituel. Ctrl+S enregistre toujours.

Utilisation

  1. Activez-le : cochez Commands dans les Overrides de Dyl-Settings, ou tapez Dyl-CmdOptimizer et répondez On. Il s'applique à chaque dessin.
  2. Choisissez les étapes : le bouton ouvrir à côté de Commands (ou Dyl-PrepSuite) ouvre la fenêtre de préparation, une grille des étapes et de quatre colonnes : All saves, All prints, PREVIEW et REGEN. Cochez ce que chacune lance, All On / All Off pour une colonne entière, puis OK.
  3. Enregistrez, tracez, publiez ou exportez comme d'habitude : les étapes de la colonne passent d'abord, puis la commande.

Bon à savoir

  • Par défaut, REGEN applique seulement le préréglage d'ordre de tracé (voir Draw Order), et seulement tant que l'ordre de tracé automatique est activé.
  • Une commande désactivée dans Dyl-Suite garde son comportement d'AutoCAD.
  • Dyl-RestoreCommands rend les commandes d'AutoCAD pour cette session seulement; désactivez Commands dans Dyl-Settings pour les garder.

Limites connues

  • Un dessin dont le démarrage de DynALisp s'est arrêté tôt n'a aucune de ces commandes pendant qu'un autre dessin a retiré celles d'AutoCAD : tapez _.QSAVE dans ce dessin, et cherchez l'erreur dans ses lignes de démarrage (ou lancez Diagnostics).
  • -PLOT et -PUBLISH ne sont pas préparés : les scripts et les programmes les appellent par leur nom.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont les commandes AutoCAD que Dyl-CmdOptimizer redéfinit (voir plus haut).
