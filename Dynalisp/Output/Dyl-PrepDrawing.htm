Prep Drawing

Function Syntax Dyl-PrepDrawing
Works with Command Optimizer – runs it before each save or plot
Draw Order – the draw order it applies

Program Description

Get a drawing ready to send in one command.

How To Use

  1. Type Dyl-PrepDrawing.
  2. To do it before each save or plot, turn on Command Optimizer.

The Steps

  1. Layers – turns on and thaws every layer.
  2. Unhide – shows hidden objects.
  3. Xrefs – reloads the xrefs.
  4. Data links – updates the linked tables.
  5. Tables – fits each table row to its text.
  6. Draw order – applies your draw order.
  7. Regen – regenerates the drawing.
