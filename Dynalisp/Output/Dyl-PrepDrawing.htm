Prep Drawing

Function Syntax Dyl-PrepDrawing
Requires AutoCAD for Windows (ActiveX / Visual LISP), the output prep of Resources\dynalisp.mnl
Licence GNU General Public License v3

Program Description

Get a drawing ready to send in one command: every layer turned on and thawed, the hidden objects shown, the xrefs reloaded, the data links and tables updated, the draw order applied and the drawing regenerated. The same steps run before each save or print when Command Optimizer is on.

How To Use

  1. Type Dyl-PrepDrawing: every step runs now, and the command line says which.
  2. To run them on their own before each save or print, turn Command Optimizer on and pick the steps of each command in the output prep window.

The Steps

  1. Layers – turns on and thaws every layer.
  2. Unhide – shows the hidden and isolated objects.
  3. Xrefs – reloads every xref, when the drawing has some. It can be slow when they are many or on a server.
  4. Data links – updates the tables of every data link, when the drawing has some.
  5. Tables – fits every row of every table to its text height.
  6. Draw order – applies the active draw order preset to the whole drawing, while auto draw order is on (see Draw Order); Rebuild draw order builds it again from scratch, which keeps panning and zooming fast in a drawing edited for a long time.
  7. Regen – regenerates every viewport (REGENALL), which can be slow in a large drawing.

Commands

CommandNameDescription
Dyl-PrepDrawingPrep DrawingRuns every output prep step now: layers, hidden objects, xrefs, data links, tables, draw order and regen.

Known Limitations

  • A step that fails is skipped without a message; the next ones still run.
  • Turning Dyl-PrepDrawing off in Dyl-Suite removes the command only: the commands of Command Optimizer still run the steps.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
