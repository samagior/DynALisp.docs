Prep Drawing

Function Syntax Dyl-PrepDrawing
Source File Modules\Dynalisp\Apps\Output\Dyl-PrepDrawing.lsp
Requires AutoCAD for Windows (ActiveX / Visual LISP), the output prep of Resources\dynalisp.mnl
Licence GNU General Public License v3

Program Description

Prepares the drawing before it is saved, plotted or published. Dyl-PrepDrawing runs every step now; the commands redefined by Command Optimizer (the save commands, the print commands and REGEN) run the steps checked for their column in the output prep window (Dyl-PrepSuite, or the open button next to Commands in Dyl-Settings).

Commands

CommandNameDescription
Dyl-PrepDrawingPrep DrawingRuns every output prep step now: layers, hidden objects, xrefs, data links, tables, draw order and regen.

How It Works

  1. Layers: turns on and thaws every layer.
  2. Unhide: shows the hidden and isolated objects (UNISOLATEOBJECTS).
  3. Xrefs: reloads every xref, when the drawing has some.
  4. Data links: updates the tables of every data link, when the drawing has some.
  5. Tables: fits every row of every table to its text height (also TBLFIX).
  6. Draw order: applies the active draw order preset to model space, every layout and every block definition, while auto draw order is on (see Draw Order). Checked for REGEN only by default.
  7. Regen: regenerates every viewport (REGENALL).

Known Limitations

  • The steps are commands run silently: one that fails is skipped without message, the next ones still run.
  • Turning Dyl-PrepDrawing off in Dyl-Suite removes the command only: the redefined commands still load this file to run their steps.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
