Préparer le dessin (Prep Drawing)

Syntaxe Dyl-PrepDrawing
Fichier source Modules\Dynalisp\Apps\Output\Dyl-PrepDrawing.lsp
Requis AutoCAD pour Windows (ActiveX / Visual LISP), la préparation de sortie de Resources\dynalisp.mnl
Licence Licence publique générale GNU v3

Description

Prépare le dessin avant qu'il soit enregistré, tracé ou publié. Dyl-PrepDrawing exécute maintenant chaque étape; les commandes redéfinies par Command Optimizer (les commandes d'enregistrement, les commandes d'impression et REGEN) exécutent les étapes cochées dans leur colonne de la fenêtre de préparation de sortie (Dyl-PrepSuite, ou le bouton ouvrir à côté de Commands dans Dyl-Settings).

Commandes

CommandeNomDescription
Dyl-PrepDrawingPrep DrawingExécute maintenant chaque étape de préparation de sortie : calques, objets masqués, xréfs, liaisons de données, tableaux, ordre de tracé et régénération.

Fonctionnement

  1. Layers : active et libère chaque calque.
  2. Unhide : affiche les objets masqués et isolés (UNISOLATEOBJECTS).
  3. Xrefs : recharge chaque xréf, quand le dessin en a.
  4. Data links : met à jour les tableaux de chaque liaison de données, quand le dessin en a.
  5. Tables : ajuste chaque rangée de chaque tableau à la hauteur de son texte (aussi TBLFIX).
  6. Draw order : applique le préréglage d'ordre de tracé actif à l'espace objet, à chaque présentation et à chaque définition de bloc, tant que l'ordre de tracé automatique est activé (voir Draw Order). Coché pour REGEN seulement par défaut.
  7. Regen : régénère chaque fenêtre (REGENALL).

Limites connues

  • Les étapes sont des commandes exécutées sans message : celle qui échoue est sautée en silence, les suivantes s'exécutent quand même.
  • Désactiver Dyl-PrepDrawing dans Dyl-Suite retire seulement la commande : les commandes redéfinies chargent encore ce fichier pour exécuter leurs étapes.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
