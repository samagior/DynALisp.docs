Préparer le dessin (Prep Drawing)

Syntaxe Dyl-PrepDrawing
Requis AutoCAD pour Windows (ActiveX / Visual LISP), la préparation de sortie de Resources\dynalisp.mnl
Licence Licence publique générale GNU v3

Description

Préparez un dessin à envoyer en une commande : chaque calque activé et libéré, les objets cachés affichés, les xréfs rechargées, les liaisons de données et les tables mises à jour, l'ordre de tracé appliqué et le dessin régénéré. Les mêmes étapes passent avant chaque enregistrement ou impression quand Command Optimizer est activé.

Utilisation

  1. Tapez Dyl-PrepDrawing : chaque étape passe maintenant, et la ligne de commande dit lesquelles.
  2. Pour qu'elles passent d'elles-mêmes avant chaque enregistrement ou impression, activez Command Optimizer et choisissez les étapes de chaque commande dans la fenêtre de préparation.

Les étapes

  1. Calques – active et libère chaque calque.
  2. Afficher – montre les objets cachés et isolés.
  3. Xréfs – recharge chaque xréf, quand le dessin en a.
  4. Liaisons de données – met à jour les tables de chaque liaison de données, quand le dessin en a.
  5. Tables – ajuste chaque rangée de chaque table à la hauteur de son texte.
  6. Ordre de tracé – applique le préréglage d'ordre de tracé actif à tout le dessin, tant que l'ordre de tracé automatique est activé (voir Draw Order); reconstruire l'ordre de tracé le refait depuis le début.
  7. Régénération – régénère chaque fenêtre.

Commandes

CommandeNomDescription
Dyl-PrepDrawingPrep DrawingExécute maintenant chaque étape de préparation de sortie : calques, objets masqués, xréfs, liaisons de données, tableaux, ordre de tracé et régénération.

Limites connues

  • Une étape qui échoue est sautée sans message; les suivantes passent quand même.
  • Désactiver Dyl-PrepDrawing dans Dyl-Suite retire seulement la commande : les commandes de Command Optimizer lancent toujours les étapes.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
