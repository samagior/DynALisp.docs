Préparer le dessin (Prep Drawing)

Syntaxe Dyl-PrepDrawing
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Préparez un dessin à envoyer en une commande.

Utilisation

  1. Tapez Dyl-PrepDrawing.
  2. Pour le faire avant chaque enregistrement ou traçage, activez l'Optimiseur de commandes.

Les étapes

  1. Layers – active et libère tous les calques.
  2. Unhide – affiche les objets cachés.
  3. Xrefs – recharge les xréfs.
  4. Data links – met à jour les tableaux liés.
  5. Tables – ajuste chaque rangée de tableau à son texte.
  6. Draw order – applique votre ordre de tracé.
  7. Regen – régénère le dessin.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite.

CommandeAliasNom
Dyl-PrepDrawing–Prep Drawing
