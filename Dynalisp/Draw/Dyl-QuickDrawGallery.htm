Quick Draw Gallery

Function Syntax PST-QUICKDRAWGALLERY (alias QDG)
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Pick a Quick Draw preset by its look: a tile for each one, its hatch as it plots.

How To Use

  1. Click Quick Draw in the ribbon, or type QDG.
  2. Filter with the pills, or type a few letters.
  3. Double-click a tile to draw it. Pick another method under the tiles first if you like.

Good To Know

  • Recent holds the presets you drew today.
  • Drafting tiles are at their size on paper; Model tiles follow the scale of the drawing.
  • A crossed-out tile needs its hatch pattern: see Rebuild Patterns.
  • Quick Draw Manager opens Quick Draw to edit the presets.
