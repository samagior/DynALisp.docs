Quick Shape

Function Syntax DYL-QUICKSHAPE (Quick Shape tab of the Manager) + 6 preset commands – see Commands
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Place ready-made shapes, already hatched: studs, bricks, blocks, steel tubes. Again and again, until Enter.

How To Use

  1. Type a shape, QS-STUD2X4 for a 2x4 stud (the list below).
  2. Pick its point, then its rotation. Enter stops.
  3. To change or add one, type Dyl-QuickShape.

Quick Shape Window

  • Material – what fills the shape, and View: Cut in a section, Surface in an elevation.
  • Shape and Scale – the shape to place and its size.
  • Border – the layer and the look of its outline.
  • Draw places it, Save keeps the changes.

Your Own Shapes

  • Add shape from selection... – select the objects, pick the base point, type a name.
  • Open library – opens the drawing of the shapes, to edit them.
  • Draw the parts to fill with closed outlines, on layer 0.

Known Limitations

  • Attributes are not asked; dynamic blocks lose their grips.
