Galerie de dessin rapide (Quick Draw Gallery)

Syntaxe PST-QUICKDRAWGALLERY (alias QDG)
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Choisissez un préréglage de Quick Draw à son allure : une tuile pour chacun, sa hachure telle qu'elle s'imprime.

Utilisation

  1. Cliquez Quick Draw dans le ruban, ou tapez QDG.
  2. Filtrez avec les pastilles, ou tapez quelques lettres.
  3. Double-cliquez une tuile pour la dessiner. Choisissez d'abord une autre méthode sous les tuiles si vous voulez.

Bon à savoir

  • Recent garde les préréglages dessinés aujourd'hui.
  • Les tuiles Drafting sont à leur taille sur papier ; les tuiles Model suivent l'échelle du dessin.
  • Une tuile barrée a besoin de son motif de hachure : voyez Reconstruire les motifs.
  • Quick Draw Manager ouvre Dessin rapide pour modifier les préréglages.
