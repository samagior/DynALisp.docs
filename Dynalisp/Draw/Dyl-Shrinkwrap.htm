Shrinkwrap

Function Syntax DYL-SHRINKWRAP
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Draw a closed outline around objects, texts and dimensions included. The objects stay as they are.

How To Use

  1. Type Dyl-Shrinkwrap and select the objects.
  2. Type a gap, or press Enter for none.
  3. The outlines are drawn and left selected, ready to hatch.

Gap Tolerance

The gap closes the openings between objects up to that width. With none, Shrinkwrap tries larger gaps by itself until it finds an outline; set the step in Dyl-Settings, Drawing Settings. A larger gap rounds the corners more.

Known Limitations

  • Flat objects only.
  • Large selections with many blocks are slow.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
