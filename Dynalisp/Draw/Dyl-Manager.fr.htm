Gestionnaire (Manager)

Syntaxe DYL-MANAGER
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Réglez tous les outils de dessin dans une seule fenêtre : Quick Draw, Assembly Presets, Quick Shape, Materials et Hatch Presets, chacun dans son onglet.

Utilisation

  1. Tapez Dyl-Manager, ou cliquez Manager dans le ruban.
  2. Cliquez un onglet, ou appuyez sur Ctrl+Tab : l'onglet quitté est enregistré.
  3. Continuez à dessiner pendant qu'il est ouvert.
  4. OK ou Save enregistre, Cancel abandonne les changements de l'onglet affiché, Draw dessine le préréglage.

Bon à savoir

  • Chaque onglet a sa page : Dessin rapide, Préréglages d'assemblage, Forme rapide, Matériaux, Préréglages de hachures.
  • Seuls les onglets des outils activés dans Dyl-Suite s'affichent.
  • Il se rouvre sur le dernier onglet, là où vous l'avez laissé.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite.
