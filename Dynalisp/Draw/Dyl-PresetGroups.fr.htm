Groupes de préréglages (Preset Groups)

Classez vos préréglages et matériaux en groupes : Wall, Section, Phase pour les préréglages, Masonry, Wood, Insulation pour les matériaux.

Utilisation

  1. Cliquez le bouton carré à côté d'une liste Group dans Dessin rapide, Forme rapide, Préréglages d'assemblage, Préréglages de hachures ou Matériaux.
  2. Add, renommez, Remove ou déplacez les groupes.
  3. Cliquez OK : un groupe renommé l'est partout.

Reset rend les groupes par défaut.
