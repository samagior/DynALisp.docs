Group Cluster

Function Syntax GROUPCLUSTER
Requires AutoCAD 2025 or later for Windows
Status To be checked – see Known Limitations
Licence GNU General Public License v3

Program Description

Group the objects that are close to each other, in one step.

How To Use

  1. Type GROUPCLUSTER and draw a window, or press Enter to select.
  2. Type the largest gap between two objects of a group.
  3. Each cluster becomes a group; objects alone stay as they are.

Known Limitations

  • Slow with thousands of objects.
  • Arcs and diagonal lines can join a group a little too far.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
