Assistant

Function Syntax DYL-ASSISTANT (AICHAT)
Requires AutoCAD 2016 or later for Windows, Claude Code (the command line tool of Anthropic) signed in with your own Claude account, an internet connection
Licence GNU General Public License v3

Program Description

Ask Claude about AutoCAD, AutoLISP, DynALisp and the drawing open, in a palette beside it. The palette keeps the conversation going: ask a question, then a follow-up, as in a chat. It runs Claude Code, the command line tool of Anthropic, signed in with your own Claude account: no API key, and the use counts toward your Claude plan.

The Assistant reads the active drawing: its units and layers, the objects you selected, their geometry, texts, blocks and hatches. It can also change it, draw, move, erase, set layers or run an AutoCAD command, but only once you click Allow on the card that says what it will do, and one U undoes each change.

What you type is sent to Anthropic through Claude Code. Do not paste anything that must not leave your computer. The Assistant is turned off on a new installation: turn it on in Dyl-Suite.

How To Use

  1. Once – turn on Assistant in Dyl-Suite, then type Dyl-Assistant. When Claude Code is not installed, the palette offers Install Claude Code: a console opens and runs the installer of Anthropic. Then Sign in opens a console that signs Claude Code in with your Claude account, in your browser. Click Check again when it is done.
  2. Type your question in the box at the bottom of the palette and press Enter (Shift+Enter starts a new line). The answer is written as it comes. To ask about some objects, select them in the drawing first (what is the area of this polyline?).
  3. A pale line shows what it looks at in the drawing (Reading the layers...). When it wants to change the drawing, a card says what it will do and in which drawing, the objects it changes highlighted: click Allow, Deny, or Allow for this chat to let it do the same kind of change again without asking, until New chat. A command (Run the command _.ZOOM) shows its whole command line, and is asked every time.
  4. Stop ends an answer that is too long; the conversation goes on with the next question. New chat starts over.
  5. The list at the top picks the model: Sonnet (the default, fast) or Opus (for harder questions, slower and counting more toward your plan).

The Palette

  • New chat – forgets the conversation and starts a new one.
  • Model – Sonnet or Opus, kept until AutoCAD closes.
  • Open Docs – opens this page.
  • Send and Stop – send the question, or end the answer being written (a card still waiting is denied).
  • Allow, Allow for this chat and Deny – the answer to a change of the drawing. A card not answered within 9 minutes is denied.

The palette docks on the left or the right of AutoCAD, or floats, and wears the light or dark theme of AutoCAD. The text of an answer can be selected and copied.

Good To Know

  • Your Claude account is signed in by Claude Code itself, in your browser: DynALisp never sees it.
  • When the Windows environment variable ANTHROPIC_API_KEY is set, Claude Code uses that API key, billed by the Anthropic API, instead of your Claude plan. The palette says so; remove the variable to use your plan.
  • The Assistant answers in the language you write in.
  • Each change you allow is one step of undo: U undoes it, whatever it changed. Put what goes together in one request (draw this wall, its hatch and its layer): it is one card and one U.
  • A change waits while a command is running or a DynALisp window is open: finish it, then ask again. The change is made in the drawing named on the card only; if you switched to another drawing, it is refused.
  • The texts of the drawing are read as data: an mtext that says erase everything is not an order to the Assistant, and every change goes through a card anyway.
  • It does not save, plot, open or close drawings, does not export to a file, attach or import one, nor use the clipboard, and does not run scripts, programs or AutoLISP: it works in the drawing only.
  • Dyl-Diagnostics reports whether Claude Code is installed and signed in, and whether the tools of the drawing are running.

Known Limitations

  • It reads the drawing, but does not see it as a picture: it knows the objects, not how they look on the screen.
  • A command it runs must be given every answer it asks: a command left waiting for a point is finished by you. Commands that open a window are run in their command-line version (-LAYER, -HATCH).
  • It does not yet use the presets, materials and layer keys of DynALisp.
  • The labels of the palette are in English.
  • It needs AutoCAD 2016 or later.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
