Assistant

Function Syntax DYL-ASSISTANT (AICHAT)
Requires AutoCAD 2025 or later for Windows, Claude Code signed in with your own Claude account, an internet connection
Licence GNU General Public License v3

Program Description

Ask Claude about AutoCAD, DynALisp and your drawing, in a palette beside it. It reads the drawing and can draw for you, once you say yes.

What you type is sent to Anthropic. Do not paste anything that must stay on your computer.

How To Use

  1. Once – turn on Assistant in Dyl-Suite, type AICHAT, then click Install Claude Code and Sign in if the palette asks.
  2. Type your question and press Enter. Select objects first to ask about them.
  3. To change the drawing, it shows a card: click Allow or Deny. One U undoes each change.
  4. New chat starts over; Resume last chat takes up the last one.

Good To Know

  • It uses your own Claude plan. Sonnet is fast, Opus is for harder questions.
  • It knows the materials and assemblies of DynALisp, and says when a value is unknown.
  • It works in the drawing only: it never saves, plots or opens files.
  • It answers in the language you write in.

Known Limitations

  • A change waits while a command runs or a DynALisp window is open.
  • The palette is in English.
