Quick Select Similar

Function Syntax QSS, QSELECTSIMILAR
Source File Modules\Dynalisp\Apps\Utilities\Dyl-QuickSelectSimilar.lsp
Requires AutoCAD for Windows (DCL dialog generated at run time)

Program Description

A customisable SELECTSIMILAR: it selects every visible object of the current space that matches object types and property filters chosen in a dialog box, pre-filled from reference objects. The dialog is in French.

Commands

CommandNameDescription
QSSQuick Select SimilarSelects the visible objects matching the types and properties chosen in a dialog.
QSELECTSIMILARQuick Select Similar (Alias)Alias of QSS.

How It Works

  1. Pre-select one or more reference objects, or pick them at the prompt. Press Enter without a selection to reopen the dialog with the last settings.
  2. The dialog Selection rapide d'objets similaires lists the object types visible in the current space with live counts; the reference types are selected.
  3. Property filters are pre-filled from the references: layer, colour (ACI), linetype, lineweight, text style, dimension style and block name (effective name, dynamic blocks included). Tick the filters to use and edit the values: comma-separated values and the * ? wildcards are allowed.
  4. Set the scope (whole current space, or current view only) and the options (exclude locked layers, add to the current selection). Choisir reference < picks new references without losing the settings.
  5. On OK the matching objects are gripped and stored as the Previous selection, and a count by type is printed.

Filter logic

  • Values inside one field are combined with OR; checked fields are combined with AND.
  • Text style, dimension style and block name only restrict their own object types; the other selected types are not affected by them.
  • Visible means layer on and thawed and object not invisible.

Known Limitations

  • Layers frozen only in a paper space viewport are not detected as hidden.
  • The colour filter compares index colours (true colours use their ACI).
  • The settings are remembered for the drawing session only.

;;;   Type-specific filters (text style, dim style, block name) only restrict

;;; Commands:
;;;   QSS              - run the command
;;;   QSELECTSIMILAR   - alias of QSS
;;;
;;; Workflow:
;;;   1. Pre-select reference object(s), or pick them at the prompt
;;;      (press Enter to skip and open the dialog with the last settings).

;;;      Check the filters to apply, edit values as needed.

;;;   4. OK: the result is gripped (PICKFIRST) and stored as "Previous".

;;; Notes:
;;;   - "Visible" means: layer on and thawed, object not invisible (DXF 60).
;;;     Layers frozen only in a paper space viewport (VP freeze) are not
