Quick Select Similar

Function Syntax QSS, QSELECTSIMILAR
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Select every object like the ones you pick, matching only what you choose: type, layer, color, linetype, style or block.

How To Use

  1. Select one or more objects and type QSS.
  2. Check what must match, and the whole space or the view.
  3. Click OK: the objects are selected for your next command.

Known Limitations

  • A layer frozen in a viewport only still counts as visible.
