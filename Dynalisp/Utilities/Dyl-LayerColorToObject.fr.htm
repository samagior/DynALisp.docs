Couleur du calque à l'objet (Layer Color To Object)

Syntaxe LCOL, LAYCOLTOOBJ
Fichier source Modules\Dynalisp\Apps\Utilities\Dyl-LayerColorToObject.lsp
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Applique directement à chaque objet la couleur de son calque, à la place de DuCalque, DuBloc ou de toute couleur explicite, en copie exacte, en couleur d'index ou en couleur vraie. Elle peut aussi ramener les objets à DuCalque.

Commandes

CommandeNomDescription
LCOLLayer Color To ObjectApplique directement à chaque objet sélectionné la couleur de son calque.
LAYCOLTOOBJLayer Color To Object (Alias)Alias de LCOL.

Fonctionnement

  1. Utilise les objets présélectionnés, ou demande une sélection (les objets sur des calques verrouillés sont exclus).
  2. Choisissez le mode de couleur à Color mode [AsIs/Index/TrueColor/ByLayer]; Entrée garde le dernier mode de la session (AsIs au départ).
  3. Chaque objet reçoit la couleur établie d'après son calque (établie une fois par calque), le tout en une seule étape d'annulation.
  4. La commande indique combien d'objets ont été modifiés et combien n'ont pas pu l'être.
ModeCouleur appliquée
AsIsLa couleur du calque exactement telle que définie : index, couleur vraie ou couleur d'un carnet de couleurs.
IndexUne couleur d'index (ACI); pour un calque en couleur vraie, la couleur d'index la plus proche enregistrée avec le calque.
TrueColorUne couleur vraie RVB; les couleurs d'index des calques sont converties en leurs valeurs RVB.
ByLayerRamène les objets à DuCalque.

Limites connues

  • Les objets présélectionnés sur des calques verrouillés ne sont pas retirés; ils sont comptés comme could not be modified.
  • Seuls les objets sélectionnés changent : les objets dans les définitions de blocs gardent leurs propres couleurs.
  • Le chargement du fichier affiche un message loaded à la ligne de commande : il apparaît donc à chaque démarrage de DynALisp.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).

Notes du programme d'origine (en anglais) 
;;; ==========================================================================
;;; LayerColorToObject.lsp
;;;
;;; Reads the color of each selected object's layer and applies it directly
;;; to the object (replacing ByLayer / ByBlock / any explicit color).
;;;
;;; Color modes:
;;;   AsIs       - Copies the layer color exactly as defined on the layer
;;;                (ACI, true color or color book color).
;;;   Index      - Applies the layer color as an ACI index color. For layers
;;;                using a true color, the closest ACI stored by AutoCAD in
;;;                the layer record (DXF 62) is used.
;;;   TrueColor  - Applies the layer color as an RGB true color. ACI layer
;;;                colors are converted to their RGB equivalent.
;;;   ByLayer    - Reverts the selected objects to the ByLayer color.
;;;
;;; Commands:
;;;   LCOL         - Main command
;;;   LAYCOLTOOBJ  - Alias of LCOL
;;;
;;; Notes:
;;;   - Supports pre-selection (pickfirst).
;;;   - Objects on locked layers are filtered out of the selection.
;;;   - The last chosen mode is remembered for the current session.
;;;   - The whole operation is recorded as a single UNDO step.
;;; ==========================================================================
