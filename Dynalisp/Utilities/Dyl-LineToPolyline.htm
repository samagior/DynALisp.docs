Line To Polyline

Function Syntax LTPL
Licence GNU General Public License v3

Program Description

Converts the selected lines into polylines and, as an option, joins the ones that touch into single polylines.

Commands

CommandNameDescription
LTPLLine To PolylineConverts each selected line into a polyline with PEDIT, optionally joining the touching ones.

Known Limitations

  • Expects PEDITACCEPT = 0: the routine answers Yes to Do you want to turn it into one?. With PEDITACCEPT = 1 that answer is read as a PEDIT option instead.
  • Arcs and other curves are not selected.
  • There is no single undo step: each conversion is undone separately.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
