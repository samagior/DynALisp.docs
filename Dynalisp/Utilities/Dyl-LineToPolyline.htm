Line To Polyline

Function Syntax LTPL
Licence GNU General Public License v3

Program Description

Turn lines into polylines, and join the ones that touch.

How To Use

  1. Type LTPL and say whether to join the lines that touch.
  2. Select the lines.

Known Limitations

  • Arcs and curves are left out.
  • Each line is undone on its own.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
