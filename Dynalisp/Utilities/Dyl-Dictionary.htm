Dictionary

Function Syntax DYL-DICTIONARY (DICO)
Works with Set File Preferences – turns the custom dictionary on
Status New – see Known Limitations

Program Description

Look up the words the spell checker of DynALisp knows, with their definition: about 2,450 French architecture and construction words and 260 expressions.

How To Use

  1. Type DICO.
  2. Type a word, or a part of it: vitr finds vitrage and vitrail. Accents do not matter.
  3. Pick a word to read it; Copy word puts it on the clipboard.

Good To Know

  • Edit list... opens the list in Excel: save it as CSV UTF-8.
  • A word you add to the dictionary in AutoCAD gets its definition there.
  • The definitions are working notes, not an official terminology.
  • French only for now.
