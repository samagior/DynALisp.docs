Program Description

Opens a window to search the words of the DynALisp custom dictionaries (see Set File Preferences) with their definition, type and category. Next to each custom dictionary <code>.cus, a definitions file <code>-def.csv describes its words: fra-def.csv gives about 2,450 French architecture and construction words and Roman numerals, with the plural, feminine and other forms of fra.cus, and about 260 expressions such as semelle filante or clé de voûte.

Commands

CommandNameDescription
DYL-DICTIONARYDictionarySearches the words of the DynALisp dictionaries, their definitions and categories, in the language of the file preferences.

How It Works

  1. The window opens the definitions file of the language of the file preferences (fra-def.csv in French). Dictionary shows the other ones of Res\Dictionaries.
  2. Words: type one or more words and press Enter or Search. Every word typed must be found in the word or in one of its forms (vitr finds vitrage, vitrail and vitraux). Accents, ligatures and case are ignored: equarri finds équarri, oeil finds œil-de-bœuf. Tick Also in the definitions to search the definitions too (corrosion then finds inhibiteur, galvanisé, galvanisation...).
  3. Category, Subcategory and Type filter the list (n.m., n.f., adj., v., sigle, abr., n.pr., loc.n.f. for an expression...). The subcategories are the ones of the category chosen. Clear removes the search and the filters.
  4. Selecting a word shows its type, forms, definition and category. See also lists related words: Go to shows one, clearing the filters when it is not in the list.
  5. Copy word, or a double-click in the list, copies the word to the clipboard, to paste it in a text.
  6. Edit list... closes the window and opens your copy of the definitions file in Excel (made under User\ from the default the first time). Save it as CSV UTF-8, then run the command again. Dyl-UserFiles can make your copy the default.

Definitions File

Res\Dictionaries\<code>-def.csv, UTF-8, one word per row: Word;Forms;Type;Category;Subcategory;Definition;See also.

  • Word: the word as written in the custom dictionary (singular, masculine), or an expression of several words. Expressions are only in the definitions file: the spell checker checks each of their words separately.
  • Forms: its other forms in the custom dictionary (plural, feminine, other spellings), separated by commas. They are searched with the word.
  • Type: n.m., n.f., adj., v., sigle, abr., n.pr., num. (Roman numeral) or, for an expression, loc.n.m., loc.n.f., loc.adj. or loc.adv.; several separated by / (n.m./adj.).
  • Category and Subcategory: the theme of the word, in 10 categories: Structure, Enveloppe, Intérieur, Mécanique et électricité, Matériaux, Architecture, Patrimoine et rénovation, Projet et réglementation, Abréviations et sigles, Mots composés (Structure > Pièce sur pièce, Enveloppe > Ferblanterie, Architecture > Églises : mobilier liturgique...).
  • Definition: one or two sentences, without the ; separator.
  • See also: related words of the file, separated by commas.

A word added to the custom dictionary from AutoCAD (Add to dictionary) is not added to the definitions file: add its row with Edit list....

About 100 terms defined by the Quebec Construction Code (National Building Code as amended for Quebec, Division A, Article 1.4.1.2), such as mur coupe-feu, premier étage or distance limitative, end their definition with Terme défini du code.: tick Also in the definitions and search terme defini to list them all. The ones not found elsewhere are in Projet et réglementation > Termes définis du code. Their definitions are reworded summaries, not the text of the code: check the code before relying on one.

Known Limitations

  • The definitions are short working definitions written for the drawings and specifications of the firm, not an official terminology. Check the regional and heritage terms with your references (Office québécois de la langue française, Grand dictionnaire terminologique).
  • The file is read as UTF-8: saved by Excel as a plain CSV (not CSV UTF-8), its accented letters show wrong.
  • Copy word uses the Windows htmlfile object; when Windows does not provide it, the window says the word could not be copied.
  • Only French has a definitions file for now: another language opens the first one found.
