Dictionary

Function Syntax DYL-DICTIONARY (DICO)
Requires AutoCAD 2021 or later for Windows (Unicode AutoLISP, ActiveX / Visual LISP)
Status New – see Known Limitations
Licence GNU General Public License v3

Program Description

Look up the words of the DynALisp custom dictionaries with their definition, type and category: about 2,450 French architecture and construction words, Roman numerals, and 260 expressions such as semelle filante or clé de voûte, the words the spell checker knows through the DynALisp dictionary (see Set File Preferences).

How To Use

  1. Type Dyl-Dictionary: the window opens on the dictionary of the language of your file preferences.
  2. Type one or more words: the list follows as you type. Narrow it with the category, subcategory and type.
  3. Select a word to read its definition; Copy word (or a double-click) puts it on the clipboard, to paste in a text.

Dictionary Window

  • Dictionary – the dictionary shown, when there are several.
  • Words – every word typed must be found in the word or one of its forms: vitr finds vitrage, vitrail and vitraux. Accents, ligatures and case are ignored: equarri finds équarri, oeil finds œil-de-bœuf.
  • Category, Subcategory, Type – filter the list (n.m., n.f., adj., v., sigle, abr., n.pr., loc.n.f. for an expression...). Clear removes the search and the filters.
  • The word selected – its type, forms, definition and category; See also lists related words, and Go to shows one.
  • Edit list... – opens your copy of the list in Excel; save it as CSV UTF-8, then run the command again. A word added to the dictionary from AutoCAD (Add to dictionary) gets its definition there.

Commands

CommandNameDescription
DYL-DICTIONARYDictionarySearches the words of the DynALisp dictionaries, their definitions and categories, in the language of the file preferences.

Known Limitations

  • The definitions are short working definitions written for the drawings and specifications of the firm, not an official terminology. Check the regional and heritage terms with your references (Office québécois de la langue française, Grand dictionnaire terminologique).
  • The file is read as UTF-8: saved by Excel as a plain CSV (not CSV UTF-8), its accented letters show wrong.
  • Copy word uses the Windows htmlfile object; when Windows does not provide it, the window says the word could not be copied.
  • Only French has a definitions file for now: another language opens the first one found.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
