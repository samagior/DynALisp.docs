Préfixe et suffixe de texte (Add Prefix / Suffix)

Syntaxe TXTPS
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Ajoutez le même texte au début ou à la fin de chaque texte et texte multiligne sélectionné, en une étape : un numéro d'étage devant chaque nom de pièce, une unité après chaque valeur.

Utilisation

  1. Tapez TXTPS et sélectionnez les textes; seuls les textes et textes multilignes sont gardés.
  2. Choisissez Prefix ou Suffix (Entrée : Suffix), puis tapez le texte à ajouter, espaces compris.
  3. Chaque texte sélectionné le reçoit; un U annule tout le changement.

Commandes

CommandeNomDescription
TXTPSText Prefix SuffixAjoute un texte choisi comme préfixe ou suffixe aux textes et textes multilignes sélectionnés.

Limites connues

  • Pour un texte multiligne, le texte est ajouté au contenu brut : un préfixe se place avant les codes de mise en forme du début, il peut donc ne pas prendre la mise en forme du premier mot.
  • Les objets sur des calques verrouillés ne sont pas retirés de la sélection; en modifier un arrête la commande par une erreur.
  • Les attributs, les cotes et les lignes de repère multiples ne sont pas traités.
  • Le chargement du fichier affiche un message loaded à la ligne de commande : il apparaît donc à chaque démarrage de DynALisp.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite.

CommandeAliasNom
Dyl-AddPrefixSuffixTXTPSText Prefix Suffix

Notes du programme d'origine (en anglais) 
;;; ==============================================================
;;; AddPrefixSuffix.lsp
;;;
;;; Adds a user-chosen string to the beginning (prefix) or end
;;; (suffix) of the text content of all selected TEXT and MTEXT
;;; entities.
;;;
;;; COMMAND:  TXTPS
;;;
;;; USAGE:
;;;   1. Load this file (APPLOAD, or drag-and-drop onto the
;;;      AutoCAD window).
;;;   2. Type TXTPS at the command line.
;;;   3. Select the TEXT / MTEXT objects to modify (other object
;;;      types in the selection are ignored automatically).
;;;   4. Choose whether to add the string as a Prefix or Suffix.
;;;   5. Type the text to add.
;;;
;;; NOTES:
;;;   - Works on both single-line TEXT and multiline MTEXT.
;;;   - For MTEXT, the string is added to the raw TextString
;;;     (including any formatting codes it may already contain),
;;;     so existing formatting is preserved.
;;;   - Wrapped in a single UNDO group, so one U / CTRL+Z undoes
;;;     the whole operation.
;;; ==============================================================
