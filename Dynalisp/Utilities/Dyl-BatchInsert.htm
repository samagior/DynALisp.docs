Batch Insert

Function Syntax BATCH-INSERT
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Insert every drawing of a folder side by side, to see a set of drawings at a glance.

How To Use

  1. Type BATCH-INSERT and pick the folder.
  2. The drawings come in as blocks, left to right by name.
  3. One U removes them all.

Known Limitations

  • A drawing whose name is already a block here is skipped: rename or purge that block first.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
