Batch Insert

Function Syntax BATCH-INSERT
Requires AutoCAD for Windows (Shell folder browser)
Status Work in progress – see Known Limitations
Licence GNU General Public License v3

Program Description

Meant to insert every drawing of a folder into the current drawing as blocks, side by side, to review a set of drawings at a glance.
It does not work at the moment: see Known Limitations.

How To Use

  1. Type BATCH-INSERT and pick the folder in the window.
  2. Each drawing of the folder should be inserted at scale 1, 100 units to the right of the last.

Commands

CommandNameDescription
BATCH-INSERTBatch InsertInserts every drawing of a folder side by side as blocks in the current drawing.

Known Limitations

  • The folder picked in the browser is not used: the files are listed from the hard-coded folder C:/Users/My folder/.
  • The insertion point is sent as the literal text x,0,0 instead of the X counter value, so AutoCAD rejects the point.
  • File names are passed without their folder, so -INSERT only finds them when the folder is on the support file search path.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
