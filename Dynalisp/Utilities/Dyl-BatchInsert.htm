Batch Insert

Function Syntax BATCH-INSERT
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Insert every drawing of a folder into the current drawing as blocks, side by side, to review a set of drawings at a glance or gather them in one file.

How To Use

  1. Type BATCH-INSERT and pick the folder in the window (you can also type its path there).
  2. Each drawing of the folder is inserted as a block, at scale 1 and on the current layer, from left to right in the order of their names, the bottoms lined up, a small gap between two.
  3. The view zooms to them, and the command line gives how many were inserted and skipped. One U removes them all.

Commands

CommandNameDescription
BATCH-INSERTBatch InsertInserts every drawing of a folder side by side as blocks in the current drawing.

Known Limitations

  • A drawing whose name is already a block of the current drawing is skipped, so the block there is never redefined: rename or purge it first.
  • The current drawing, when it is in the folder, is skipped too.
  • The blocks go in model space, or in the layout when it is current with no viewport active.

The short names are aliases of the command: change them in Dyl-Suite.
