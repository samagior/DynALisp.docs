Ungroup Nested

Function Syntax UNGROUPNEXT
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Remove every group of the objects you select, groups inside groups too, in one command.

How To Use

  1. Type UNGROUPNEXT.
  2. Select one object of each group.

The short names are aliases of the command: change them in Dyl-Suite.
