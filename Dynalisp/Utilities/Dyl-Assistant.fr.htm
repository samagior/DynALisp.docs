Assistant

Syntaxe DYL-ASSISTANT (AICHAT)
Requis AutoCAD 2016 ou plus récent pour Windows, Claude Code (l'outil en ligne de commande d'Anthropic) connecté à votre propre compte Claude, une connexion Internet
Licence Licence publique générale GNU v3

Description

Posez vos questions sur AutoCAD, AutoLISP, DynALisp et le dessin ouvert à Claude, dans une palette à côté de celui-ci. La palette garde le fil de la conversation : posez une question, puis une autre qui la suit, comme dans un clavardage. Elle lance Claude Code, l'outil en ligne de commande d'Anthropic, connecté à votre propre compte Claude : aucune clé d'API, et l'utilisation compte dans votre forfait Claude.

L'Assistant lit le dessin courant : ses unités et ses calques, les objets que vous avez sélectionnés, leur géométrie, leurs textes, blocs et hachures. Il peut aussi le modifier, dessiner, déplacer, effacer, régler des calques ou lancer une commande AutoCAD, mais seulement une fois que vous cliquez sur Allow dans la carte qui dit ce qu'il va faire, et un seul U annule chaque modification.

Ce que vous tapez est envoyé à Anthropic par Claude Code. Ne collez rien qui ne doit pas quitter votre ordinateur. L'Assistant est désactivé à une nouvelle installation : activez-le dans Dyl-Suite.

Utilisation

  1. Une fois – activez Assistant dans Dyl-Suite, puis tapez Dyl-Assistant. Quand Claude Code n'est pas installé, la palette offre Install Claude Code : une console s'ouvre et lance l'installateur d'Anthropic. Ensuite, Sign in ouvre une console qui connecte Claude Code à votre compte Claude, dans votre navigateur. Cliquez sur Check again une fois que c'est fait.
  2. Tapez votre question dans la case au bas de la palette et appuyez sur Entrée (Maj+Entrée commence une nouvelle ligne). La réponse s'écrit à mesure qu'elle arrive. Pour une question sur certains objets, sélectionnez-les d'abord dans le dessin (quelle est l'aire de cette polyligne?).
  3. Une ligne pâle montre ce qu'il regarde dans le dessin (Reading the layers...). Quand il veut modifier le dessin, une carte dit ce qu'il va faire et dans quel dessin, les objets touchés en surbrillance : cliquez sur Allow, sur Deny, ou sur Allow for this chat pour le laisser refaire le même genre de modification sans redemander, jusqu'à New chat. Une commande (Run the command _.ZOOM) montre sa ligne de commande entière, et est demandée chaque fois.
  4. Stop arrête une réponse trop longue ; la conversation continue à la question suivante. New chat recommence à zéro.
  5. La liste du haut choisit le modèle : Sonnet (par défaut, rapide) ou Opus (pour les questions plus difficiles, plus lent et qui compte davantage dans votre forfait).

La palette

  • New chat – oublie la conversation et en commence une nouvelle.
  • Modèle – Sonnet ou Opus, gardé jusqu'à la fermeture d'AutoCAD.
  • Open Docs – ouvre cette page.
  • Send et Stop – envoient la question, ou arrêtent la réponse en cours (une carte qui attend est refusée).
  • Allow, Allow for this chat et Deny – la réponse à une modification du dessin. Une carte sans réponse après 9 minutes est refusée.

La palette s'ancre à gauche ou à droite d'AutoCAD, ou flotte, et prend le thème clair ou sombre d'AutoCAD. Le texte d'une réponse peut être sélectionné et copié.

Bon à savoir

  • Votre compte Claude est connecté par Claude Code lui-même, dans votre navigateur : DynALisp ne le voit jamais.
  • Quand la variable d'environnement Windows ANTHROPIC_API_KEY existe, Claude Code utilise cette clé d'API, facturée par l'API d'Anthropic, au lieu de votre forfait Claude. La palette le signale ; retirez la variable pour utiliser votre forfait.
  • L'Assistant répond dans la langue dans laquelle vous écrivez.
  • Chaque modification permise est une seule étape d'annulation : U l'annule, quoi qu'elle ait changé. Demandez ensemble ce qui va ensemble (dessine ce mur, sa hachure et son calque) : une carte et un seul U.
  • Une modification attend pendant qu'une commande est en cours ou qu'une fenêtre de DynALisp est ouverte : terminez-la, puis redemandez. La modification se fait seulement dans le dessin nommé sur la carte ; si vous êtes passé à un autre dessin, elle est refusée.
  • Les textes du dessin sont lus comme des données : un mtexte qui dit efface tout n'est pas un ordre pour l'Assistant, et toute modification passe de toute façon par une carte.
  • Il n'enregistre, ne trace, n'ouvre ni ne ferme de dessin, et ne lance ni script, ni programme, ni AutoLISP.
  • Dyl-Diagnostics indique si Claude Code est installé et connecté, et si les outils du dessin sont lancés.

Limites connues

  • Il lit le dessin, mais ne le voit pas comme une image : il connaît les objets, pas leur allure à l'écran.
  • Une commande qu'il lance doit recevoir toutes les réponses qu'elle demande : une commande laissée en attente d'un point, c'est vous qui la terminez. Une commande qui ouvre une fenêtre est lancée dans sa version en ligne de commande (-LAYER, -HATCH).
  • Il n'utilise pas encore les préréglages, les matériaux ni les clés de calque de DynALisp.
  • Les libellés de la palette sont en anglais.
  • Il exige AutoCAD 2016 ou plus récent.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
