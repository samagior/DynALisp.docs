Assistant

Syntaxe DYL-ASSISTANT (AICHAT)
Requis AutoCAD 2016 ou plus récent pour Windows, Claude Code (l'outil en ligne de commande d'Anthropic) connecté à votre propre compte Claude, une connexion Internet
Licence Licence publique générale GNU v3

Description

Posez vos questions sur AutoCAD, AutoLISP et DynALisp à Claude dans une palette à côté de votre dessin. La palette garde le fil de la conversation : posez une question, puis une autre qui la suit, comme dans un clavardage. Elle lance Claude Code, l'outil en ligne de commande d'Anthropic, connecté à votre propre compte Claude : aucune clé d'API, et l'utilisation compte dans votre forfait Claude.

Dans cette première version, l'Assistant ne fait que répondre : il ne lit ni ne modifie le dessin, et ne lance pas de commande. Il donne les étapes, les commandes ou le code AutoLISP pour le faire vous-même.

Ce que vous tapez est envoyé à Anthropic par Claude Code. Ne collez rien qui ne doit pas quitter votre ordinateur. L'Assistant est désactivé à une nouvelle installation : activez-le dans Dyl-Suite.

Utilisation

  1. Une fois – activez Assistant dans Dyl-Suite, puis tapez Dyl-Assistant. Quand Claude Code n'est pas installé, la palette offre Install Claude Code : une console s'ouvre et lance l'installateur d'Anthropic. Ensuite, Sign in ouvre une console qui connecte Claude Code à votre compte Claude, dans votre navigateur. Cliquez sur Check again une fois que c'est fait.
  2. Tapez votre question dans la case au bas de la palette et appuyez sur Entrée (Maj+Entrée commence une nouvelle ligne). La réponse s'écrit à mesure qu'elle arrive.
  3. Stop arrête une réponse trop longue ; la conversation continue à la question suivante. New chat recommence à zéro.
  4. La liste du haut choisit le modèle : Sonnet (par défaut, rapide) ou Opus (pour les questions plus difficiles, plus lent et qui compte davantage dans votre forfait).

La palette

  • New chat – oublie la conversation et en commence une nouvelle.
  • Modèle – Sonnet ou Opus, gardé jusqu'à la fermeture d'AutoCAD.
  • Open Docs – ouvre cette page.
  • Send et Stop – envoient la question, ou arrêtent la réponse en cours.

La palette s'ancre à gauche ou à droite d'AutoCAD, ou flotte, et prend le thème clair ou sombre d'AutoCAD. Le texte d'une réponse peut être sélectionné et copié.

Bon à savoir

  • Votre compte Claude est connecté par Claude Code lui-même, dans votre navigateur : DynALisp ne le voit jamais.
  • Quand la variable d'environnement Windows ANTHROPIC_API_KEY existe, Claude Code utilise cette clé d'API, facturée par l'API d'Anthropic, au lieu de votre forfait Claude. La palette le signale ; retirez la variable pour utiliser votre forfait.
  • L'Assistant répond dans la langue dans laquelle vous écrivez.
  • Dyl-Diagnostics indique si Claude Code est installé et connecté.

Limites connues

  • Il ne voit pas encore votre dessin : décrivez ce dont vous avez besoin.
  • Les libellés de la palette sont en anglais.
  • Il exige AutoCAD 2016 ou plus récent.

Noms des commandes et alias
