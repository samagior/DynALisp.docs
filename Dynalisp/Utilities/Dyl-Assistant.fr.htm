Assistant

Syntaxe DYL-ASSISTANT (AICHAT)
Requis AutoCAD 2025 ou plus récent pour Windows, Claude Code connecté à votre propre compte Claude, une connexion Internet
Licence Licence publique générale GNU v3

Description

Posez vos questions à Claude sur AutoCAD, DynALisp et votre dessin, dans une palette à côté. Il lit le dessin et peut dessiner pour vous, une fois que vous dites oui.

Ce que vous tapez est envoyé à Anthropic. Ne collez rien qui doit rester sur votre ordinateur.

Utilisation

  1. Une fois – activez Assistant dans Dyl-Suite, tapez AICHAT, puis cliquez Install Claude Code et Sign in si la palette le demande.
  2. Tapez votre question et appuyez sur Entrée. Sélectionnez d'abord des objets pour poser une question sur eux.
  3. Pour changer le dessin, il montre une carte : cliquez Allow ou Deny. Un U annule chaque changement.
  4. New chat recommence ; Resume last chat reprend la dernière conversation.

Bon à savoir

  • Il utilise votre propre forfait Claude. Sonnet est rapide, Opus sert aux questions plus difficiles.
  • Il connaît les matériaux et les assemblages de DynALisp, et dit quand une valeur est inconnue.
  • Il travaille dans le dessin seulement : il n'enregistre, ne trace et n'ouvre jamais de fichiers.
  • Il répond dans la langue où vous écrivez.

Limites connues

  • Un changement attend pendant qu'une commande tourne ou qu'une fenêtre DynALisp est ouverte.
  • La palette est en anglais.
