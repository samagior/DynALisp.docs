Count by Layers

Function Syntax COUNTBYLAYERS

Program Description

Total the lengths and areas of what you select, layer by layer, in a table or a file.

How To Use

  1. Type Dyl-CountByLayers and select the lines, arcs, circles and polylines.
  2. Each object gets a label with its length, or its area.
  3. Choose Table, Csv or None for the totals.

Known Limitations

  • The labels are always added: one U removes them.
  • Labels read in feet and metres, whatever the units of the drawing.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
