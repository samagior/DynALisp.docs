Count by Layers

Function Syntax COUNTBYLAYERS
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence Based on Total Area by Lee Mac, Copyright © 2013 (www.lee-mac.com)

Program Description

Total the length of the curves you select, and the area of the closed ones, layer by layer: every object gets a label with its length (or its area and perimeter), and the totals go in a table or a CSV file.

How To Use

  1. Type COUNTBYLAYERS and select the lines, arcs, circles, polylines and splines.
  2. Each object is labelled, and the totals by layer are printed on the command line.
  3. At Output, choose Table to insert a table at a point, Csv to write a file, or None.

Commands

CommandNameDescription
COUNTBYLAYERSCount by LayersTotals the length and area of the selected curves by layer, labels each object and outputs the totals as a table or CSV file.

Known Limitations

  • The labels are always created, even with None; one U removes them all.
  • Labels always show feet and metres, whatever the drawing units (for example a millimetre drawing still reads in ft and m).
  • Drawing-unit values follow LUPREC; converted values are rounded to 2 decimals.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
