Layer Color To Object

Function Syntax LCOL, LAYCOLTOOBJ
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Give objects the color of their layer as their own color, or put them back to ByLayer.

How To Use

  1. Select the objects and type LCOL.
  2. Choose AsIs, Index, TrueColor or ByLayer.
  3. One U undoes it.

Known Limitations

  • Objects on locked layers are not changed.
  • Objects inside blocks keep their colors.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.

CommandAliasesName
