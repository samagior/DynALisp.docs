Layer Color To Object

Function Syntax LCOL, LAYCOLTOOBJ
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Give each object the color of its layer as its own color, in place of ByLayer, ByBlock or another color: as it is, as an index color or as a true color. Or put objects back to ByLayer.

How To Use

  1. Select the objects (or type the command first), then type LCOL.
  2. Choose the color mode: AsIs, Index, TrueColor or ByLayer (Enter keeps the last one of the session).
  3. The command line says how many objects changed. One U undoes it.

Commands

CommandNameDescription
LCOLLayer Color To ObjectApplies the color of each selected object's layer directly to the object.
LAYCOLTOOBJLayer Color To Object (Alias)Alias of LCOL.

Known Limitations

  • Pre-selected objects on locked layers are not filtered out; they are counted as could not be modified.
  • Only the selected objects change: objects inside block definitions keep their own colors.
  • Loading the file prints a loaded message at the command line, so it shows at every DynALisp startup.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.

Bundled program notes 
;;; ==========================================================================
;;; LayerColorToObject.lsp
;;;
;;; Reads the color of each selected object's layer and applies it directly
;;; to the object (replacing ByLayer / ByBlock / any explicit color).
;;;
;;; Color modes:
;;;   AsIs       - Copies the layer color exactly as defined on the layer
;;;                (ACI, true color or color book color).
;;;   Index      - Applies the layer color as an ACI index color. For layers
;;;                using a true color, the closest ACI stored by AutoCAD in
;;;                the layer record (DXF 62) is used.
;;;   TrueColor  - Applies the layer color as an RGB true color. ACI layer
;;;                colors are converted to their RGB equivalent.
;;;   ByLayer    - Reverts the selected objects to the ByLayer color.
;;;
;;; Commands:
;;;   LCOL         - Main command
;;;   LAYCOLTOOBJ  - Alias of LCOL
;;;
;;; Notes:
;;;   - Supports pre-selection (pickfirst).
;;;   - Objects on locked layers are filtered out of the selection.
;;;   - The last chosen mode is remembered for the current session.
;;;   - The whole operation is recorded as a single UNDO step.
;;; ==========================================================================
