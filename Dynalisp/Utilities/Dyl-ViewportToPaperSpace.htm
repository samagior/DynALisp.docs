Viewport To Paper Space

Function Syntax VP2PS
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Turn the content of viewports into paper space objects: what you see through the viewports is copied into the layout at 1:1, exactly where it was on the sheet, and the viewports are deleted. The sheet looks the same, but no longer depends on model space.

How To Use

  1. Go to a layout and type VP2PS.
  2. Choose the result: Decouper (the default: the copies in a block clipped by the viewport, as it looked) or Libre (loose objects, not trimmed at the edge).
  3. Select the viewports. Each one is replaced by its content; one U undoes it all.

Commands

CommandNameDescription
VP2PSViewport To Paper SpaceRecreates the model space objects seen through the selected viewports in paper space, then deletes the viewports.

Known Limitations

  • Perspective viewports are skipped; 3D (non-plan) views keep their depth – use FLATTEN afterwards.
  • Viewport layer overrides (VP colour, linetype…) are not transferred.
  • Copies are no longer associative (dimensions, hatches); check annotative objects and multileaders visually.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).

Bundled program notes 
;;; ==========================================================================
;;; VP2PS.lsp  -  Viewport To Paper Space
;;;
;;; Purpose :
;;;   Recreates the model space objects visible through the selected
;;;   viewports directly in the current layout (paper space) at a 1:1
;;;   scale. Each copy is placed exactly where it appeared on the sheet,
;;;   so the sheet layout is preserved. The source viewports are then
;;;   deleted.
;;;
;;; Commands :
;;;   VP2PS   - Run the conversion on the selected viewports.
;;;
;;; Result modes :
;;;   Decouper (Clip)  - Copies are grouped in a block and clipped (XCLIP)
;;;                      with the viewport boundary. The result is visually
;;;                      identical to the viewport. (default)
;;;   Libre (Free)     - Copies are placed as loose objects in paper space.
;;;                      Objects crossing the viewport edge are NOT trimmed.
;;;
;;; What is handled :
;;;   - Any viewport scale, view center and twist angle.
;;;   - Rectangular and non-rectangular (clipped) viewports.
;;;   - Layers that are off, frozen, or frozen in the viewport are skipped.
;;;   - Objects on locked layers are copied normally.
;;;   - PSLTSCALE = 0 : linetype scales are adjusted to keep dash lengths.
;;;   - Dimensions keep their displayed value and their visual size.
;;;
;;; Limitations :
;;;   - Perspective viewports are skipped.
;;;   - 3D (non-plan) views keep their depth : use FLATTEN afterwards.
;;;   - Viewport layer overrides (VP color, linetype...) are not transferred.
;;;   - Annotative objects and multileaders should be checked visually.
;;;   - Copies are no longer associative (dimensions, hatches).
;;;
;;; The whole operation is recorded as a single UNDO group.
;;; ==========================================================================
