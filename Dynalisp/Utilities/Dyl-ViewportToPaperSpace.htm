Viewport To Paper Space

Function Syntax VP2PS
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Copy what you see through viewports onto the sheet itself, then remove the viewports. The sheet looks the same, without model space.

How To Use

  1. In a layout, type VP2PS.
  2. Choose Decouper (cut at the edge of the viewport) or Libre (not cut).
  3. Select the viewports. One U undoes it.

Known Limitations

  • Perspective viewports are skipped.
  • The colors set per viewport are lost.
  • Dimensions and hatches no longer follow their objects.
