Réinitialiser l'échelle des types de ligne (Reset Linetype Scale)

Syntaxe LTS1, RESETLTSCALE
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Remettez à 1 l'échelle de type de ligne de tous les objets, dans toutes les présentations, sans rien sélectionner.

Utilisation

  1. Tapez LTS1.
  2. Un U l'annule.

Limites connues

  • Les objets dans les blocs gardent leur échelle.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite.

CommandeAliasNom
Dyl-ResetLinetypeScaleLTS1, RESETLTSCALEReset Linetype Scale
