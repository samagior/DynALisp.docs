Réinitialiser l'échelle des types de ligne (Reset Linetype Scale)

Syntaxe LTS1, RESETLTSCALE
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Remettez l'échelle du type de ligne de chaque objet du dessin à 1,0, dans l'espace objet et chaque présentation, attributs compris, sans rien sélectionner.

Utilisation

  1. Tapez LTS1.
  2. La ligne de commande dit combien d'objets ont changé; le dessin est régénéré. Un U l'annule.

Commandes

CommandeNomDescription
LTS1Reset Linetype ScaleRemet à 1,0 l'échelle de type de ligne de chaque objet de l'espace objet et de toutes les présentations.
RESETLTSCALEReset Linetype Scale (Alias)Alias de LTS1 qui remet à 1,0 l'échelle de type de ligne de chaque objet du dessin.

Limites connues

  • Les définitions de blocs ne sont pas traitées : les objets dans les blocs gardent leur propre échelle de type de ligne.
  • Les variables système LTSCALE, CELTSCALE et PSLTSCALE ne sont pas changées.
  • Les messages de la ligne de commande sont en français.
  • Le chargement du fichier affiche un message loaded à la ligne de commande : il apparaît donc à chaque démarrage de DynALisp.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).

Notes du programme d'origine (en anglais) 
;;; ==========================================================================
;;; ResetLtScale.lsp
;;;
;;; Remet l'echelle de type de ligne (LinetypeScale / code DXF 48) a 1.0 sur
;;; tous les objets du dessin : espace objet + tous les onglets de
;;; presentation, y compris les attributs des references de blocs.
;;;
;;; Portee : objets du dessin uniquement.
;;;   - Les definitions de blocs ne sont PAS parcourues.
;;;   - Les variables systeme LTSCALE / CELTSCALE ne sont PAS modifiees.
;;;   - Les references externes (xrefs) sont ignorees.
;;;
;;; Commandes :
;;;   LTS1            - execute la remise a 1.0
;;;   RESETLTSCALE    - alias de LTS1
;;;
;;; Notes :
;;;   Utilise ActiveX : les objets sur des calques verrouilles, geles ou
;;;   desactives sont egalement traites.
;;;   L'operation est enregistree comme une seule transaction UNDO.
;;; ==========================================================================
