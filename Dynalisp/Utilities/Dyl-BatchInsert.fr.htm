Insertion par lot (Batch Insert)

Syntaxe BATCH-INSERT
Requis AutoCAD pour Windows (sélecteur de dossier Shell)
Licence Licence publique générale GNU v3

Description

Insérez chaque dessin d'un dossier dans le dessin courant comme blocs, côte à côte, pour passer en revue un jeu de dessins d'un coup d'œil ou les réunir dans un fichier.

Utilisation

  1. Tapez BATCH-INSERT et choisissez le dossier dans la fenêtre (vous pouvez aussi y taper son chemin).
  2. Chaque dessin du dossier est inséré comme bloc, à l'échelle 1 et sur le calque courant, de gauche à droite dans l'ordre de leurs noms, les bas alignés, un petit espace entre deux.
  3. La vue se règle sur eux, et la ligne de commande donne combien ont été insérés et sautés. Un seul U les retire tous.

Commandes

CommandeNomDescription
BATCH-INSERTBatch InsertInsère chaque dessin d'un dossier côte à côte comme blocs dans le dessin courant.

Limites connues

  • Un dessin dont le nom est déjà un bloc du dessin courant est sauté, pour ne jamais redéfinir le bloc qui s'y trouve : renommez-le ou purgez-le d'abord.
  • Le dessin courant, quand il est dans le dossier, est sauté aussi.
  • Les blocs vont dans l'espace objet, ou dans la présentation quand elle est courante sans fenêtre active.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
