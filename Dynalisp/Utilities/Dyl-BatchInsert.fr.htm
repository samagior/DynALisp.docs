Insertion par lot (Batch Insert)

Syntaxe BATCH-INSERT
Requis AutoCAD pour Windows (sélecteur de dossier Shell)
État En développement – voir Limites connues
Licence Licence publique générale GNU v3

Description

Prévu pour insérer chaque dessin d'un dossier dans le dessin courant comme blocs, côte à côte, pour passer en revue un jeu de dessins d'un coup d'œil.
Il ne fonctionne pas pour l'instant : voir Limites connues.

Utilisation

  1. Tapez BATCH-INSERT et choisissez le dossier dans la fenêtre.
  2. Chaque dessin du dossier devrait être inséré à l'échelle 1, 100 unités à droite du précédent.

Commandes

CommandeNomDescription
BATCH-INSERTBatch InsertInsère chaque dessin d'un dossier côte à côte comme blocs dans le dessin courant.

Limites connues

  • Le dossier choisi dans le sélecteur n'est pas utilisé : les fichiers sont listés depuis le dossier codé en dur C:/Users/My folder/.
  • Le point d'insertion est envoyé comme le texte littéral x,0,0 au lieu de la valeur du compteur X : AutoCAD refuse donc le point.
  • Les noms de fichiers sont passés sans leur dossier : -INSERT ne les trouve donc que si le dossier est dans le chemin de recherche des fichiers de support.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
