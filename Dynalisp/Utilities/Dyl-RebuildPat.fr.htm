Reconstruire les motifs (Rebuild Patterns)

Syntaxe DYL-REBUILDPAT (RPAT), OPENPATS
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Un dessin reçu utilise des motifs de hachures que vous n'avez pas ? Récupérez-les de ses hachures, pour les utiliser dans les vôtres.

Utilisation

  1. Tapez RPAT, sélectionnez des hachures ou appuyez sur Entrée pour toutes.
  2. Les motifs manquants sont ajoutés. OPENPATS ouvre leur dossier.

Limites connues

  • Un motif reconstruit peut différer un peu de l'original.
  • Les remplissages pleins et les dégradés n'ont rien à reconstruire.
