Reconstruire les motifs (Rebuild Patterns)

Syntaxe DYL-REBUILDPAT (RPAT), OPENPATS
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Un dessin reçu de quelqu'un d'autre utilise souvent des motifs de hachures absents de votre ordinateur : les hachures s'affichent, mais le motif ne peut pas être choisi pour une nouvelle hachure (p. ex. dans la fenêtre Hatch Presets, où il est marqué (not found on the support path)). DYL-REBUILDPAT reconstruit les fichiers .pat manquants à partir des hachures du dessin et les enregistre dans un dossier du chemin de recherche des fichiers de support, pour qu'ils puissent être réutilisés et modifiés. Le dessin lui-même n'est pas modifié.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv). Les rangées marquées ↳ sont des commandes enfants de Dyl-RebuildPat : elles se lancent par leur alias (leur commande se nomme Pst-*).
