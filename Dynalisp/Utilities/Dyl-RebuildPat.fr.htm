Reconstruire les motifs (Rebuild Patterns)

Syntaxe DYL-REBUILDPAT (RPAT), OPENPATS
Requis AutoCAD pour Windows (ActiveX / Visual LISP)
Licence Licence publique générale GNU v3

Description

Un dessin reçu d'une autre personne utilise souvent des motifs de hachures que votre ordinateur n'a pas : les hachures s'affichent, mais le motif ne peut pas être choisi pour une nouvelle hachure. Rebuild Patterns réécrit les fichiers .pat manquants d'après les hachures du dessin, dans un dossier où AutoCAD cherche, pour que vous puissiez les utiliser et les modifier. Le dessin lui-même n'est pas modifié.

Utilisation

  1. Tapez RPAT. Sélectionnez des hachures, ou appuyez sur Entrée pour chaque hachure du dessin.
  2. Chaque motif manquant est écrit; pour une hachure sélectionnée dont le motif existe déjà, choisissez Replace, Rename ou Cancel.
  3. La ligne de commande donne le dossier et les motifs écrits. OPENPATS ouvre ce dossier.
  4. Le bouton Pick hatch... de la fenêtre Hatch Presets propose de reconstruire de la même façon le motif de la hachure choisie.

Limites connues

  • Le motif reconstruit peut différer de l'original : vérifiez les hachures dessinées avec lui.
  • Les xréfs, les remplissages pleins, les dégradés et les hachures définies par l'utilisateur sont sautés : ils n'utilisent aucun fichier .pat.
