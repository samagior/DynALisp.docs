Text Fix

Function Syntax DYL-TEXTFIX (TEXTFIX)
Requires AutoCAD 2016 or later for Windows, Claude Code (the command line tool of Anthropic) signed in with your own Claude account, an internet connection
Licence GNU General Public License v3

Program Description

Proofread the texts of a drawing with Claude: each text, mtext and multileader you select is checked for spelling, grammar, accents and punctuation in its own language, never translated, and replaced by its corrected version once you say yes. Technical terms, abbreviations, units, dimensions and codes are left as they are. It goes through Claude Code signed in with your own Claude account: no API key, and the use counts toward your Claude plan.

The text of the objects selected is sent to Anthropic through Claude Code. Do not use it on drawings whose text must not leave your computer. Text Fix is turned off on a new installation: turn it on in Dyl-Suite.

How To Use

  1. Once – turn on Text Fix in Dyl-Suite. When Claude Code is not installed or signed in yet, run Assistant (Dyl-Assistant): its palette installs Claude Code and signs it in with your Claude account.
  2. Select the texts, then type Dyl-TextFix or click Text Fix in the Assistant panel of the ribbon. All the texts are sent to Claude together and AutoCAD waits a few seconds for the answer (a large selection is sent in a few parts).
  3. For each text that changes, the command line shows the original and the correction: answer Oui to replace it, Non to keep it, Tous to accept all the others, Quitter to stop.
  4. A summary gives the texts checked, corrected and failed. One U undoes all the corrections.

Known Limitations

  • Block attributes are not processed (they cannot be selected with the selection prompt).
  • In AutoCAD older than 2021, characters outside the code page of Windows in the reply are replaced by ?.
  • When the Windows environment variable ANTHROPIC_API_KEY is set, Claude Code uses that API key, billed by the Anthropic API, instead of your Claude plan.
  • The prompts of the command line are in French.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
