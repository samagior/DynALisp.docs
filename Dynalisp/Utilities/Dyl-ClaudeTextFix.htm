Claude Text Fix

Function Syntax DYL-CLAUDETEXTFIX (CLAUDETEXT)
Source File Modules\Dynalisp\Apps\Utilities\Dyl-ClaudeTextFix.lsp
Requires AutoCAD for Windows (WinHttp COM object), an Anthropic login (the ant CLI, ant auth login run once) or an Anthropic API key, an internet connection
Licence GNU General Public License v3

Program Description

Proofreads the selected texts, mtexts and multileaders with Claude (the Anthropic API) and replaces each one with its corrected version after you confirm it. Spelling, grammar, accents and punctuation are corrected in the language of the text, never translated; technical terms, abbreviations, units, numbers, dimensions, codes and standard references (e.g. CNB, CSA) are kept, and so are the AutoCAD formatting codes (\P, \f...;, %%c...) and the line structure.

The text of the selected objects is sent to the Anthropic API. Do not use it on drawings whose text must not leave your computer.

How It Works

  1. Sign-in: the ANTHROPIC_API_KEY environment variable when set (it wins), else the Anthropic login of the user (the ant CLI: run ant auth login once; its short-lived token is read again every 10 minutes), else a key asked on the command line.
  2. The API key is taken from the ANTHROPIC_API_KEY Windows environment variable (restart AutoCAD after creating it), else asked on the command line; a key typed is kept for the session only, never saved.
  3. The objects selected before the command are used (right-click menu), else the command asks for a selection: TEXT, MTEXT and MULTILEADER.
  4. Each object is sent on its own (model claude-haiku-5-5, 30 s timeout). When the text changes, the original and the corrected text are shown (Avant / Apres) and the command asks Appliquer la correction ? [Oui/Non/Tous/Quitter] <Oui>: Oui replaces it, Non keeps it, Tous replaces it and every next correction without asking, Quitter stops.
  5. The corrections are written with ActiveX, so objects on locked layers are corrected too. The whole command is one undo step, and a summary gives the objects checked, corrected and failed.

Known Limitations

  • Block attributes are not processed (they cannot be selected with the selection prompt).
  • Characters outside the AutoLISP code page (codes above 255) in the reply are replaced by ?.
  • The prompts of the command line are in French.
