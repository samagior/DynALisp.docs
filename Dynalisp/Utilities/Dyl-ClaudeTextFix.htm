Claude Text Fix

Function Syntax DYL-CLAUDETEXTFIX (CLAUDETEXT)
Requires AutoCAD for Windows (WinHttp COM object), an Anthropic login (the ant CLI, ant auth login run once) or an Anthropic API key, an internet connection
Licence GNU General Public License v3

Program Description

Proofread the texts of a drawing with Claude: each text, mtext and multileader you select is checked for spelling, grammar, accents and punctuation in its own language, never translated, and replaced by its corrected version once you say yes. Technical terms, abbreviations, units, dimensions and codes are left as they are.

The text of the objects selected is sent to the Anthropic API. Do not use it on drawings whose text must not leave your computer.

How To Use

  1. Once – sign in to Anthropic: set the Windows environment variable ANTHROPIC_API_KEY to your API key (then restart AutoCAD), or sign in with the Anthropic command line tool (ant auth login). Without either, the command asks for a key, kept for the session only.
  2. Select the texts, then type Dyl-ClaudeTextFix.
  3. For each text that changes, the command line shows the original and the correction: answer Oui to replace it, Non to keep it, Tous to accept all the others, Quitter to stop.
  4. A summary gives the texts checked, corrected and failed. One U undoes all the corrections.

Known Limitations

  • Block attributes are not processed (they cannot be selected with the selection prompt).
  • Characters outside the AutoLISP code page (codes above 255) in the reply are replaced by ?.
  • The prompts of the command line are in French.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
