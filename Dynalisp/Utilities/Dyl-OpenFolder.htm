Open Folder

Function Syntax DYL-OPENFOLDER
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Open a working folder in Windows Explorer in two keystrokes: the DynALisp folder, the folder of the drawing, the DynALisp templates, the sheet set folder of the project or the AutoCAD support folder.

How To Use

  1. Type Dyl-OpenFolder.
  2. Choose the folder: Repository, CurrentDrawing, Template, SheetSet or sUpport (type its capital letter).
  3. Windows Explorer opens on it; a folder that does not exist is reported.

Commands

CommandNameDescription
DYL-OPENFOLDEROpen FolderOpens the repository, current drawing, template, sheet set or AutoCAD support folder in Windows Explorer.

Known Limitations

  • SheetSet opens the folder only; the sheet set itself is not opened in the Sheet Set Manager.
  • For a drawing that has never been saved, CurrentDrawing and SheetSet start from the default drawing folder.
