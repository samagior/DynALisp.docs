Open Folder

Function Syntax DYL-OPENFOLDER

Program Description

Open a working folder in two keystrokes: DynALisp, the drawing, the templates, the sheet set or the AutoCAD support folder.

How To Use

  1. Type Dyl-OpenFolder.
  2. Type the capital letter of the folder: Repository, CurrentDrawing, Template, SheetSet or sUpport.
