Correction de texte (Text Fix)

Syntaxe DYL-TEXTFIX (TEXTFIX)
Requis AutoCAD 2016 ou plus récent pour Windows, Claude Code (l'outil en ligne de commande d'Anthropic) connecté à votre propre compte Claude, une connexion Internet
Licence Licence publique générale GNU v3

Description

Faites relire les textes d'un dessin par Claude : chaque texte, texte multiligne et ligne de repère multiple sélectionné est vérifié pour l'orthographe, la grammaire, les accents et la ponctuation dans sa propre langue, jamais traduit, et remplacé par sa version corrigée une fois que vous dites oui. Les termes techniques, abréviations, unités, cotes et codes restent tels quels. Elle passe par Claude Code connecté à votre propre compte Claude : aucune clé d'API, et l'utilisation compte dans votre forfait Claude.

Le texte des objets sélectionnés est envoyé à Anthropic par Claude Code. Ne l'utilisez pas sur des dessins dont le texte ne doit pas quitter votre ordinateur. Text Fix est désactivé à une nouvelle installation : activez-le dans Dyl-Suite.

Utilisation

  1. Une fois – activez Text Fix dans Dyl-Suite. Quand Claude Code n'est pas encore installé ou connecté, lancez l'Assistant (Dyl-Assistant) : sa palette installe Claude Code et le connecte à votre compte Claude.
  2. Sélectionnez les textes, puis tapez Dyl-TextFix. Tous les textes sont envoyés ensemble à Claude et AutoCAD attend la réponse quelques secondes (une grande sélection est envoyée en quelques parties).
  3. Pour chaque texte qui change, la ligne de commande montre l'original et la correction : répondez Oui pour le remplacer, Non pour le garder, Tous pour accepter tous les autres, Quitter pour arrêter.
  4. Un résumé donne les textes vérifiés, corrigés et en échec. Un U annule toutes les corrections.

Limites connues

  • Les attributs de blocs ne sont pas traités (ils ne peuvent pas être sélectionnés à l'invite de sélection).
  • Dans un AutoCAD antérieur à 2021, les caractères hors de la page de codes de Windows dans la réponse sont remplacés par ?.
  • Quand la variable d'environnement Windows ANTHROPIC_API_KEY existe, Claude Code utilise cette clé d'API, facturée par l'API d'Anthropic, au lieu de votre forfait Claude.
  • Les invites de la ligne de commande sont en français.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
