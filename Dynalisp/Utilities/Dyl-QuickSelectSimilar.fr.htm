Sélection rapide semblable (Quick Select Similar)

Syntaxe QSS, QSELECTSIMILAR
Fichier source Modules\Dynalisp\Apps\Utilities\Dyl-QuickSelectSimilar.lsp
Requis AutoCAD pour Windows (fenêtre DCL générée à l'exécution)
Licence Licence publique générale GNU v3

Description

Un SELECTSIMILAR personnalisable : il sélectionne chaque objet visible de l'espace courant qui correspond aux types d'objets et aux filtres de propriétés choisis dans une fenêtre, préremplie à partir d'objets de référence. La fenêtre est en français.

Commandes

CommandeNomDescription
QSSQuick Select SimilarSélectionne les objets visibles qui correspondent aux types et propriétés choisis dans une fenêtre.
QSELECTSIMILARQuick Select Similar (Alias)Alias de QSS.

Fonctionnement

  1. Présélectionnez un ou plusieurs objets de référence, ou choisissez-les à l'invite. Appuyez sur Entrée sans sélection pour rouvrir la fenêtre avec les derniers réglages.
  2. La fenêtre Selection rapide d'objets similaires liste les types d'objets visibles dans l'espace courant avec leurs comptes à jour; les types des références sont sélectionnés.
  3. Les filtres de propriétés sont préremplis à partir des références : calque, couleur (ACI), type de ligne, épaisseur de ligne, style de texte, style de cote et nom de bloc (nom effectif, blocs dynamiques compris). Cochez les filtres à utiliser et modifiez les valeurs : les valeurs séparées par des virgules et les caractères génériques * ? sont permis.
  4. Réglez la portée (tout l'espace courant, ou la vue courante seulement) et les options (exclure les calques verrouillés, ajouter à la sélection courante). Choisir reference < choisit de nouvelles références sans perdre les réglages.
  5. Avec OK, les objets correspondants sont affichés avec leurs poignées et gardés comme sélection Précédent, et un compte par type est affiché.

Logique des filtres

  • Les valeurs d'un même champ se combinent par OU; les champs cochés se combinent par ET.
  • Le style de texte, le style de cote et le nom de bloc ne restreignent que leurs propres types d'objets; les autres types sélectionnés n'en sont pas touchés.
  • Visible veut dire calque activé et libéré, et objet non invisible.

Limites connues

  • Les calques gelés seulement dans une fenêtre de l'espace papier ne sont pas détectés comme masqués.
  • Le filtre de couleur compare les couleurs d'index (les couleurs vraies utilisent leur ACI).
  • Les réglages sont mémorisés pour la session du dessin seulement.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).

Notes du programme d'origine (en anglais) 
;;; ==========================================================================
;;; QuickSelectSimilar.lsp
;;;
;;; Customizable "Select Similar" for AutoCAD / AutoCAD Architecture.
;;;
;;; Selects every visible object of the current space that matches criteria
;;; chosen on the fly in a dialog box:
;;;   - one or many object types (DXF names, shown with live counts);
;;;   - optional property filters, combined with a logical AND:
;;;       Layer, Color, Linetype, Lineweight,
;;;       Text style (TEXT / MTEXT / ATTDEF), Dim style (dimensions),
;;;       Block name (block references, dynamic blocks supported);
;;;   - scope: whole current space or current view only;
;;;   - options: exclude locked layers, add to the current selection.
;;;
;;; Filter syntax:
;;;   Each field accepts comma-separated values and the * ? wildcards.
;;;   Within one field, values are combined with OR.
;;;   Type-specific filters (text style, dim style, block name) only restrict
;;;   their own object types; other selected types are not affected by them.
;;;
;;; Commands:
;;;   QSS              - run the command
;;;   QSELECTSIMILAR   - alias of QSS
;;;
;;; Workflow:
;;;   1. Pre-select reference object(s), or pick them at the prompt
;;;      (press Enter to skip and open the dialog with the last settings).
;;;   2. The dialog is pre-filled with the reference types and properties.
;;;      Check the filters to apply, edit values as needed.
;;;   3. "Choisir reference <" lets you pick new reference objects without
;;;      losing the dialog settings.
;;;   4. OK: the result is gripped (PICKFIRST) and stored as "Previous".
;;;
;;; Notes:
;;;   - "Visible" means: layer on and thawed, object not invisible (DXF 60).
;;;     Layers frozen only in a paper space viewport (VP freeze) are not
;;;     detected.
;;;   - The color filter compares ACI values (true colors use their ACI).
;;;   - Dialog settings are remembered for the current drawing session.
;;;   - The dialog definition (DCL) is generated at run time, so this single
;;;     .lsp file is all that is needed.
;;; ==========================================================================
