Sélection rapide semblable (Quick Select Similar)

Syntaxe QSS, QSELECTSIMILAR
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Sélectionnez tous les objets semblables à ceux que vous choisissez, selon ce que vous cochez : type, calque, couleur, type de ligne, style ou bloc.

Utilisation

  1. Sélectionnez un ou plusieurs objets et tapez QSS.
  2. Cochez ce qui doit correspondre, et tout l'espace ou la vue.
  3. Cliquez OK : les objets sont sélectionnés pour votre prochaine commande.

Limites connues

  • Un calque gelé dans une fenêtre seulement compte encore comme visible.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite.
