Rebuild Patterns

Function Syntax DYL-REBUILDPAT (RPAT), OPENPATS
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

A drawing from someone else often uses hatch patterns your computer does not have: the hatches show, but the pattern cannot be picked for a new hatch. Rebuild Patterns writes the missing .pat files back from the hatches of the drawing, into a folder AutoCAD searches, so you can use and edit them. The drawing itself is not changed.

How To Use

  1. Type RPAT. Select hatches, or press Enter for every hatch of the drawing.
  2. Each missing pattern is written; for a hatch selected whose pattern exists already, choose Replace, Rename or Cancel.
  3. The command line gives the folder and the patterns written. OPENPATS opens that folder.
  4. The Pick hatch... button of the Hatch Presets window offers to rebuild the pattern of the hatch picked the same way.

Known Limitations

  • The pattern rebuilt can differ from the original: check the hatches drawn with it.
  • Xrefs, solid fills, gradients and user-defined hatches are skipped: they use no .pat file.
