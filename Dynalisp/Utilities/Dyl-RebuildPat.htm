Rebuild Patterns

Function Syntax DYL-REBUILDPAT (RPAT), OPENPATS
Source File Modules\Dynalisp\Apps\Utilities\Dyl-RebuildPat.lsp
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

A drawing received from someone else often uses hatch patterns that are not on your computer: the hatches show, but the pattern cannot be picked for a new hatch (e.g. in the Hatch Presets window, where it is marked (not found on the support path)). DYL-REBUILDPAT rebuilds the missing .pat files from the hatches of the drawing and saves them in a folder of the support file search path, so they can be reused and edited. The drawing itself is not modified.

How It Works

  1. Select hatches, or press Enter to use every hatch of the drawing (model space, every layout and every block definition). Xrefs and xref-dependent blocks, solid fills, gradients and user-defined hatches are skipped (they use no .pat file).
  2. Every hatch keeps a copy of its pattern definition, transformed by its scale, angle and origin. The routine reverses that transformation to get the original definition (scale 1, angle 0) and writes it in the standard .pat format: one pattern per file, named after the pattern. The file says the units of the pattern, those of the drawing (;%UNITS=MM in a metric drawing, ;%UNITS=INCH in an imperial one), so the hatch presets scale it for both.
  3. A pattern is missing when no <name>.pat is found and the name is not in acad.pat or acadiso.pat: it is always rebuilt. A pattern that exists is left as it is for the whole drawing; with selected hatches, the command asks [Replace/Rename/Cancel] (Replace is not offered for a pattern of acad.pat / acadiso.pat).
  4. The folder: a folder named pats already in the support file search path (e.g. the one AutoCAD Architecture installs), else <ROAMABLEROOTPREFIX>\Support\pats (the roaming folder of the product, release and language running), created when needed. When it is not in the support file search path, it is added to the current profile. The command line gives the folder and the patterns written.

OPENPATS opens that pattern folder in Windows Explorer.

The Pick hatch... button of the Hatch Presets window rebuilds the pattern of the hatch picked the same way, when no .pat file has it and you agree. It uses this program: when Rebuild Patterns is turned off in the Startup Suite, it asks to turn it on first.
