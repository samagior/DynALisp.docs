Reset Linetype Scale

Function Syntax LTS1, RESETLTSCALE
Source File Modules\Dynalisp\Apps\Utilities\Dyl-ResetLinetypeScale.lsp
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Resets the linetype scale of every object of the drawing to 1.0, in model space and all layouts, block attributes included. No selection is needed.

Commands

CommandNameDescription
LTS1Reset Linetype ScaleResets the linetype scale of every object in model space and all layouts to 1.0.
RESETLTSCALEReset Linetype Scale (Alias)Alias of LTS1 that resets the linetype scale of every drawing object to 1.0.

How It Works

  1. The routine goes through model space and every layout (external references are skipped).
  2. Each object whose linetype scale (DXF 48) is not 1.0 is set to 1.0, as well as the attributes of block references.
  3. Objects on locked, frozen or off layers are processed too.
  4. The change is one undo step; a REGENALL runs when something changed, and the command reports the number of objects and spaces processed.

Known Limitations

  • Block definitions are not processed: objects inside blocks keep their own linetype scale.
  • The LTSCALE, CELTSCALE and PSLTSCALE system variables are not changed.
  • Command line messages are in French.
  • Loading the file prints a loaded message at the command line, so it shows at every DynALisp startup.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
