Reset Linetype Scale

Function Syntax LTS1, RESETLTSCALE
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Put the linetype scale of every object back to 1, in every layout, without selecting anything.

How To Use

  1. Type LTS1.
  2. One U undoes it.

Known Limitations

  • Objects inside blocks keep their scale.
  • The messages are in French.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.
