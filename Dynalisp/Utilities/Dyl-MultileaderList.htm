Multileader List

Function Syntax MLLIST

Program Description

Count the multileaders and blocks of a selection by what they say, for a door or a keynote schedule.

How To Use

  1. Select the multileaders and blocks, then type MLLIST.
  2. The command line lists each one with its count, [x3].

Known Limitations

  • Dynamic blocks show a *U… name.
  • Two blocks with the same values read the same.
  • On the command line only.
