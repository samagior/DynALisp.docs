Multileader List

Function Syntax MLLIST
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Count the multileaders and blocks of a selection by their content: one line per kind (block name and attribute values, or leader text), with its count. Handy for a door or a keynote schedule.

How To Use

  1. Select the multileaders and blocks, then type MLLIST (or type it first, then select).
  2. The command line lists each content with its count, [x3], sorted, then the totals.

Commands

CommandNameDescription
MLLISTMultileader and Block ListLists the selected multileaders and blocks grouped by attribute values with a count per group.

Known Limitations

  • Dynamic blocks are listed under their anonymous name (*U…), not their block name.
  • For blocks with attributes only the TAG=value pairs are printed, so two different blocks with the same attribute values print identical lines.
  • Multileader text is printed with its raw Mtext formatting codes.
  • A selected MINSERT block stops the command with an error.
  • The list is printed at the command line only (no table or file).
  • Loading the file prints a loaded message at the command line, so it shows at every DynALisp startup.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).
