Correction de texte Claude (Claude Text Fix)

Syntaxe DYL-CLAUDETEXTFIX (CLAUDETEXT)
Requis AutoCAD pour Windows (objet COM WinHttp), une connexion Anthropic (l'outil ant, ant auth login lancé une fois) ou une clé d'API Anthropic, une connexion Internet
Licence Licence publique générale GNU v3

Description

Faites relire les textes d'un dessin par Claude : chaque texte, texte multiligne et ligne de repère multiple sélectionné est vérifié pour l'orthographe, la grammaire, les accents et la ponctuation dans sa propre langue, jamais traduit, et remplacé par sa version corrigée une fois que vous dites oui. Les termes techniques, abréviations, unités, cotes et codes restent tels quels.

Le texte des objets sélectionnés est envoyé à l'API d'Anthropic. Ne l'utilisez pas sur des dessins dont le texte ne doit pas quitter votre ordinateur.

Utilisation

  1. Une fois – connectez-vous à Anthropic : réglez la variable d'environnement Windows ANTHROPIC_API_KEY à votre clé d'API (puis redémarrez AutoCAD), ou connectez-vous avec l'outil en ligne de commande d'Anthropic (ant auth login). Sans l'un ni l'autre, la commande demande une clé, gardée pour la session seulement.
  2. Sélectionnez les textes, puis tapez Dyl-ClaudeTextFix.
  3. Pour chaque texte qui change, la ligne de commande montre l'original et la correction : répondez Oui pour le remplacer, Non pour le garder, Tous pour accepter tous les autres, Quitter pour arrêter.
  4. Un résumé donne les textes vérifiés, corrigés et en échec. Un U annule toutes les corrections.

Limites connues

  • Les attributs de blocs ne sont pas traités (ils ne peuvent pas être sélectionnés à l'invite de sélection).
  • Les caractères hors de la page de codes d'AutoLISP (codes au-dessus de 255) dans la réponse sont remplacés par ?.
  • Les invites de la ligne de commande sont en français.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
