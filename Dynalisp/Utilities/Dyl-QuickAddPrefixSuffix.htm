Quick Add Prefix / Suffix

Function Syntax DYL-QUICKADDPREFIXSUFFIX and 7 dimension texts (DT-PM, DT-DIA, DT-MAX, DT-MIN, DT-TYP, DT-OB, DT-OL)
Source File Modules\Dynalisp\Apps\Utilities\Dyl-QuickAddPrefixSuffix.lsp
Licence GNU General Public License v3

Program Description

DYL-QUICKADDPREFIXSUFFIX lists every dimension text preset with its alias: double-click one (or OK) to apply it to the dimension you select next. The presets are child commands (Pst-*) run by their aliases, which can be added, renamed or removed in Dyl-Suite (see Command Names And Aliases).

A set of seven one-pick toggles that add or remove a standard qualifier on the text of a dimension while keeping the measured value live. Running the same command on the same dimension a second time removes the qualifier again.

How It Works

  1. The command prompts Select dimension: and reads the dimension text override (DXF group 1). The measured value is represented in the override by <>.
  2. If the qualifier is not present yet:
    • an empty override (plain measured value) becomes <qualifier><>;
    • an override that already contains <> gets the qualifier inserted right before <>;
    • an override without <> (fully typed text) is left untouched.
  3. If the qualifier is present, it is removed: an override equal to <qualifier><> is cleared back to the plain measured value, otherwise <qualifier><> is replaced by <>.
  4. The change is written with entmod, so it can be undone with U.

Known Limitations

  • The suffix commands (DT-TYP, DT-OB, DT-OL) store a prefix/suffix type, but the routine always inserts the text before <>, so suffixes currently display in front of the value (e.g. (TYP)1200).
  • Only one dimension is processed per run and the pick is not filtered to dimension objects.
  • Pressing Enter or missing the pick at the prompt ends the command with an error message.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-QuickAddPrefixSuffix: they are run by their alias, or picked from Dyl-QuickAddPrefixSuffix when it lists them (their command is named Pst-*).
