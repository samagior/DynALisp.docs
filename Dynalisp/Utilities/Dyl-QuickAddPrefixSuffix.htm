Quick Add Prefix / Suffix

Function Syntax DYL-QUICKADDPREFIXSUFFIX and 7 dimension texts (DT-PM, DT-DIA, DT-MAX, DT-MIN, DT-TYP, DT-OB, DT-OL)

Program Description

Add ±, Ø, max., min., (TYP), (OB) or (OL) to a dimension in one pick. Pick it again to take it off.

How To Use

  1. Type DT-PM, DT-DIA, DT-MAX, DT-MIN, DT-TYP, DT-OB or DT-OL.
  2. Pick the dimension.

Known Limitations

  • (TYP), (OB) and (OL) show before the value, not after.
  • One dimension at a time.
