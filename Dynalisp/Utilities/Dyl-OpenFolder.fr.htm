Ouvrir un dossier (Open Folder)

Syntaxe DYL-OPENFOLDER
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Ouvrez un dossier de travail dans l'Explorateur Windows en deux touches : le dossier de DynALisp, le dossier du dessin, les gabarits de DynALisp, le dossier du jeu de feuilles du projet ou le dossier de support d'AutoCAD.

Utilisation

  1. Tapez Dyl-OpenFolder.
  2. Choisissez le dossier : Repository, CurrentDrawing, Template, SheetSet ou sUpport (tapez sa majuscule).
  3. L'Explorateur Windows s'ouvre dessus; un dossier qui n'existe pas est signalé.

Commandes

CommandeNomDescription
DYL-OPENFOLDEROpen FolderOuvre dans l'Explorateur Windows le dossier du dépôt, du dessin courant, des gabarits, du jeu de feuilles ou de support d'AutoCAD.

Limites connues

  • SheetSet ouvre seulement le dossier; le jeu de feuilles lui-même n'est pas ouvert dans le Gestionnaire du jeu de feuilles.
  • Pour un dessin jamais enregistré, CurrentDrawing et SheetSet partent du dossier de dessin par défaut.

Noms des commandes et alias

Les noms courts sont des alias de la commande : modifiez-les dans Dyl-Suite.
