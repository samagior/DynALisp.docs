Ouvrir un dossier (Open Folder)

Syntaxe DYL-OPENFOLDER
Requis AutoCAD pour Windows (Explorateur Windows)
Licence Licence publique générale GNU v3

Description

Ouvre un dossier de travail dans l'Explorateur Windows : le paquet DynALisp, le dossier du dessin courant, les gabarits de modèle Dynalisp, le dossier du jeu de feuilles du projet courant ou le dossier de support d'AutoCAD.

Commandes

CommandeNomDescription
DYL-OPENFOLDEROpen FolderOuvre dans l'Explorateur Windows le dossier du dépôt, du dessin courant, des gabarits, du jeu de feuilles ou de support d'AutoCAD.

Limites connues

  • SheetSet ouvre seulement le dossier; le jeu de feuilles lui-même n'est pas ouvert dans le Gestionnaire du jeu de feuilles.
  • Pour un dessin jamais enregistré, CurrentDrawing et SheetSet partent du dossier de dessin par défaut.

Noms des commandes et alias

Chaque programme a une commande principale qui commence par Dyl-. Les noms courts sont ses alias : ils lancent la même commande, et s'ajoutent, se renomment ou se retirent dans Dyl-Suite (enregistrés dans Resources\Aliases.csv).
