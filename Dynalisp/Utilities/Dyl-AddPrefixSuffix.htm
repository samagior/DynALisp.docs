Add Prefix / Suffix

Function Syntax TXTPS
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

Add the same text to the start or the end of every text and mtext you select, in one step: a level number before every room name, a unit after every value.

How To Use

  1. Type TXTPS and select the texts; only texts and mtexts are kept.
  2. Choose Prefix or Suffix (Enter: Suffix), then type the text to add, spaces included.
  3. Every text selected gets it; one U undoes the whole change.

Commands

CommandNameDescription
TXTPSText Prefix SuffixAdds a user string as a prefix or suffix to the selected Text and Mtext objects.

Known Limitations

  • For Mtext the string is added to the raw contents: a prefix goes before any opening formatting codes, so it may not take the formatting of the first word.
  • Objects on locked layers are not filtered out of the selection; editing one stops the command with an error.
  • Attributes, dimensions and multileaders are not handled.
  • Loading the file prints a loaded message at the command line, so it shows at every DynALisp startup.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).

Bundled program notes 
;;; ==============================================================
;;; AddPrefixSuffix.lsp
;;;
;;; Adds a user-chosen string to the beginning (prefix) or end
;;; (suffix) of the text content of all selected TEXT and MTEXT
;;; entities.
;;;
;;; COMMAND:  TXTPS
;;;
;;; USAGE:
;;;   1. Load this file (APPLOAD, or drag-and-drop onto the
;;;      AutoCAD window).
;;;   2. Type TXTPS at the command line.
;;;   3. Select the TEXT / MTEXT objects to modify (other object
;;;      types in the selection are ignored automatically).
;;;   4. Choose whether to add the string as a Prefix or Suffix.
;;;   5. Type the text to add.
;;;
;;; NOTES:
;;;   - Works on both single-line TEXT and multiline MTEXT.
;;;   - For MTEXT, the string is added to the raw TextString
;;;     (including any formatting codes it may already contain),
;;;     so existing formatting is preserved.
;;;   - Wrapped in a single UNDO group, so one U / CTRL+Z undoes
;;;     the whole operation.
;;; ==============================================================
