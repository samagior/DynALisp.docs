Add Prefix / Suffix

Function Syntax TXTPS
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Program Description

Add the same text before or after every text you select: a level number before each room name, a unit after each value.

How To Use

  1. Type TXTPS and select the texts.
  2. Choose Prefix or Suffix, then type the text to add.
  3. One U undoes it.

Known Limitations

  • Texts and mtexts only: not attributes, dimensions or multileaders.
  • Unlock the layers first.

Command Names And Aliases

The short names are aliases of the command: change them in Dyl-Suite.

CommandAliasesName
Dyl-AddPrefixSuffixTXTPSText Prefix Suffix
