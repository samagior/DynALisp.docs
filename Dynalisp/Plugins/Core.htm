Core

Setting None: always on
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Description

The core of DynALisp in .NET. It reads the data of DynALisp (the layer keys, the materials, the hatch presets, the presets of Quick Draw and Quick Shape, the assemblies, the groups, the climates, the Startup Suite and the aliases read as each drawing opens...) once for the whole session of AutoCAD, and gives it to every drawing: a drawing opened after the first one no longer reads those files again. A file changed, by a window of DynALisp, in another drawing or in Excel, is read again the next time it is needed.

How To Use

Nothing to do: it is loaded with AutoCAD, and the tools of DynALisp use it on their own.

Notes

  • When it is not loaded (blocked by SECURELOAD, or a file missing), DynALisp works the same, only slower: each drawing reads the files again. Dyl-Diagnostics says so, and shows how many files it keeps and the time it spent reading them.
  • For whoever changes DynALisp: the source is Installer\Core, one project built for .NET 8 (AutoCAD 2025 and 2026) and for .NET 10 (AutoCAD 2027 and later), both DLLs committed.
