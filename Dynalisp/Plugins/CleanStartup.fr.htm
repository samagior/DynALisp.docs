Démarrage épuré

Description

Une ligne de commande propre au démarrage d'AutoCAD : seules les lignes de DynALisp et les erreurs restent.

Utilisation

  1. Dans Dyl-Settings, activez Clean startup, puis Save.
  2. Redémarrez AutoCAD.

Bon à savoir

  • Les lignes s'affichent un instant, puis disparaissent quand AutoCAD est prêt.
  • Toutes les lignes restent dans la fenêtre de texte (F2).
