Démarrage épuré

Paramètre Clean startup, dans les dérogations (Overrides) de Dyl-Settings (DynalispCleanStartup), désactivé à une nouvelle installation
Requis AutoCAD 2015 ou suivant pour Windows
Licence Licence publique générale GNU v3

Description

Une fois AutoCAD démarré, les lignes qu'il a affichées au démarrage (Loading AEC..., Customization file loaded successfully, les palettes et les commandes de démarrage de l'espace de travail...) sont retirées de la ligne de commande. Conservées : la ligne Drawing created using..., les lignes de DynALisp et toute ligne qui signale une erreur ou un avertissement. Activez-le dans Dyl-Settings : il s'applique au prochain démarrage.

Utilisation

  1. Dans Dyl-Settings, cochez Clean startup (dans Overrides), puis Save.
  2. Redémarrez AutoCAD : une fois démarré, la ligne de commande ne garde que le dessin créé, les lignes de DynALisp et les erreurs.

Notes

  • AutoCAD et ses déclinaisons (AutoCAD Architecture...) affichent la plupart de ces lignes avant le chargement de DynALisp, et aucun réglage d'AutoCAD ne les supprime : elles sont retirées une fois le démarrage terminé, quand DynALisp est chargé, qu'aucune commande ne tourne et qu'aucune ligne n'est arrivée depuis 2 secondes. Elles peuvent s'afficher un moment d'ici là. Si DynALisp loaded n'est pas arrivé après 30 secondes, les lignes sont retirées quand même; après 2 minutes, rien n'est fait.
  • Une ligne est conservée quand elle contient Drawing created using, commence par DynALisp, Dyl-Settings ou -->, ou contient error, warning, exception, failed, unable, cannot, not found, invalid, unknown command ou missing.
  • Seule la ligne de commande est épurée : les lignes retirées deviennent des lignes vides au-dessus de celles conservées (visibles en remontant son historique), et la fenêtre de texte (F2) garde toutes les lignes du démarrage. AutoCAD garde sa propre copie des lignes et ajoute les suivantes après le nombre de lignes affichées : la ligne de commande garde donc ce nombre.
  • L'avis System Variable Changed est celui d'AutoCAD : SYSMON 0 le désactive pour de bon, que Clean startup soit activé ou non.
  • AutoCAD n'a pas de commande pour cela : le module d'extension utilise la liste des lignes de la ligne de commande, et ne fait rien dans une version où il ne la trouve pas. Dans une version antérieure à 2015, le module d'extension n'est pas chargé et le paramètre est grisé.
  • Pour qui modifie DynALisp : la source est Installer\Startup, un seul projet compilé pour .NET 8 et pour .NET Framework 4.8, les deux DLL validées dans git.
