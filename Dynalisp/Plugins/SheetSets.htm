Reopen Sheet Sets

Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Description

Your sheet sets open again each time AutoCAD starts, as you left them in the Sheet Set Manager.

How To Use

  1. In Dyl-Settings, turn on Reopen sheet sets, then Save.
  2. Open your sheet sets in the Sheet Set Manager as usual.
  3. Next time AutoCAD starts, they open again.
  4. To forget one, close it in the Sheet Set Manager.
