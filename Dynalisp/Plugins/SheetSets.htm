Reopen Sheet Sets

Setting Reopen sheet sets, in the Overrides of Dyl-Settings, off on a new installation
Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Description

The Sheet Set Manager of AutoCAD forgets the sheet sets it had open when AutoCAD closes: each day, they are opened again one by one. With Reopen sheet sets on, DynALisp remembers the sheet sets open in the Sheet Set Manager and opens them again each time AutoCAD starts, until you close them yourself in the manager.

How To Use

  1. In Dyl-Settings, check Reopen sheet sets (in Overrides), then Save. The sheet sets open now are remembered at once.
  2. Open your sheet sets in the Sheet Set Manager as usual (SHEETSET, Open...).
  3. Close AutoCAD and start it again: once the first drawing is open and AutoCAD is idle, the same sheet sets open again in the Sheet Set Manager.
  4. A sheet set you no longer need: close it in the Sheet Set Manager (right-click its name, Close Sheet Set). It is not opened again.

Notes

  • The sheet sets open are noted after each command, when a drawing is made current or closed, and when AutoCAD closes. A sheet set closed in the manager just before AutoCAD stops on an error may open once more at the next startup.
  • The Sheet Set Manager shows the last sheet set opened again; the others are in its list at the top.
  • A sheet set whose file no longer exists (moved, renamed, deleted) is no longer remembered: the command line says so at startup. One that exists but cannot be opened (a server not reachable yet) is kept for the next startup.
  • The list is kept on this computer: it is not part of the settings exported by Dyl-UserFiles. Turning the setting off forgets it.
  • When AutoCAD starts without a drawing (the Start tab only), the sheet sets open with the first drawing.
  • For whoever changes DynALisp: the plugin is the one of Clean Startup; its source is Installer\Startup.
