Windows

Description

The windows of DynALisp: clear sections, a switch for each setting, and an Open Docs button in each one.

Good To Know

  • A window with a list can be resized and maximized. It opens again where you left it.
  • A square button beside a setting opens its options.
  • A setting greyed out is not available yet: turn on the setting above it.
  • The windows follow the light or dark theme of AutoCAD, and the Interface colors you chose.
