Rouvrir les jeux de feuilles

Paramètre Reopen sheet sets, dans les dérogations (Overrides) de Dyl-Settings, désactivé à une nouvelle installation
Requis AutoCAD 2025 ou suivant pour Windows
Licence GNU General Public License v3

Description

Le Gestionnaire du jeu de feuilles d'AutoCAD oublie les jeux de feuilles qu'il avait ouverts quand AutoCAD se ferme : chaque jour, il faut les rouvrir un par un. Avec Reopen sheet sets activé, DynALisp mémorise les jeux de feuilles ouverts dans le Gestionnaire du jeu de feuilles et les rouvre à chaque démarrage d'AutoCAD, jusqu'à ce que vous les fermiez vous-même dans le gestionnaire.

Utilisation

  1. Dans Dyl-Settings, cochez Reopen sheet sets (dans Overrides), puis Save. Les jeux de feuilles ouverts à ce moment sont mémorisés aussitôt.
  2. Ouvrez vos jeux de feuilles dans le Gestionnaire du jeu de feuilles comme d'habitude (SHEETSET, Ouvrir...).
  3. Fermez AutoCAD et redémarrez-le : une fois le premier dessin ouvert et AutoCAD au repos, les mêmes jeux de feuilles se rouvrent dans le Gestionnaire du jeu de feuilles.
  4. Un jeu de feuilles dont vous n'avez plus besoin : fermez-le dans le Gestionnaire du jeu de feuilles (clic droit sur son nom, Fermer le jeu de feuilles). Il n'est plus rouvert.

Notes

  • Les jeux de feuilles ouverts sont notés après chaque commande, quand un dessin devient courant ou se ferme, et à la fermeture d'AutoCAD. Un jeu de feuilles fermé dans le gestionnaire juste avant qu'AutoCAD s'arrête sur une erreur peut se rouvrir une fois de plus au démarrage suivant.
  • Le Gestionnaire du jeu de feuilles affiche le dernier jeu rouvert ; les autres sont dans sa liste du haut.
  • Un jeu de feuilles dont le fichier n'existe plus (déplacé, renommé, supprimé) n'est plus mémorisé : la ligne de commande le dit au démarrage. Un jeu qui existe mais ne peut pas s'ouvrir (un serveur pas encore joignable) est gardé pour le démarrage suivant.
  • La liste reste sur cet ordinateur : elle ne fait pas partie des réglages exportés par Dyl-UserFiles. Désactiver le réglage l'oublie.
  • Quand AutoCAD démarre sans dessin (l'onglet Démarrer seulement), les jeux de feuilles s'ouvrent avec le premier dessin.
  • Pour qui modifie DynALisp : le plug-in est celui du Démarrage épuré ; sa source est Installer\Startup.
