Rouvrir les jeux de feuilles

Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Vos jeux de feuilles se rouvrent à chaque démarrage d'AutoCAD, comme vous les avez laissés dans le Gestionnaire du jeu de feuilles.

Utilisation

  1. Dans Dyl-Settings, activez Reopen sheet sets, puis Save.
  2. Ouvrez vos jeux de feuilles dans le Gestionnaire du jeu de feuilles comme d'habitude.
  3. Au prochain démarrage d'AutoCAD, ils se rouvrent.
  4. Pour en oublier un, fermez-le dans le Gestionnaire du jeu de feuilles.
