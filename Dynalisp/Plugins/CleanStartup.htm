Clean Startup

Requires AutoCAD 2025 or later for Windows
Licence GNU General Public License v3

Description

A clean command line when AutoCAD starts: only the lines of DynALisp and the errors stay.

How To Use

  1. In Dyl-Settings, turn on Clean startup, then Save.
  2. Start AutoCAD again.

Good To Know

  • The lines show for a moment, then go once AutoCAD is ready.
  • Every line is still in the text window (F2).
