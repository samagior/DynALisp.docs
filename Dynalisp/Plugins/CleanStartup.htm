Clean Startup

Setting Clean startup, in the Overrides of Dyl-Settings (DynalispCleanStartup), off on a new installation
Requires AutoCAD 2015 or later for Windows
Licence GNU General Public License v3

Description

Once AutoCAD has started, the lines it printed while starting (Loading AEC..., Customization file loaded successfully, the palettes and startup commands of the workspace...) are removed from the command line. Kept: the Drawing created using... line, the lines of DynALisp and every line that reports an error or a warning. Turn it on in Dyl-Settings: it applies from the next startup.

How To Use

  1. In Dyl-Settings, check Clean startup (in Overrides), then Save.
  2. Start AutoCAD again: once it has started, the command line keeps only the drawing created, the lines of DynALisp and the errors.

Notes

  • AutoCAD and its verticals (AutoCAD Architecture...) print most of these lines before DynALisp is loaded, and no setting of AutoCAD turns them off: they are removed once the startup is over, when DynALisp is loaded, no command runs and no line has come for 2 seconds. They may show for a moment until then. When DynALisp loaded has not come after 30 seconds, the lines are cleaned anyway; after 2 minutes, nothing is done.
  • A line is kept when it holds Drawing created using, starts with DynALisp, Dyl-Settings or -->, or holds error, warning, exception, failed, unable, cannot, not found, invalid, unknown command or missing.
  • Only the command line is cleaned: the lines removed become blank lines above the ones kept (seen when its history is scrolled up), and the text window (F2) keeps every line of the startup. AutoCAD keeps its own copy of the lines and adds the next ones after the number of lines shown, so the command line keeps that number.
  • The System Variable Changed notice is AutoCAD's own: SYSMON 0 turns it off for good, whether Clean startup is on or not.
  • AutoCAD has no command for it: the plugin uses the list of lines of the command line, and does nothing in a version where it does not find it. In a version older than 2015, the plugin is not loaded and the setting is greyed out.
  • For whoever changes DynALisp: the source is Installer\Startup, one project built for .NET 8 and for .NET Framework 4.8, both DLLs committed.
