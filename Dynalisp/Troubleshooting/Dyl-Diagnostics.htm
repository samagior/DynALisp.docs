Diagnostics

Function Syntax DYL-DIAGNOSTICS
Works with Start Page – Report a problem runs it for you
Requires A GitHub account to send the report

Program Description

Find out why something does not work. Diagnostics checks DynALisp, AutoCAD and your drawing, and lists the problems with what to do.

How To Use

  1. Type DIAG. The report opens.
  2. Read the problems at the top: each one says what to do.
  3. To get help, answer Open issue, say what happened and attach the report (see below).

Sending A Report

The report goes in a public GitHub issue that you read before you submit it. It never holds your name, your computer name or your drawing. Report a problem on the Start page does it all for you.

When AutoCAD Is Slow

  • DIAG-EVENTS – run it, work the slow way for 20 seconds, run it again: the report shows what kept AutoCAD busy.
  • DIAG-RECORD – for a problem that comes and goes. A red REC badge shows it records. Click Bug now when it happens, Stop to end.
  • DIAG-DWG – times a regeneration of the drawing.
  • DIAG-INTERFACE – when a part of AutoCAD keeps the wrong colors.
