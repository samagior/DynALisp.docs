Diagnostics

Syntaxe DYL-DIAGNOSTICS
Requis AutoCAD 2025 ou plus récent pour Windows, un compte GitHub pour envoyer le rapport
Licence Licence publique générale GNU v3

Description

Trouvez pourquoi quelque chose ne fonctionne pas. Diagnostics vérifie DynALisp, AutoCAD et votre dessin, et liste les problèmes avec quoi faire.

Utilisation

  1. Tapez DIAG. Le rapport s'ouvre.
  2. Lisez les problèmes en haut : chacun dit quoi faire.
  3. Pour obtenir de l'aide, répondez Open issue, dites ce qui s'est passé et joignez le rapport (voir plus bas).

Envoyer un rapport

Le rapport va dans un ticket GitHub public que vous relisez avant de le soumettre. Il ne contient jamais votre nom, le nom de votre ordinateur ni votre dessin. Report a problem sur la page de démarrage fait tout pour vous.

Quand AutoCAD est lent

  • DIAG-EVENTS – lancez-le, travaillez 20 secondes là où c'est lent, relancez-le : le rapport montre ce qui occupait AutoCAD.
  • DIAG-RECORD – pour un problème qui va et vient. Un badge rouge REC montre l'enregistrement. Cliquez Bug now quand ça arrive, Stop pour finir.
  • DIAG-DWG – chronomètre une régénération du dessin.
  • DIAG-INTERFACE – quand une partie d'AutoCAD garde les mauvaises couleurs.
