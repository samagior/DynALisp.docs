Startup Suite

Function Syntax DYL-SUITE

Program Description

Every command of DynALisp in one list. Turn on the ones you use and give them short names you can type.

How To Use

  1. Type Dyl-Suite.
  2. Check the commands you want and add their short names under Aliases of the command.
  3. Click Save.

The Window

  • Module / Group / Show / Sort by / Search – find a command.
  • List – check Load to turn a command on. Click the arrow of a command to show its variants. Double-click a command to open its docs.
  • Selection – what the command does. Command docs opens its page, Open Lisp its program.
  • Aliases of the command – Add, Rename or Remove a short name. DynALisp tells you when a name is already taken by AutoCAD or another program.
  • On/Off – turns the selected commands on or off.
  • Open in VS Code – opens DynALisp in Visual Studio Code (below).

Visual Studio Code

Dyl-VSCode opens DynALisp in Visual Studio Code, to read or change the programs. If it is not installed yet:

  • Install (winget) – installs it for you. Wait for Successfully installed, then click Open DynALisp.
  • Download page – to install it yourself.
