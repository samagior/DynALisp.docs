Startup Suite

Function Syntax DYL-SUITE, DYL-VSCODE, DYL-SUITEUPDATE, DYL-RELOAD
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

DYL-SUITE opens the Startup Suite window: every command of the DynALisp modules, with its aliases, name, module and group. It turns the commands on or off (the commands turned on are autoloaded: their Lisp file loads the first time one of them is run; a command turned off is not defined), edits their aliases and opens their docs or their Lisp file. The list is the command index Resources\StartupSuite.csv (a new command is off until it is turned on).

The Window

  • Module / Group / Show / Sort by – list the commands of a module and of a group. Dyl-Suite opens on the Dynalisp module: pick another module (LeeMac, MyTools...) or All to list its commands; Show: All, On, Off or With aliases; Sort by: Command, Aliases, Name, Module or Group (each main command keeps its children under it). Search (Enter) lists the commands that contain the text typed, Clear empties it.
  • List – state, command, aliases, name, module and group. A main command with children (presets, Pst-*) shows [+] / [-]: double-click it, or Fold/Unfold (Fold/Unfold All), to show or hide them. Show unloaded commands and Show child commands add them to the list; both are unchecked each time Dyl-Suite opens, so the list starts with the main commands turned on (check Show child commands to fold and unfold the children). Double-click another command to open its docs page.
  • Selection – the name, description and file of the commands selected. Command docs opens their docs pages (the commands without a page of their own open the docs index of their module), Open Lisp their Lisp files (10 at most).
  • Aliases of the command – the short names that run the command selected: Add creates the alias typed, Rename gives the alias picked the name typed, Remove deletes it. An alias is a short name: it cannot start with Dyl-, LM- or Pst- (the long names are the commands), nor be the name of a command, another alias, an AutoCAD command, the command of another program loaded in AutoCAD (an Express Tools command such as TCOUNT, a Lisp file of your own...) or an alias of acad.pgp (DO for DONUT), which it would take from AutoCAD: the message under the list says which one has it. An alias saved before that name was taken (Express Tools installed later...) never runs, since a command always wins: the message under the list tells it when its command is selected (TCOUNT is already a command of another program: rename it.), and Dyl-Reload and the save of Dyl-Suite list it at the command line, with its command and what has its name. Saved to Resources\Aliases.csv (your copy under User).
  • On/Off – turns the commands selected on or off; All Listed On/Off all the commands listed.
  • Open in VS Code – opens the DynALisp folder in Visual Studio Code (below).
  • Save – saves the commands turned on and off (StartupSuite.csv) and the aliases, then asks whether to apply them to the current drawing now (else they apply to the drawings opened from now on, or after Dyl-Reload); a file open in Excel can be closed and retried. Cancel discards the changes. Open Docs opens this page.

Other Commands

CommandWhat it does
Dyl-ReloadLoads the module commands again, as turned on in Dyl-Suite (after editing a Lisp file, or turning commands on).
Dyl-SuiteUpdateRebuilds the command index (StartupSuite.csv) from the Lisp files; it runs by itself at startup when a Lisp file changed.
