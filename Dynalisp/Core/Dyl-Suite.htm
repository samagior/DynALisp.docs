Startup Suite

Function Syntax DYL-SUITE, DYL-VSCODE, DYL-SUITEUPDATE, DYL-RELOAD
Requires AutoCAD for Windows (ActiveX / Visual LISP)
Licence GNU General Public License v3

Program Description

DYL-SUITE opens the Startup Suite window: every command of the DynALisp modules, with its aliases, name, module and group. It turns the commands on or off (the commands turned on are autoloaded: their Lisp file loads the first time one of them is run; a command turned off is not defined), edits their aliases and opens their docs or their Lisp file. The list is the command index Resources\StartupSuite.csv (a new command is off until it is turned on).

How To Use

  1. Type Dyl-Suite: every command of the modules, with its aliases, name, module and group.
  2. Check the box of the commands you want, give them short names in Aliases of the command, open their docs or their Lisp file.
  3. Click Save: the commands turned on are ready in every drawing; the ones turned off are not defined.

The Window

  • Module / Group / Show / Sort by – list the commands of a module and of a group. Dyl-Suite opens on the Dynalisp module: pick another module (LeeMac, MyTools...) or All to list its commands; Show: All, On, Off or With aliases; Sort by: Command, Aliases, Name, Module or Group (each main command keeps its children under it). Search lists, as you type, the commands whose command, aliases, name, description or file contain the text; Clear lists every module again, with Show on All and no search.
  • List – Load (its box turns the command on or off), command, aliases, name, module and group. Ctrl or Shift click selects several commands. A main command with children (presets, Pst-*) shows how many it has and an arrow before it: click the arrow, double-click the command, or use Fold/Unfold (Fold/Unfold All) to show or hide them; a main command unfolded goes to the top of the list. A custom preset of Quick Draw is turned on and off with its main command: its box is greyed out. Show unloaded commands and Show child commands add them to the list; both are unchecked each time Dyl-Suite opens, so the list starts with the main commands turned on (check Show child commands to fold and unfold the children). Double-click another command to open its docs page.
  • Selection – the name and description of the command selected, its main command or its children, and the other files that define the same command. Command docs opens their docs pages (the commands without a page of their own open the docs index of their module), Open Lisp their Lisp files (10 at most).
  • Aliases of the command – the short names that run the command selected: pick an alias to put it in the box. Add (or Enter in the box) creates the alias typed, Rename gives the alias picked the name typed, Remove deletes it. An alias is a short name: it cannot start with Dyl-, LM- or Pst- (the long names are the commands), nor be the name of a command, another alias, an AutoCAD command, the command of another program loaded in AutoCAD (an Express Tools command such as TCOUNT, a Lisp file of your own...) or an alias of acad.pgp (DO for DONUT), which it would take from AutoCAD: the message under the aliases says which one has it (an AutoCAD command is said when you click Save: the window opens again with its message, to rename it). An alias saved before that name was taken (Express Tools installed later...) never runs, since a command always wins: the message under the list tells it when its command is selected (TCOUNT is already a command of another program: rename it.), and Dyl-Reload and the save of Dyl-Suite list it at the command line, with its command and what has its name. Saved to Resources\Aliases.csv (your copy under User).
  • On/Off – turns the commands selected on or off; All Listed On/Off all the commands listed.
  • Open in VS Code – opens the DynALisp folder in Visual Studio Code (below), then the Startup Suite window again, as it was.
  • Save – saves the commands turned on and off (StartupSuite.csv) and the aliases, then asks whether to apply them to the current drawing now (else they apply to the drawings opened from now on, or after Dyl-Reload); a file open in Excel can be closed and retried. Cancel discards the changes. Open Docs opens this page. The sort and the commands unfolded are kept for the next time.

Visual Studio Code

Dyl-VSCode (or Open in VS Code) opens the DynALisp folder in Visual Studio Code, to read or edit the programs. When Visual Studio Code is not found, a window guides its install:

  • Install (winget) – installs it for your Windows user with the Windows package manager, in a black window: wait for Successfully installed, close it, then click Open DynALisp.
  • Download page – opens its download page: get the User Installer for Windows, run it and keep Add to PATH checked.
  • Open DynALisp – opens the folder once Visual Studio Code is installed (the window says when it is still not found). In Visual Studio Code, trust the folder and install the recommended AutoLISP extension when asked.

Other Commands

CommandWhat it does
Dyl-ReloadLoads the module commands again, as turned on in Dyl-Suite (after editing a Lisp file, or turning commands on).
Dyl-SuiteUpdateRebuilds the command index (StartupSuite.csv) from the Lisp files; it runs by itself at startup when a Lisp file changed.
