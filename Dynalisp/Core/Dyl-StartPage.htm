Start Page

Setting Start page and Active time, in the Overrides of Dyl-Settings, off on a new installation
Requires AutoCAD 2025 or later for Windows, its Start tab on
Licence GNU General Public License v3

Description

The Start tab of AutoCAD shows the Start page of DynALisp in place of its own, in the manner of a profile page, in three columns across the tab: near its left edge, what starts a drawing (New, Open..., Open sheet set... and your templates); in the middle between them, the widest, what you pinned (drawings, sheet sets, projects), the time you spent working each day of the year and a few recent drawings, with the picture each drawing keeps of itself; near its right edge, the tasks of each project and sheet set pinned, with a bar of what is done. No path is shown: point at a card or a drawing to read it. DynALisp itself is only a line at the foot of the page. It opens as AutoCAD starts and each time you click the Start tab, in the colours of AutoCAD (or of DynALisp Neutral).

How To Use

  1. In Dyl-Settings, check Start page (in Overrides), and Active time under it to count the time spent in each drawing, then Save. The Start tab shows the page of DynALisp within a second.
  2. New starts a drawing from your template (the one of QNEW), a template of the list starts one from it, Open... opens one or more drawings, Open sheet set... opens a sheet set in the Sheet Set Manager.
  3. Right-click a recent drawing and choose Pin, Pin sheet set or Pin project, or click Pin... and pick a drawing (.dwg), a sheet set (.dst) or a project (.apj).
  4. Click a pinned drawing to open it. Click a pinned sheet set or project to show only its time in the graph; click it again, or Show all, to show all of it.
  5. Click a day of the graph (or a month over it) to list the drawings worked on then; click one to open it.
  6. Under a project on the right, type a task in the box and press Enter; check it once done, right-click it to delete it.
  7. Something went wrong? Click Report a problem, say what happened, then Open the issue (see Report a Problem).

The Page

  • New, Open and the templates – on the left. Templates lists the template of QNEW first, marked default, then the templates of the template folder of AutoCAD (Files of Options), 12 at most; Browse templates... picks another one.
  • Pinned – up to 6 cards, in the order they were pinned: each with its name (the title of a sheet set, as the Sheet Set Manager shows it, not the name of its file), its kind (Drawing, Sheet set or Project) and its active time in the last year. The time of a sheet set or a project is that of the drawings in its folder and the folders under it. Right-click a card to open it (a drawing, a sheet set: in the Sheet Set Manager), show its time, show it in its folder or unpin it.
  • Active time – a square for each day, darker for more time: under 1 hour, 1 to 3 hours, 3 to 6 hours, 6 hours and more. Point at a day to read its time. The last 12 months, or a year picked on the right. Under it, the drawings worked on in the day or month picked (the last month with time until you pick one), the most time first.
  • Recent – the first 10 drawings of the recent list of AutoCAD, the last opened first, each with its picture and when it was last saved. Type in Search to find one by its name or its folder, among all of them. Right-click a drawing to open it read-only, show it in its folder, or pin it, its sheet set or its project. A drawing that is no longer found says Not found, greyed out. A drawing already open is made current instead of being opened again.
  • Projects – on the right, a card for each project and sheet set pinned: its tasks, and a bar of how many are done. The tasks are kept with the project, in a DynALisp\Tasks.csv file beside its .apj or .dst, so everyone who opens the project from the same folder sees the same tasks.
  • The foot of the page – the version of DynALisp, the AutoCAD it runs in and the time of its last startup; in red, what is wrong (a plugin not loaded, a warning of the last startup, the problems of the last Dyl-Diagnostics). Settings opens Dyl-Settings, Report a problem opens the panel of a report, Docs opens the home page of the docs.

Active Time

A drawing counts while it is the current drawing, AutoCAD is the application in front and you used the mouse or the keyboard in the last 3 minutes. The Start tab, another application, a pause and a drawing never saved do not count. The time is written every 2 minutes, when a drawing closes and when AutoCAD quits; two AutoCAD open at once add their time to the same files.

It stays on this computer, in the User\Start folder of DynALisp (a file per month, a line per day and drawing), with the pins: Export settings of Dyl-UserFiles keeps them, and a report of Dyl-Diagnostics never holds them. It is counted only while Start page is on too.

Report a Problem

Type what you did, what you saw and what you expected, then click Open the issue. DynALisp runs Dyl-Diagnostics on its own, then opens a new issue of DynALisp on GitHub in your browser, filled in with what you typed, the summary and the problems of the report. GitHub does not let a page attach a file to an issue: the zip of the report is put on the clipboard, so press Ctrl+V in the text of the issue to attach it. Check the issue, then Submit: it is public, and nothing is sent until you do. The report never holds your user name, your computer name, your active time or the drawing itself.

Notes

  • Settings and a report run in a drawing, and a sheet set opens in the Sheet Set Manager of a drawing: when no drawing is open, a new drawing is started first. With no drawing open, Report a problem uses the last report made.
  • A project has no command to open it: its card shows its time, and Show in folder opens its folder.
  • The page is shown only in the Start tab: with STARTMODE at 0 (the Start tab off), turning Start page on in Dyl-Settings turns the Start tab back on.
  • The page reads the drawings and the time on its own, so the Start tab never waits for a slow network drive: they appear once read. The pictures are kept in the temp folder, made again when a drawing is saved. The title of a sheet set is read again only once its file changed.
  • AutoCAD has no command for its Start tab: DynALisp puts its page over the page of AutoCAD, which it hides, and gives it back when Start page is turned off. In a version of AutoCAD where it does not find the Start tab, the Start tab stays as it is; the Interface section of Dyl-Diagnostics says what was found, to send with an issue.
