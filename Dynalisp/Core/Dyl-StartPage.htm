Start Page

Setting Start page, in the Overrides of Dyl-Settings, off on a new installation
Requires AutoCAD 2025 or later for Windows, its Start tab on
Licence GNU General Public License v3

Description

The Start tab of AutoCAD shows the Start page of DynALisp in place of its own: your recent drawings, with the picture each drawing keeps of itself, and beside them what DynALisp is, how it started in the last drawing opened, its main settings and its last diagnostics. It opens as AutoCAD starts and each time you click the Start tab, in the colours of AutoCAD (or of DynALisp Neutral).

How To Use

  1. In Dyl-Settings, check Start page (in Overrides), then Save. The Start tab shows the page of DynALisp within a second.
  2. Click a drawing to open it; right-click it to open it read-only or show it in its folder. Type in Search to find a drawing by its name or its folder.
  3. New starts a drawing from your template (the one of QNEW), Open... opens one or more drawings.
  4. Read the cards on the right; Settings, Run Diagnostics and Open report lead to the rest.

The Page

  • Recent drawings – the drawings of the recent list of AutoCAD, the last opened first, each with its picture, its folder and when it was last saved (today, yesterday or its date). A drawing that is no longer found says Not found, greyed out. A drawing already open is made current instead of being opened again.
  • DynALisp – how it is installed (by the setup, or a git clone with its branch and commit), its modules, and whether every plugin of DynALisp is loaded (one that is not is named, in red).
  • Startup – the time DynALisp took to start in the last drawing opened, the drawing and when, its commands and aliases, its three slowest steps, and in red each warning and each file that did not load. Before any drawing is opened, the last startup of the previous session.
  • Settings – Reactors, Display, Clean startup, Updates and Language, as saved in Dyl-Settings. Settings opens Dyl-Settings.
  • Diagnostics – the last full report of Dyl-Diagnostics: when, how many problems, and the first three. Run Diagnostics makes a new one, Open report opens the last; Open Docs opens this page.

Notes

  • Settings and Run Diagnostics run in a drawing: they are greyed out while no drawing is open.
  • The page is shown only in the Start tab: with STARTMODE at 0 (the Start tab off), turning Start page on in Dyl-Settings turns the Start tab back on.
  • The page reads the drawings on its own, so the Start tab never waits for a slow network drive: they appear once read. The pictures are kept in the temp folder, made again when a drawing is saved.
  • AutoCAD has no command for its Start tab: DynALisp puts its page over the page of AutoCAD, which it hides, and gives it back when Start page is turned off. In a version of AutoCAD where it does not find the Start tab, the Start tab stays as it is; the Interface section of Dyl-Diagnostics says what was found, to send with an issue.
