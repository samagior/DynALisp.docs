Preview Picture

Syntaxe Choose preview picture... sur la page de démarrage
Requis AutoCAD 2025 ou plus récent pour Windows
Licence Licence publique générale GNU v3

Description

Cadrez la partie d'une image à montrer comme aperçu d'un dessin sur la page de démarrage.

Utilisation

  1. Sur la page de démarrage, cliquez droit sur un dessin, choisissez Choose preview picture... et une image.
  2. Glissez le cadre sur la partie à garder. Glissez son coin ou tournez la molette pour le redimensionner.
  3. Cliquez OK.
