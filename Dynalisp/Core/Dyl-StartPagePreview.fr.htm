Preview Picture

Ouverte par Choose preview picture... d'un dessin cliqué avec le bouton droit dans la page de démarrage, quand l'image choisie n'a pas la forme des cadres de la page
Requiert AutoCAD 2025 ou plus récent pour Windows
Licence GNU General Public License v3

Description du programme

Chaque image d'un dessin dans la page de démarrage remplit un cadre de la même forme, 16 de large sur 10 de haut. Une image d'une autre forme (une photo prise à la verticale, un logo carré) est montrée en entier dans cette fenêtre avec un cadre dessus : ce qui est dans le cadre devient l'image du dessin.

Mode d'emploi

  1. Dans la page de démarrage, cliquez avec le bouton droit sur un dessin récent ou une carte épinglée et choisissez Choose preview picture..., puis choisissez une image.
  2. Glissez le cadre sur la partie à garder. Glissez son coin, ou tournez la molette, pour l'agrandir ou le réduire ; cliquez à côté pour l'y amener.
  3. Cliquez sur OK.

Fenêtre Preview Picture

  • Le cadre garde toujours sa forme et reste sur l'image ; il s'ouvre aussi grand que l'image le permet, en son milieu. Une photo est montrée droite, comme son appareil l'a prise.
  • OK garde la partie encadrée comme image du dessin (copiée : l'image elle-même peut être déplacée ou supprimée ensuite). Cancel garde l'image qu'avait le dessin, Open Docs ouvre cette page.
