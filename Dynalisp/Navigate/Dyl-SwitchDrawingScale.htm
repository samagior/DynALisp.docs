Switch Drawing Scale

Function Syntax DYL-SWITCHDRAWINGSCALE and 39 scales – see Commands
Works with Quick Draw – scales its hatches with it

Program Description

Set the annotation scale in a few keystrokes: type 1-100 and the drawing is at 1:100. In an imperial drawing, you get the closest architectural scale.

How To Use

  1. Type a scale: 1-50, 1-100, 1-48... (tables below).
  2. Or pick one under the arrow of the Switch Drawing Scale button of the ribbon.

A scale the drawing does not have yet is added for you.

Known Limitations

  • In a layout, the command changes the annotation scale of paper space, not the scale of a viewport.
