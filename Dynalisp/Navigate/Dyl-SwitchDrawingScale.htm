Switch Drawing Scale

Function Syntax DYL-SWITCHDRAWINGSCALE and 39 scales – see Commands
Licence GNU General Public License v3

Program Description

Set the annotation scale in a few keystrokes: type 1-100 and the drawing is at 1:100. The same command gives the closest architectural scale in an imperial drawing (1-100 gives 1/8" = 1'-0"), so the same keystrokes work in metric and imperial drawings.

How To Use

  1. Type the scale as its alias: 1-50, 1-100, 1-48... (the tables below). The annotation scale changes at once.
  2. Or type Dyl-SwitchDrawingScale and the ratio (100, 1:100 or 1-100); ? lists the scales, Enter keeps the current one.
  3. From the ribbon, the arrow of the Switch Drawing Scale button lists the usual scales; the button then sets the one picked last.

Good To Know

  • A scale the drawing does not have yet is added to its scale list, then set.
  • The metric series is named after the metric ratio, the imperial series after the imperial one: 1-48 is 1/4" = 1'-0" in an imperial drawing and 1:50 in a metric one.

Known Limitations

  • 1-384 sets 1" = 1'-0" in imperial drawings; the 1:384 scale is 1/32" = 1'-0".
  • In a layout, the command changes the annotation scale of paper space, not the scale of a viewport.

Command Names And Aliases

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of Dyl-SwitchDrawingScale: they are run by their alias, or picked from Dyl-SwitchDrawingScale when it lists them (their command is named Pst-*).
